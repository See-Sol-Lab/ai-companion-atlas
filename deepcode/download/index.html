一键安装

安装器按当前 Windows 用户安装到本地应用目录，不需要管理员权限，也没有多页安装向导。

自带运行时

发行包包含 DeepSeek Harness 运行所需内容。普通用户不需要预先安装 Node.js、pnpm 或从源码构建。

数据不跟着卸载消失

普通卸载会询问是否删除 DeepCode 应用数据；选择保留后，重装可以继续使用已有设置、凭据与会话。

FIRST RUN

安装之后，四步开始工作。

01

打开 Models

在设置里进入 Models，填入 DeepSeek API key。凭据由 Harness 的官方凭据机制保存在 DeepCode 自己的数据目录。

02

选择工作区

回到首页，选择你要让 Agent 工作的项目文件夹。

03 · 04

新建会话，开始

选择模型与工作区后创建会话。需要更深控制时，再打开 Profiles、插件或 DSH Terminal。
