隐私政策

最后更新：2026 年 8 月 27 日。DeepCode 是本地优先的桌面 Agent 产品。本页说明当前公开预览设计中，应用数据、API 凭据、模型请求、诊断日志以及官网访问分别如何处理。

1. 适用范围

本政策适用于 See-Sol-Lab 提供的 DeepCode Desktop、DeepCode 产品官网与官方下载安装页面。DeepCode 是 DeepSeek Harness 的非官方社区产品，与 DeepSeek 无隶属关系，也未获其背书。

2. 本地应用数据

DeepCode Desktop 把 Harness 的运行数据与产品偏好保存在用户自己的设备上。打包版默认使用 %APPDATA%\DeepCode\dsh 保存凭据、设置、会话与 Profiles；桌面 launcher 和窗口偏好也使用 DeepCode 自己的 userData 目录。

DeepCode 不为了桌面界面再建立第二套会话、模型、凭据、权限、记忆或 hook 存储。Harness 仍是运行时与持久状态的来源。

3. API Key 与凭据

用户自行配置 DeepSeek 或其他 Harness 支持的模型服务凭据。DeepCode Desktop 使用 Harness 的凭据机制把密钥保存在应用自己的数据目录中；产品设计要求这些密钥不进入安装包、普通命令行参数或诊断日志。

请不要把自己的 API key、token 或其他账号凭据提交到 GitHub issue、公开评论区或其他公开渠道。

4. 第三方模型与服务

当你使用 DeepSeek、OpenAI-compatible endpoint 或其他由 Harness adapter 接入的第三方服务时，为完成你的请求，相关提示词、文件内容或工具结果可能会发送给你主动选择的服务提供商。

这些第三方如何保存、训练、审计或处理数据，由它们各自的服务条款和隐私政策决定。DeepCode 无法替代第三方政策。

5. 诊断日志

打包版会在本机 DeepCode 应用数据目录记录有限的 Harness 服务诊断日志，用于定位启动和运行问题。当前实现会对常见 API key、GitHub/Slack token、AWS access-key id 与 Bearer token 等凭据形态做脱敏，并限制历史日志数量和总大小。

如果你主动把日志提交给维护者，请仍然在发送前检查其中是否包含项目路径、文件名、错误正文或其他你不希望公开的信息。

6. 官网与下载页面

访问 DeepCode 官网和下载页面时，网站托管、CDN、反向代理或服务器可能为了正常提供页面、安全防护和故障诊断而处理标准 HTTP 元数据，例如 IP 地址、时间、请求路径、User-Agent 和缓存信息。

DeepCode 官网不以出售个人信息、广告画像或跨站追踪为产品目标。如果未来加入额外分析、账号体系、崩溃上报或其他在线服务，我们会在启用前更新本政策并说明用途。

7. 删除与卸载

普通卸载 DeepCode 时，卸载程序会询问是否一并删除 %APPDATA%\DeepCode。如果选择保留，凭据、设置与会话可以在之后重装时继续使用。静默卸载和升级替换会默认保留应用数据。

如需彻底清除本地数据，请在确认不再需要后删除 DeepCode 的应用数据目录，并同时检查你自己指定的 Existing Harness Home 或外部备份位置。

8. 外部链接与上游项目

官网可能链接到 GitHub、DeepSeek Harness、AI Companion Atlas 或模型服务商。离开 DeepCode 官网后，对方网站的数据处理受其各自政策约束。

9. 政策更新与联系

DeepCode 仍在开发中。如果数据流、网站托管方式或在线能力发生实质变化，我们会更新本页并修改“最后更新”日期。

产品公开后，隐私与安全问题可以通过 DeepCode GitHub 仓库提交；涉及敏感漏洞时，请优先使用仓库公布的安全联系方式，而不是公开 issue。
