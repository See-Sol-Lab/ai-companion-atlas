FROM INSTALL TO WORK

装好，选一个文件夹，然后开始。

DeepCode 的第一层目标很简单：让不想折腾 Node.js、pnpm 和本地 Web 地址的人，也能直接使用 DeepSeek Harness 的桌面能力。

01 · INSTALL

一键安装

Windows 按当前用户安装，不需要管理员权限。发行包自带运行时，不要求你先配 Node.js 或 pnpm。

02 · WORKSPACE

工作区直接打开

从桌面里选择项目文件夹，新建或继续会话。模型配置、工作区与 Harness 都在同一个入口里。

03 · LOCAL DATA

应用数据留在本机

DeepCode 使用自己的应用数据目录保存 Harness 设置、凭据、会话与 Profiles，不去污染全局 DSH 环境。

HARNESS-FIRST

一个桌面，不另造一个 Agent。

DeepCode 不复制第二套会话、模型、凭据或记忆系统。DeepSeek Harness 仍然是运行时与事实来源，桌面层负责把它变得更容易使用、检查和扩展。

原生 Profiles

继续使用 Harness 的 profile 体系；切换、恢复和配置都围绕同一个运行时发生。

PROFILE · BUNDLE · CORDIS
插件与终端

需要更深一层时，可以进入 DSH Terminal 与插件管理，而不是离开产品重新搭一套开发环境。

TOOLS · PLUGINS · TERMINAL

COMPATIBILITY · WORKBENCH · LAB

TWO DEPTHS, ONE PRODUCT

普通使用时干净，想研究时也有门。

你可以把 DeepCode 当成一个日常 Coding Agent 桌面客户端；也可以继续往下打开 Profiles、插件、终端和 Harness 控制面。复杂度只在需要的时候出现。

DeepCode 来自 See-Sol-Lab，也住在 AI Companion Atlas 的同一片院子里。

Atlas 负责发现记忆、前端、五感、工具与关系延续项目；DeepCode 是我们自己做出来的产品之一。两个入口会互相连接，但各自只做自己最该做的事。
