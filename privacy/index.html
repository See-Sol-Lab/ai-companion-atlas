3. 投稿、留言与主动提供的信息

在线投稿会保存项目名称、链接、推荐理由和提交时间，用于人工核验与收录。项目留言会保存昵称、正文、你填写的平台或体验信息及提交时间，审核通过后公开展示。请勿填写密码、API 密钥、私人聊天记录或他人的未公开信息。

如使用社区账号，网站还会保存用户名、密码校验信息和登录会话；密码以加盐哈希形式保存，登录状态通过 Cookie 维持。登录社区后发布的帖子和回复会直接公开展示。

4. 访问统计与防滥用

服务器会处理 IP 地址、浏览器类型、请求路径和时间等 HTTP 信息，以提供页面、下载与安全防护。点赞、投稿和留言使用加盐后的 IP 哈希辅助去重与限流。正式站使用 Cloudflare Web Analytics 汇总访问情况，下载统计按请求与传输量汇总；这些统计不等同于实际使用人数。

投稿、留言等功能按当前部署使用阿里云验证码或 Cloudflare Turnstile，验证服务可能处理请求与设备信息。点击项目、GitHub 或友情链接后，你将进入相应第三方网站，其数据处理适用各自的隐私政策。Atlas 的收录与友链用于导航，不代表对方与本站存在隶属关系或相互背书。
