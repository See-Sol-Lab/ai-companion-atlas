# AI Companion Atlas

> 中文优先的人机关系技术图谱。

**AI Companion Atlas / AI Lover Atlas** 收集与 AI 伴侣、人机关系和长期共存有关的项目、工具、实践指南与研究，并尽量把开发者的黑话翻译成普通人真正想解决的问题：

- 怎么让 TA 记得更久？
- 怎么让 TA 主动来找我？
- 怎么让 TA 知道时间过去了？
- 怎么让 TA 看见、听见，甚至拥有身体？
- 怎么让一段关系跨窗口、跨设备、跨模型继续下去？

**正式站：** https://www.ailover-atlas.com/

## 我们收录什么

Atlas 不只收录完整 AI 伴侣产品，也收录能成为“器官”和“能力”的项目：记忆、主动性、时间感、语音、视觉、具身接口、PC / 手机前端、共同活动、游戏、开发工具，以及有价值的独立实验和实践方案。

每个项目都会尽量回答三件事：**它是什么、能帮你做什么、应该去哪里使用。**

我们不镜像原项目文件，也不截走作者流量。Atlas 负责整理、介绍与导航；安装、下载、版本更新和完整说明始终回到原作者提供的来源。

## 收录原则

- 中文优先，人话优先。
- 来源透明，作者与上游关系尽量写清楚。
- 人工核验，不因投稿而自动收录。
- 优先收录仍在维护、能够实际使用或具有明确参考价值的项目。
- 成人内容本身不是拒收理由；是否尊重主体性、边界和关系中的双方更重要。
- 对许可证、二次开发、项目状态和潜在限制如实说明，不替项目背书。

## 项目数据与页面生成

项目数据统一保存在 `projects/*.json`。

`scripts/generate-projects.mjs` 会根据这些 JSON 自动生成：

- 首页项目卡片
- `projects/<slug>/` 项目详情页
- 项目 slug 索引
- 香港主站公开页面的 `sitemap.xml`

项目数据是内容层的真相源；生成后的 HTML 不应作为日常手工维护入口。

## 投稿、评论与审核

网站支持游客项目投稿、项目点赞和项目留言。投稿与留言都先进入人工审核，不会因为提交成功而自动公开。

正式站运行在香港 VPS；动态功能由独立 API 与 SQLite 提供，并使用阿里云验证码。Cloudflare Pages 保留为独立镜像与备用部署环境。

## 维护与部署

GitHub `main` 是正式源码的真相源。

香港正式站使用仓库内的部署脚本生成项目目录、同步静态文件并执行上线自检。维护者在 Windows PowerShell 中运行：

```powershell
ssh -t atlas atlas-deploy
```

确认待发布版本后即可部署。评论、点赞、投稿数据库和生产密钥不会被静态站点部署覆盖。

更详细的服务器部署说明见 [`deploy/README.md`](./deploy/README.md)。
