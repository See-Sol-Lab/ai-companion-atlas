一键安装

安装器按当前 Windows 用户装进本地应用目录，普通用户权限就够，双击之后一路到底。

自带运行时

发行包已经带齐 DeepSeek Harness 运行所需的一切，Node.js 和 pnpm 都打包在里面，装完就能用。

卸载之后数据还在

普通卸载会询问是否删除 DeepSeek GUI 应用数据；选择保留后，重装可以继续使用已有设置、凭据与会话。

FIRST RUN

安装之后，四步开始工作。

01

打开 Models

在设置里进入 Models，填入 DeepSeek API key。凭据由 Harness 的官方凭据机制保存在 DeepSeek GUI 自己的数据目录。

02

选择工作区

回到首页，选择你要让 Agent 工作的项目文件夹。

03 · 04

新建会话，开始

选择模型与工作区后创建会话。需要更深控制时，再打开 Profiles、插件或 DSH Terminal。
