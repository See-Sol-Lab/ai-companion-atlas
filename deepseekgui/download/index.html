DeepSeek GUI 1.0.0 · Windows 桌面应用

FIRST RUN

遇到蓝色弹窗，两步继续安装

双击安装包后，Windows 会弹出“已保护你的电脑”。这个弹窗默认只显示“不运行”按钮，需要先点开“更多信息”，运行按钮才会出现。

  1. 第一步

    点击左下角的 更多信息。这是一个不显眼的文字链接，容易被忽略。

  2. 第二步

    弹窗展开后会多出 仍要运行 按钮，点击它就开始安装了。

这个提示来自 Windows 对未签名应用的默认拦截。安装包的 SHA256 校验值公布在 GitHub Release 页面，可以先核对再安装。代码签名会在后续版本加上。
