DeepSeek GUI 是什么

DeepSeek GUI 是 See-Sol-Lab 在 DeepSeek Harness 之上做的 Windows 桌面客户端。Harness 负责所有运行时和会话管理；DeepSeek GUI 负责桌面界面——工作区、模型配置、Profiles、终端和插件管理。

一句话：打开就能当日常 Coding Agent 用，想深入时 Harness 的配置和运行细节也全在里面。

安装

公开安装包上线后，从 DeepSeek GUI 官网下载 DeepSeekGUI-Setup-<version>.exe。安装器按当前 Windows 用户安装，普通用户权限就够。

  1. 双击安装包。
  2. 文件安装完成后，DeepSeek GUI 会自动启动。
  3. 之后可以从桌面或开始菜单打开 DeepSeek GUI。

发行包自带 DeepSeek Harness 运行时，Node.js 和 pnpm 都已经在里面了。

首次配置

1. 配置模型

打开左下角设置，进入 Models。填入 DeepSeek API key。凭据由 Harness 的凭据机制保存在 DeepSeek GUI 自己的数据目录中，不进入安装包、命令行或普通诊断日志。

2. 选择工作区

返回首页，选择一个项目文件夹作为 workspace。项目留在原地就行，Agent 直接在你选的这个工作区里干活。

3. 新建或恢复会话

选择模型与工作区后新建会话。已有 Harness 会话、Profiles 与配置继续由同一个运行时管理。

Harness 与 Profiles

模型、会话、凭据、权限、记忆和 hook 状态都由 Harness 管理。当前的 Harness Home 和 Profile 由桌面启动器控制。

  • Managed Home：默认使用 DeepSeek GUI 自己的应用数据目录。
  • Existing Home：高级用户可以显式选择已有 Harness Home；DeepSeek GUI 不自动迁移、合并或改写它。
  • Profile：可以切换 Harness profile；切换失败时保留 last-known-good 状态用于恢复。

终端与插件

需要更深层控制时，可以打开 DSH Terminal。DeepSeek GUI 为终端准备私有的 dsh / node / pnpm 入口，不修改系统 PATH、注册表或 shell 配置。

插件管理继续走 Harness 官方的 dsh plugin 路径。DeepSeek GUI 不把“装进 package.json”误当成“插件已经实际加载”，并会区分 Profile Bundles、已安装依赖与 Loader 的真实状态。

数据与卸载

打包版默认把 Harness 数据放在 %APPDATA%\DeepSeekGUI\dsh，其中包括凭据、设置、会话与 Profiles。DeepSeek GUI 的 launcher 和窗口偏好也保存在自己的 userData 目录。

普通卸载会询问是否删除 %APPDATA%\DeepSeekGUI。如果选择保留，之后重装可以继续使用原来的凭据、设置和会话。静默卸载与升级替换会保留数据。

故障排查

端口 3080 被占用

DeepSeek GUI 当前固定在本机 127.0.0.1:3080 启动 Harness 服务。端口被其他程序占用时会明确报错，而不是偷偷换端口。

Harness 启动失败

打包版诊断日志位于 DeepSeek GUI 应用数据目录。日志会对常见 API key、Bearer token 等凭据形态做脱敏。发生运行时崩溃时，DeepSeek GUI 不会无限自动重启；可以从桌面控制层手动 Restart Harness。

窗口关闭后为什么还在

窗口右上角关闭只是隐藏窗口，Harness 继续在系统托盘运行。要真正停止运行时，请使用托盘或菜单中的 Quit DeepSeek GUI。

从源码运行

面向开发者的最短路径：

pnpm install
pnpm run build
pnpm run dev:desktop

dev:desktop 会启动本地 DSH Web 服务并打开 DeepSeek GUI Desktop。公开发布后，更完整的架构与开发文档仍保留在 GitHub 仓库中。

许可与上游

DeepSeek GUI 是 DeepSeek Harness 的非官方社区产品，与 DeepSeek 无隶属关系，也未获其背书。Harness 和官方 Web UI 属于 DeepSeek。

仓库采用分层许可：上游 DeepSeek Harness 及上游衍生内容继续保留 MIT；See-Sol-Lab 原创桌面/产品层在明确范围内采用 PolyForm Perimeter 1.0.1。个人、教育、研究、兴趣与允许的内部使用均可；向他人提供与 DeepSeek GUI 竞争的替代产品需要另行授权。
