FROM INSTALL TO WORK

装上，选个文件夹，开始。

Harness 原本要自己装 Node.js、跑命令行、在浏览器里开 localhost。DeepSeek GUI 把这些全打包了——装完就是一个可以直接打开的桌面应用。

01 · INSTALL

一键安装

按当前用户安装，普通权限就够。Node.js 和 pnpm 已经打包在发行包里。

02 · WORKSPACE

工作区直接打开

在桌面里选一个项目文件夹，就能新建或接续会话。模型、工作区和设置从同一个界面管理。

03 · LOCAL DATA

应用数据留在本机

凭据、设置、会话和 Profiles 存在自己的应用目录，你系统上已有的 Harness 环境完全独立。
