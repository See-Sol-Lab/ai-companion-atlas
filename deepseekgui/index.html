FROM INSTALL TO WORK

装上，选个文件夹，开始。

Harness 原本要自己装 Node.js、跑命令行、在浏览器里开 localhost。DeepSeek GUI 把这些全打包了——装完就是一个可以直接打开的桌面应用。

01 · INSTALL

一键安装

按当前用户安装，普通权限就够。Node.js 和 pnpm 已经打包在发行包里。

02 · WORKBENCH

项目状态就在旁边

会话旁直接查看文件改动、分支、提交、worktree 和项目记忆，不用反复切回命令行确认。

03 · LOCAL DATA

协作经验留在本机

凭据、设置、会话和全局记忆存在应用目录；项目记忆留在所选工作区，覆盖升级不会清空。

HARNESS-FIRST

Workbench 已经在 1.1.0 里。

工作台通过插件扩展官方 Harness 客户端，继续使用同一套会话、工具、权限和运行时。

改动与并行工作区

按状态查看文件和 diff，检查当前分支、提交与多个 worktree，也能发现跨工作区重复改动。

CHANGES · GIT · WORKTREES
Git 与 Pull Request

通过专用工具暂存、提交、推送和创建 PR；每次写操作仍在会话中明确确认目标。

COMMIT · PUSH · PULL REQUEST
全局记忆与项目记忆

跨项目偏好由用户管理，项目决策与约定保存在工作区自己的记忆文件中。

GLOBAL · PROJECT · CONTINUITY

WORKBENCH · HARNESS CONTROL

日常工作与进阶控制，都在同一个窗口。

平时在 Workbench 里协作；需要时再打开 Profiles、插件管理、DSH Terminal 和诊断工具。
