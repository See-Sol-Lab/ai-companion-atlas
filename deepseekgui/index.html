FROM INSTALL TO WORK

装好，选一个文件夹，然后开始。

DeepSeek GUI 的第一层目标很简单：让不想折腾 Node.js、pnpm 和本地 Web 地址的人，也能直接使用 Harness 的桌面能力。

01 · INSTALL

一键安装

按当前 Windows 用户安装，双击就好。发行包自带运行时，Node.js 和 pnpm 都已经装在里面了。

02 · WORKSPACE

工作区直接打开

从桌面里选择项目文件夹，新建或继续会话。模型配置、工作区与 Harness 都在同一个入口里。

03 · LOCAL DATA

应用数据留在本机

DeepSeek GUI 把 Harness 设置、凭据、会话与 Profiles 存在自己的应用数据目录里，你系统里原有的 DSH 环境保持原样。

HARNESS-FIRST

换的是桌面，Agent 还是原来那个。

会话、模型、凭据和记忆始终由 Harness 一家管着，它是唯一的运行时和事实来源。桌面层只做一件事：让它更好用、更容易看清楚、也更容易扩展。

原生 Profiles

继续使用 Harness 的 profile 体系；切换、恢复和配置都围绕同一个运行时发生。

TWO DEPTHS, ONE PRODUCT

普通使用时干净，想研究时也有门。

你可以把 DeepSeek GUI 当成一个日常 Coding Agent 桌面客户端；也可以继续往下打开 Profiles、插件、终端和 Harness 控制面。复杂度只在需要的时候出现。

DeepSeek GUI 来自 See-Sol-Lab，也住在 AI Companion Atlas 的同一片院子里。

Atlas 负责发现记忆、前端、五感、工具与关系延续项目；DeepSeek GUI 是我们自己做出来的产品之一。两个入口会互相连接，但各自只做自己最该做的事。
