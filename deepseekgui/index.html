FROM INSTALL TO WORK

装上，选个文件夹，开始。

Harness 原本要自己装 Node.js、跑命令行、在浏览器里开 localhost。DeepSeek GUI 把这些全打包了——装完就是一个可以直接打开的桌面应用。

01 · INSTALL

装好就能登录

按当前用户安装，普通权限就够。首次启动可以用 DeepSeek 账号登录，也可以填 API Key，然后选个文件夹开始。

02 · WORKBENCH

项目状态就在旁边

会话旁直接查看文件改动、分支、提交、worktree 和项目记忆，不用反复切回命令行确认。

03 · LOCAL DATA

协作经验留在本机

凭据、设置、会话和全局记忆存在应用数据目录；托管数据需要搬家时可以复制、校验再切换。

HARNESS-FIRST

v1.1.2 跟上了官方 Harness 0.1.7。

工作台继续扩展官方 Harness 客户端，会话、工具与权限跟随官方；在这之上加了账号登录、工程记忆、技能库和一组安全保护。

账号登录与用量

用 DeepSeek 账号登录即可使用，不必填 API Key；设置页里查看余额、充值，以及今天、7 天、30 天的花费、请求与 token 用量。

SIGN IN · BALANCE · USAGE
工程记忆与技能库

项目事实和偏好存成带版本的记忆，可以查看、更正、忘掉和撤销；技能从文件夹或 ZIP 导入，按项目勾选使用。

MEMORY · SKILLS · PROJECTS
受保护位置与更新校验

涉及系统文件、已安装程序或应用自身代码的操作一律弹红色审批；更新下载后核对 SHA-256，确认后才安装。

PROTECT · VERIFY · UPDATE

WORKBENCH · HARNESS CONTROL

日常工作与进阶控制，都在同一个窗口。

平时在 Workbench 里协作；需要时再打开 Profiles、插件管理、DSH Terminal 和诊断工具。
