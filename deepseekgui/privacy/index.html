隐私政策

最后更新：2026 年 8 月 27 日。DeepSeek GUI 是纯本地的桌面应用——安装后完全运行在你自己的电脑上，我们不运营服务器，不收集用户数据。

1. 我们不收集你的数据

DeepSeek GUI 没有自己的服务器。你的聊天记录、项目文件、API 凭据和所有配置都只存在你的设备上，不会被发送到 See-Sol-Lab 或任何第三方。我们不收集、不存储、不传输你的任何个人数据或使用信息。

2. 本地数据存储

DeepSeek GUI 把运行数据保存在你设备上的 %APPDATA%\DeepSeekGUI\dsh 目录中，包括 API 凭据、会话记录、模型配置、Profiles 和桌面偏好设置。这些数据完全由你控制。

API 凭据由 Harness 的凭据机制保存在应用自己的数据目录中，不会进入安装包、命令行参数或诊断日志。请妥善保管你的 API key，不要将其提交到 GitHub issue 或其他公开渠道。

3. 第三方模型服务

当你使用 DeepSeek 或其他模型服务时，你的请求内容会发送到你自己选择的服务商。这些第三方如何处理数据，由它们各自的服务条款和隐私政策决定。DeepSeek GUI 本身不经手、不中转这些数据。

4. 诊断日志

DeepSeek GUI 在本机记录有限的运行日志，用于排查启动和运行问题。日志会对 API key、Bearer token 等凭据形态做脱敏处理，并限制历史日志数量和总大小。如果你向维护者提交日志，请自行检查其中是否包含项目路径或其他敏感信息。

5. 卸载与数据删除

卸载时会询问是否一并删除应用数据。选择保留后，重装可以继续使用已有的凭据、设置和会话。如需彻底清除本地数据，删除 %APPDATA%\DeepSeekGUI 目录即可。

6. 官网访问

DeepSeek GUI 官网托管在第三方平台上。访问网站时，托管服务可能处理标准 HTTP 元数据（IP 地址、User-Agent 等）用于正常提供页面和安全防护。我们不投放广告，不做用户画像，不进行跨站追踪。如果未来加入在线服务或分析功能，我们会在启用前更新本页并说明用途。

不允许基于 DeepSeek GUI 产品层构建与之竞争的替代产品——无论是软件、服务还是其他形式，无论是否收费。如需此类用途，请联系 See-Sol-Lab 获取商业许可。

7.3 上游代码

DeepSeek Harness 的上游代码继续遵循 DeepSeek 的 MIT 许可，不受上述限制。完整的许可说明请参阅仓库中的 DEEPSEEKGUI-LICENSE.md。

DeepSeek GUI 是 See-Sol-Lab 构建的 DeepSeek Harness 非官方社区产品，与 DeepSeek 无隶属关系，也未获其背书。Harness 和官方 Web UI 属于 DeepSeek。

隐私、安全或许可相关问题，请通过 GitHub 联系我们。涉及敏感漏洞时，请优先使用仓库的安全联系方式，而非公开 issue。
