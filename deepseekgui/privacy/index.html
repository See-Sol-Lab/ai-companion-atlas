隐私政策

最后更新：2026 年 10 月 5 日。DeepSeek GUI 在本机运行并保存应用数据；模型请求、可选反馈和官网访问的数据处理分别说明如下。

1. 本地数据与主动发送

DeepSeek GUI 的会话、凭据和配置默认保存在本机。See-Sol-Lab 不提供聊天记录托管服务。正常模型请求会发送给你选择的服务商；你主动提交反馈或启用开发者模式时，也可能发送相应内容。

2. 本地数据存储

DeepSeek GUI 把运行数据保存在你设备上的 %APPDATA%\DeepSeekGUI\dsh 目录中，包括 API 凭据、会话记录、模型配置、Profiles 和桌面偏好设置。这些数据完全由你控制。

API 凭据由 Harness 的凭据机制保存在应用自己的数据目录中，不会进入安装包、命令行参数或诊断日志。请妥善保管你的 API key，不要将其提交到 GitHub issue 或其他公开渠道。

3. 第三方模型服务

当你使用 DeepSeek 或其他模型服务时，你的请求内容会发送到你自己选择的服务商。这些第三方如何处理数据，由它们各自的服务条款和隐私政策决定。DeepSeek GUI 本身不经手、不中转这些数据。

4. 诊断日志

v1.2.0 的开发者模式默认关闭额外会话日志、插件清单和反馈会话上报；关闭时反馈可以记录在本机。启用开发者模式后采用官方相应上报行为，可能上传此前的会话记录，切换前会确认并重启 Harness。通过「BUG 诊断与反馈」提交问题时，发送前可检查内容。

DeepSeek GUI 在本机记录有限的运行日志，用于排查启动和运行问题。日志会对 API key、Bearer token 等凭据形态做脱敏处理，并限制历史日志数量和总大小。如果你向维护者提交日志，请自行检查其中是否包含项目路径或其他敏感信息。

5. 卸载与数据删除

卸载时会询问是否删除应用数据。v1.2.0 即使选择删除，也保留全局记忆与全局 AGENTS.md；项目记忆仍在项目文件夹中。迁移过的数据目录需分别核对，删除前请确认需要保留的内容。

6. 官网访问

官网服务器会处理访问请求的 HTTP 元数据，用于提供页面、安全防护与下载统计。安装包下载统计按请求和传输量汇总，不等同于实际安装人数；官网也使用 Cloudflare Web Analytics 汇总访问情况。

DeepSeek Harness 的上游代码继续遵循 DeepSeek 的 MIT 许可，不受上述限制。完整的许可说明请参阅仓库中的 DEEPSEEKGUI-LICENSE.md。
