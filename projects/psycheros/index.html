PROJECT INTRO

项目介绍

Psycheros 通过 entity-core MCP 服务保存 self、user、relationship 等第一人称身份文件，并把每日记忆汇总为周、月、年层级。

同一实体可被多个 MCP 前端调用，也能通过 entity-loom 把 ChatGPT、Claude、SillyTavern、Letta 等聊天历史转换为导入包，并用 Pulse 自主触发行动。

  • 适合：希望同一 AI 实体跨多个前端与身体维持身份连续的人。
  • 平台：Deno、MCP 与多种兼容客户端。
  • 使用方式：部署 entity-core，初始化身份文件并连接所需 Embodiment。
  • 许可：源码公开；具体条款见项目 LICENSE。
