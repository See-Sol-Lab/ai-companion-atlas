Proactive Web Surf Agent

@HUIHUI191

让伴侣闲下来时发现新网页，挑一件想与你分享的见闻。

项目从公开来源收集有限的候选网页，让已接入的 Agent 选择一项并组织分享消息，再由宿主发送。它需要现有模型和消息通道，不是独立伴侣应用。

项目地址（可复制给 AI）：https://github.com/huihui191/proactive-web-surf-agent

PROJECT INTRO

项目介绍

引擎提供公开网页发现、URL 去重、近期分享记录、白天随机调度、失败延后和可选配图。示例使用 GitHub 与 Hacker News 来源，模型如何选择和如何发送消息由使用者接入。

需要 Node.js 20+。截至本次核对，README 所写 npm 包安装入口返回 404，应从源码构建后接入现有 Agent。Telegram、Discord、邮件或自建界面只是可实现的投递通道，不表示已经内置可直接使用的完整连接。

  • 适合：已有伴侣或 Agent，希望增加低频网页探索与个人化分享的人。
  • 平台：Node.js 20+；需现有模型和消息发送通道。
  • 使用方式：获取源码、安装依赖并构建，实现 selector 与 delivery 回调后运行调度。
  • 许可：MIT；仅访问公开资源，模型调用和发送服务的费用由接入方承担。
