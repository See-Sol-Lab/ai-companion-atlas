PROJECT INTRO

项目介绍

LumiMuse 支持创建角色并设置性格、背景、开场白、示例对话和生图标签，在聊天中抽取关于用户、关系与共同经历的长期记忆。它还提供现实时间注入、原生生图和数据导入导出。

项目可在本地用 Node.js 运行，也支持 Docker Compose；数据保存在 SQLite 与本地文件中，便于备份和迁移。

  • 适合：想要好看、安静、能长期自托管的角色陪伴网页的人。
  • 平台：现代 PC 浏览器与自托管服务器。
  • 使用方式：本地运行或 Docker 部署，首次进入后配置模型和生图服务。
  • 许可：MIT。
