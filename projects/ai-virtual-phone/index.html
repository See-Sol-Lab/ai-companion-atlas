PROJECT INTRO

项目介绍

AI Virtual Phone 是一个可自托管的浏览器虚拟手机。它支持私聊、群聊、朋友圈、语音消息、转账卡片、角色作息与长期关系，也提供世界书、预设、剧情模式、视觉小说、地图冒险、日记和便签墙。

项目还包含应用市场 SDK、游戏大厅、生图、语音、音乐、3D 世界和主题美化。用户自备 LLM 与可选多媒体服务的 API Key；开启自托管模式后无需账号和激活码即可在本机使用。

  • 适合：希望用虚拟手机承载多角色关系、社交动态、剧情和共同游戏的人。
  • 平台：现代浏览器与 PWA；本地或 Netlify/Vercel 部署。
  • 使用方式：启动项目、开启 self-hosted 模式，在设置中添加模型并创建或导入角色卡。
  • 许可：AGPL-3.0-only。
