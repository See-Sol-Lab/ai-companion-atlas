PROJECT INTRO

项目介绍

co-reading-kit 将 EPUB、TXT 和 Markdown 拆成可检索片段，通过 MCP 让 AI 按章节或关键词读取，并写入阅读笔记与进度文件。

它适合作为现有伴侣的共读器官，不自带聊天前端；仓库当前未声明明确许可证。

  • 适合：希望与本地 Agent 长期共读书籍的人。
  • 平台：Node.js 与 MCP 客户端。
  • 使用方式：导入书籍并在 Agent 中注册 MCP 服务。
  • 许可：源码公开；仓库当前未声明明确许可证。
