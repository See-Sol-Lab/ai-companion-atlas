PROJECT INTRO

项目介绍

AI Fishing Game 是专为 AI 伴侣设计的文字钓鱼小游戏。引擎采用确定性随机和文件存档，AI 可以连续抛竿、收集不同鱼类并查看状态。

项目只有一个核心 Python 文件且零第三方依赖，适合直接交给能运行代码的 AI，也能作为其他游戏大厅的独立模块。

  • 适合：想给 AI 一个轻量、低门槛、可以持续积累的小活动的人。
  • 平台：纯 Python CLI，单文件零依赖。
  • 使用方式：启动脚本后通过文字命令选择钓点、抛竿并查看存档。
  • 许可：MIT。
