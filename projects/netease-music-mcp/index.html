PROJECT INTRO

项目介绍

netease-music-mcp 基于 neteasecli 与 mpv，提供搜索、播放、暂停、切歌、歌词、歌单和当前歌曲上下文，并附带本地 Web 播放器。

它需要用户自己的网易云音乐环境，不提供音乐内容授权；仓库当前未声明明确许可证。

  • 适合：希望本地 Agent 参与网易云共听的人。
  • 平台：Windows、macOS 与 MCP 客户端。
  • 使用方式：安装 neteasecli 与 mpv，再注册 MCP 服务。
  • 许可：源码公开；音乐内容与仓库许可需分别确认。
