PROJECT INTRO

项目介绍

fount 不是单个 AI 角色，也不是模型服务，而是一座用来创建和运行 AI 角色的工作室。连接模型 API 后，你可以创建或导入角色，再配置人格、世界观、行为逻辑和可以使用的工具。

做好后的角色可以留在 fount 中聊天，也能接入手机、浏览器、Telegram、Discord、IDE 和终端。跨平台只是角色的不同入口；这个项目真正解决的是怎样深度定制并长期使用自己的 AI 角色。

  • 适合：愿意花时间深度定制角色，希望人格不只停留在一段提示词里的人。
  • 平台：Windows、macOS、Linux、Android 与 Docker。
  • 使用方式：安装 fount，连接模型 API，再创建或导入角色并配置所需部件。
  • 使用门槛：功能很多，需要一定学习和代码基础；只想立即聊天的人会觉得复杂。
  • 许可：源码公开；具体许可条款见项目 LICENSE。
