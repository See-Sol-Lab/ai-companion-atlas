PROJECT INTRO

项目介绍

MIRA 以一条永久会话维持连续性：旧段落折叠成带绝对时间的第一人称记忆，离散记忆按访问、链接与时间相关性衰减，并在响应前自动检索。

系统还包含元认知观察、可进化的用户行为模型、可自动发现的工具、稳定加密文档和本地 Web Chat。安装依赖 PostgreSQL、Valkey 与 Vault，整体部署门槛高于普通记忆插件。

  • 适合：希望自托管完整连续数字实体，而非只接一个记忆 API 的用户。
  • 平台：macOS、Linux、Docker 与本地 Web。
  • 使用方式：运行部署脚本或 Docker，配置模型、数据库和凭据服务。
  • 许可：AGPL-3.0。
