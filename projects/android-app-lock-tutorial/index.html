PROJECT INTRO

项目介绍

教程从自用聊天前端中整理应用内隐私保护方法，包括 PIN 验证、超时与熄屏策略、可选系统指纹、自定义最近任务保护页和防截屏开关。它说明 Activity 生命周期与任务快照之间的时序问题，并提供参考片段。

这是一份需要接入应用代码的教程。作者明确列出弹框时误贴遮罩、部分回前台路径可能闪出真实内容等局限；验证主要来自特定 Android 设备，不保证所有 ROM。应用锁也不等同于加密聊天存储。

  • 适合：希望减少伴侣聊天在手机界面上被旁人看到的 Android 前端开发者。
  • 使用方式：按教程接入 Activity 生命周期、验证与遮罩逻辑，并在目标设备验证切换、弹框和熄屏行为。
  • 局限：存在已知内容闪现与机型差异；不防 root、ADB，也不提供独立可安装应用。
