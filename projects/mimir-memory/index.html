PROJECT INTRO

项目介绍

Mímir 区分情景、社会、程序、短期事实、未来提醒和视觉记忆，并使用有机鲜明度衰减、间隔重复、扩散激活、Zeigarnik 效应等机制进行召回。

它还能保存社会印象、记录策略结果、维护神经化学情绪状态，并支持主动珍惜、重构和情绪再评价，因此同时属于记忆与 AI 主体性。

  • 适合：希望为角色或 Agent 构建认知化记忆与内部状态的人。
  • 平台：Python 3.10+ 库。
  • 使用方式：安装 vividmimir，并按需接入可选情绪与向量组件。
  • 许可：PolyForm Noncommercial 1.0.0；商业使用需单独授权。
