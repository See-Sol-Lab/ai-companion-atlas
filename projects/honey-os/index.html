PROJECT INTRO

项目介绍

HoneyOS 是一个可以在自己电脑上运行的 AI 伴侣。它会分别保存自己的名字和性格、你们的关系、共同经历和没有做完的事，换窗口、重启或换模型后也能继续接上。

它不只会聊天，也能搜索资料、写代码和使用各种工具。本地网页、微信和飞书可以连接同一个 TA。数据主要保存在你的电脑上；使用在线模型时，必要的对话内容仍会发送给你选择的模型服务。

  • 适合：想要一个既能长期陪伴，又能真正使用工具完成任务的 TA。
  • 记得：保存 TA 的身份、你们的关系、共同经历和没有做完的事。
  • 能做：搜索资料、写代码、使用 Skill 和 MCP，也能创建本地项目。
  • 项目来源：基于 Hermes Agent 改造，重点是让会做事的 Agent 也能保持长期伴侣关系。
