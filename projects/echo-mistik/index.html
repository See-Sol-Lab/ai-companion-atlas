PROJECT INTRO

项目介绍

Echo Mistik 是私人 Mistik 架构的公开简化版本，以本地记忆、工具、持久状态、共享价值和反思 Dream 笔记维持长期伴侣。

项目作为 Python Web App 在本地运行，提供赛博朋克界面。许可与商业授权分开，Atlas 按非商业项目标注。

  • 适合：希望使用轻量、本地、偏反思型 Web 伴侣的人。
  • 平台：Windows、macOS、Linux 与本地浏览器。
  • 使用方式：启动 Python Web App，配置模型 Key 和 Persona。
  • 许可：非商业使用；商业授权需按项目文件另行取得。
