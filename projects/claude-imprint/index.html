项目介绍

Claude Imprint 整合持久记忆、语义检索、Telegram、claude.ai、Claude Code 多通道、定时任务和单文件面板。

记忆核心使用独立的 imprint-memory 项目，完整系统更偏常驻陪伴入口。

  • 适合：希望自托管多通道 Claude 伴侣的人。
  • 平台：Windows、macOS 与 VPS。
  • 使用方式：按 README 部署服务并连接所需通道。
