PROJECT INTRO

项目介绍

CosyVoice 支持多语言和跨语言语音生成、零样本音色复刻、指令式语音控制与流式输出，并提供训练、推理和部署工具。

伴侣系统可将它部署为本地或服务器 TTS 后端，用于通话、语音消息和朗读等持续声音输出。

  • 适合：需要多语言、低延迟和可训练 TTS 后端的伴侣项目。
  • 平台：Python 与 GPU 自托管环境。
  • 使用方式：下载预训练模型，运行 WebUI、推理脚本或服务接口。
  • 许可：Apache-2.0。
