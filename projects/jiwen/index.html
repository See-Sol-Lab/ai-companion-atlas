积温

JIWEN · @CLARASHAFIQ

让“想不想先开口”来自持续状态，而不是一次随机骰子。

积温是一个约 500 行的 JavaScript 状态引擎。它不写回复、不存记忆、不调用模型，只根据时间和事件推进角色状态，在达到阈值时输出联系、观察或自我调节信号。

PROJECT INTRO

项目介绍

积温通过 connection、pride、valence、arousal 和 immersion 五个连续轴，描述角色在等待、被回应、低落或沉浸于活动时的状态变化。每次 tick 只推进数学状态，达到阈值后才返回 contact、observation 或 find_activity。

项目提供自然语言状态描述、语气指引、调参模拟器、九类情绪语调网格和测试。开发者可以把它接到任意聊天、推送或心跳系统中，再由自己的模型生成具体行动和台词。

  • 适合：正在开发主动伴侣、角色状态机或需要可解释触发逻辑的人。
  • 平台：纯 JavaScript，零外部依赖，可接入任意宿主。
  • 使用方式：创建角色实例，周期调用 tick，并把返回状态转换成模型上下文或行动。
  • 许可：MIT。
