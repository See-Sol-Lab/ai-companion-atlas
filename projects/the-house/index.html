PROJECT INTRO

项目介绍

the-house 支持 Claude 和任意 OpenAI 兼容接口，可创建多个独立会话窗口、设置角色提示词、调整请求参数、发送图片并连接 MCP 服务。历史、设置和记忆均保存在本机浏览器中。

项目不需要服务器，双击 HTML 即可运行，也能部署到静态站点。仓库当前没有声明明确的开源许可证，因此公开源码不等同于获得修改和再分发授权。

  • 适合：希望用最少部署步骤获得独立 PC 聊天前端的人。
  • 平台：PC 现代浏览器。
  • 使用方式：打开单个 HTML，在设置中填写模型 API 与可选 MCP 地址。
  • 许可：源码公开；仓库当前未声明明确许可证。
