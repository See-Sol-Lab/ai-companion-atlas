PROJECT INTRO

项目介绍

SVAKOM BLE AI 是一份从零逆向蓝牙协议并搭建 AI 控制系统的完整教程。它记录 SL278H 的服务与特征、命令帧、持续发送机制和实测方法，并提供 Android Chrome Web Bluetooth 与跨平台 Python 两种 BLE 中继。

项目还描述 Railway 中继、隐藏控制指令和 Claude.ai MCP 接入。使用时必须避开固件 OTA 写入通道、保护远程 secret，并先以低强度和短时命令验证。当前仓库未声明开源许可证，因此公开源码不等同于获得修改或再分发授权。

  • 适合：持有 SVAKOM SL278H 或愿意自行验证相近 BLE 设备协议的人。
  • 平台：Android Chrome Web Bluetooth，或 Windows/macOS/Linux Python 中继；可配 Railway 与 MCP。
  • 使用方式：先用 nRF Connect 和测试脚本确认通道与命令，再选择手机或电脑中继接入 AI。
  • 许可：仓库未声明许可证；默认只能按公开资料阅读和验证，复用前需取得作者许可。
