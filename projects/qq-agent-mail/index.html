PROJECT INTRO

项目介绍

QQ Agent 邮箱是腾讯 QQ 提供的 Agent 邮箱服务，为 AI 建立独立邮件入口。

它代表 AI 自己的外部身份和通信资产；注册条件、开放范围与数据处理方式以官方页面为准。

  • 适合：希望 Agent 使用独立 QQ 邮箱参与外部通信的人。
  • 平台：腾讯 QQ 云端服务。
  • 使用方式：通过官方页面申请并配置 Agent 访问。
  • 许可：官方服务，遵守腾讯服务条款与隐私政策。
