PROJECT INTRO

项目介绍

Eros Engine 以 Rust 实现持久记忆、演化关系状态、结构化用户洞察和人格决策，让角色在长对话中保持一致。

项目面向集成方提供内核能力，需要自行连接模型与前端。

  • 适合：需要高性能关系与人格内核的伴侣开发者。
  • 平台：Rust 库与自托管服务。
  • 使用方式：接入现有 Agent 流程并提供模型、存储和界面。
  • 许可：AGPL-3.0-only；商业授权需另行联系。
