TeleMem

LONG-TERM MULTIMODAL MEMORY · @TELEAI-UAGI

以一行替换 Mem0，获得去重、长期对话和多模态视频记忆。

TeleMem 面向复杂多轮场景提供可直接替换 Mem0 的记忆层，减少重复写入，并把文本与视频信息纳入统一长期检索。

PROJECT INTRO

项目介绍

TeleMem 可通过 import telemem as mem0 作为 Mem0 的替代层，提供语义去重、长期对话记忆、角色建模、混合检索和多模态视频理解。

它更适合应用开发与研究场景，是通用记忆组件而非完整伴侣系统，因此只标记忆。

  • 适合：需要 Mem0 兼容、高性能和多模态记忆层的开发者。
  • 平台：Python、自托管服务与 MCP。
  • 使用方式：按兼容 API 接入现有应用，并配置存储与模型。
  • 许可：Apache-2.0。
