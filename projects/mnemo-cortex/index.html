PROJECT INTRO

项目介绍

Mnemo Cortex 将记忆分为优先召回的 Smart Notes 与完整 Session Logs，支持语义搜索、事实核验、夜间 Dream 整合、规则守护与 MCP/REST 接口。

Smart Notes 可分类为身份、关系、决策等内容，并支持加密 USB 同步和多模型接入。它不是完整人格系统，但其主动整合与身份记忆足以同时标记 AI 主体性。

  • 适合：需要跨 Claude、ChatGPT 与本地模型共享主动记忆的人。
  • 平台：Python 自托管、MCP 与 REST。
  • 使用方式：部署 sidecar，连接 Agent，并按需启用 Dream 与加密同步。
  • 许可：MIT。
