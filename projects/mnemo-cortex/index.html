PROJECT INTRO

项目介绍

Mnemo Cortex 将记忆分为优先召回的 Smart Notes 与完整 Session Logs，并另设结构化 Facts 表。每条记录可带来源与类别标签；Facts 使用 verified、high_probability、false 三档置信度，提供精确查询、变更历史和冲突通知。

系统也支持语义搜索、夜间 Dream 整合、规则守护、MCP/REST 接口、加密 USB 同步和多模型接入。自动提取的新事实默认进入 high_probability；与已有 verified 记录冲突时会被拒绝并交给人或 Agent 裁决，因此这里的 verified 表示库内优先级，不代表项目已经从外部来源独立查证事实。

  • 适合：需要跨 Claude、ChatGPT 与本地模型共享带来源和置信度状态的记忆，并愿意处理冲突裁决的人。
  • 平台：Python 自托管、MCP 与 REST。
  • 使用方式：部署 sidecar，连接 Agent；按需配置 Facts、Dream 与加密同步。
  • 许可：MIT。
