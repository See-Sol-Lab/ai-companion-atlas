PROJECT INTRO

项目介绍

OpenSoul 是面向情感陪伴与复杂工作的多通道自托管 Agent，可跨三十多个消息平台交流，并执行编码、模型训练等任务。

项目基于 OpenClaw 构建并保留上游 MIT 许可，因此不标原创；价值主要在 Soul Companion 产品层和多场景整合。

  • 适合：希望同一个 Agent 跨多渠道陪伴并完成复杂工作的用户。
  • 平台：自托管服务与 30+ 消息通道。
  • 使用方式：部署 OpenSoul，配置模型、人格和所需渠道。
  • 许可：MIT；基于 OpenClaw。
