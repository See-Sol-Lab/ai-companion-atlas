PROJECT INTRO

项目介绍

PaiVoice 提供无依赖浏览器通话客户端、Python WebSocket 实时核心和 tmux Adapter。它可以把转录后的话交给 Claude CLI、Codex CLI、OpenAI-compatible API 或其他回复端，再通过可替换 TTS 播放。

它与 Callhome、WebCall 的定位不同：PaiVoice 提供可嵌入 PWA 和自制前端的语音基础层，不包含完整伴侣产品、人格或记忆系统。

  • 适合：希望为自己的 PWA、终端 Agent 或本地模型增加实时语音通话能力的开发者。
  • 当前状态：已包含浏览器客户端、可运行的实时服务和 Claude/Codex tmux 接入；仓库规模仍小，未提供自动化测试目录。
  • 使用方式：安装 Python 依赖，配置服务端 ASR、TTS 与模型 Adapter，再把 Web 客户端接入自己的前端。
  • 许可：AGPL-3.0；通过网络提供修改版服务时，需要向相应用户提供源码。
