PROJECT INTRO

项目介绍

麦当劳中国官方 MCP 提供菜单浏览、优惠券查询、积分兑换和外卖下单能力。

它可用于伴侣协助点餐；任何订单与支付都应在最终步骤由用户确认。

  • 适合：希望 AI 协助现实点餐的麦当劳用户。
  • 平台：官方云端 MCP。
  • 使用方式：按官方文档连接，登录并在交易前人工确认。
  • 许可：官方服务，遵守麦当劳中国服务条款。
