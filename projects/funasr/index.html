PROJECT INTRO

项目介绍

FunASR 提供语音识别训练与推理、流式 ASR、语音活动检测、标点恢复和说话人分离，并可封装为 OpenAI 兼容或 MCP 服务。

伴侣系统可以用它处理实时麦克风、语音消息和多人环境中的转写，再把带时间与说话人信息的文本交给对话模型。

  • 适合：需要中文友好、可自托管完整语音识别管线的项目。
  • 平台：Python，自托管 CPU/GPU 环境。
  • 使用方式：按任务选择模型，组合 ASR、VAD、标点和说话人模块。
  • 许可：工具包代码为 MIT；预训练权重许可按各模型卡分别确认。
