PROJECT INTRO

项目介绍

LingChat 支持独立存档和永久记忆、自研情绪识别、动态表情动作、角色服装与触摸互动、VITS 语音、多角色剧本和羁绊系统，并内置番茄钟、日程和待办。

桌宠模式可以观察桌面工作、游戏或挂机状态，并据此主动发起对话。项目提供 Windows 安装包，也开放 Tauri 前端源码。

  • 适合：偏爱 Galgame 演出、桌宠和强视觉角色陪伴的 Windows 用户。
  • 平台：Windows 10 64 位及以上。
  • 使用方式：从 Releases 下载程序，首次启动后配置自己的模型 API。
  • 许可：AGPL-3.0。
