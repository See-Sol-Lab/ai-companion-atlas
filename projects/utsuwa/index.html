PROJECT INTRO

项目介绍

Utsuwa 是 Grok Companion 的开源替代，角色会从互动中学习成长，并可选择启用受日式恋爱模拟启发的关系机制。

项目提供 Web 平台和自托管路径，当前采用 AGPL-3.0-or-later；0.12.0 及更早版本仍保持 MIT。

  • 适合：希望自托管可成长 AI Waifu 与关系机制的用户。
  • 平台：Web 与自托管环境。
  • 使用方式：部署平台，配置模型和角色成长设置。
  • 许可：当前 AGPL-3.0-or-later；旧版本许可按发布时条款。
