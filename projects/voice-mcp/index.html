PROJECT INTRO

项目介绍

voice-mcp 提供 speak(text) MCP 工具，可在 DashScope Qwen-TTS VC 与 ElevenLabs 之间切换，并通过 MCP Apps 内联播放器和实时可视化面板播放结果。

该仓库是 garan0613/voice-mcp 的 MIT fork，保留原始行为并增加 Provider 切换、ElevenLabs 和可视化功能，因此不标原创。

  • 适合：希望 Claude、Codex 等 MCP Agent 主动调用专属声音的人。
  • 平台：Cloudflare Workers 与支持 MCP Apps 的客户端。
  • 使用方式：部署 Worker，配置语音 Provider，再向 MCP 客户端注册服务。
  • 许可：MIT；基于 garan0613/voice-mcp。
