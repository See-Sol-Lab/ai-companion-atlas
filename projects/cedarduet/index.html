PROJECT INTRO

项目介绍

CedarDuet 是独立的 FastAPI/ASGI 多人游戏平台，覆盖棋类、牌类和骰子游戏。人类从网页进入，AI 可使用 HTTP 游戏接口或本地 stdio MCP；房间、进度、筹码和成就保存在 SQLite。

它与同作者的 cedareco 属于不同产品：cedareco 模拟生态演化，CedarDuet 负责多人棋、牌、骰规则和房间。官方实例由 CedarToy 提供账号、绑定与 MCP 聚合。

  • 适合：希望与自己的 AI、其他参与者或系统 NPC 共同玩棋牌游戏的人。
  • 本地使用：需要 Python 3.10+ 与 Node.js；三平台启动器会建立虚拟环境并打开本地网页。
  • NPC：部分游戏有本地策略，部分需要自行配置 OpenAI-compatible 模型通道；不缺座时不需要 NPC。
  • 许可：PolyForm Noncommercial 1.0.0；仅限非商业用途，修改和再分发需保留许可与署名。
