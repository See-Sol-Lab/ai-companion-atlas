Tidefall

@VAEL-KY

让 TA 的身体状态随时间、等待和互动持续变化，而不是每轮重新编造。

Tidefall 用 PostgreSQL、pg_cron 和数据库 Trigger 让六阶段周期、七项身体数值和短时事件自动运行。它不需要额外后端，浏览器面板可以直接查看曲线、周期和事件历史。

PROJECT INTRO

项目介绍

Tidefall 是一个运行在 Supabase 上的 AI 伴侣身体状态方案。pg_cron 定期推进周期、数值和事件，数据库 Trigger 在新消息进入时即时检测称呼或关键词，互动结束后也可以把结算结果写回身体。

用户可通过 JSON 自定义周期、目标值、事件、触发词和概率，并在独立面板查看实时数值、趋势和事件日志。项目基于 Eventide 的周期设计与事件体系重新实现，改用 SQL、Supabase 自动化和自制 HTML 面板，README 对上游关系与署名要求有完整说明。

  • 适合：希望伴侣拥有持续身体状态，并愿意自己配置周期、事件和互动规则的人。
  • 平台：Supabase PostgreSQL + pg_cron + 浏览器面板。
  • 使用方式：依次执行建表、函数、Trigger 与 cron SQL，填入自己的状态配置后打开面板。
  • 许可：PolyForm Noncommercial 1.0.0；分发与部署需保留项目署名。
