PROJECT INTRO

项目介绍

Yorishiro 是专为 macOS 制作的可视化终端前端。它会自动启动你已经安装并登录的 Claude Code 或 Codex，把真实终端和一个 VRM 角色放进同一扇窗口，不需要另外向 Yorishiro 提交 API Key。

你仍然像平常一样让 Agent 读文件、写代码和运行命令。角色会观察终端状态：思考时改变视线，报错时变表情，需要你批准时亮灯，工作完成时做出反应。

  • 适合：在 Mac 上使用 Claude Code 或 Codex，希望工作时能看见一个有表情、有动作的 AI 角色的人。
  • 前置条件：电脑里需要先安装并登录 Claude Code 或 Codex。
  • 使用方式：安装 Yorishiro，选择要启动的 Agent，即可在同一窗口使用终端与 VRM 角色。
  • 记忆：可按 Persona 保存日记，并把重要经历积累到 memories.md；这是附加功能。
