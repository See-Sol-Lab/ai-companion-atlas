PROJECT INTRO

项目介绍

Yorishiro 是包裹真实 PTY 的桌面空间，可观察终端状态、显示等待审批的灯光、响应成功事件，并共享声音摘要与终端上下文。

每个 Persona 能写日记并在 memories.md 中积累重要时刻，后续会话会偶尔回忆数日甚至数月前的内容。

  • 适合：希望为终端 Agent 增加具身空间和长期日记的人。
  • 平台：桌面系统与终端环境。
  • 使用方式：安装应用，连接 Agent PTY 并配置 Persona 与 Journal。
  • 许可：MIT。
