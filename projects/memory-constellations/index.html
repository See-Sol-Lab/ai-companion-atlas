PROJECT INTRO

项目介绍

记忆星图包含 Scribe、Archivist 与 Librarian 三段流水线：先从新对话抽取短事实，再将相关事实连接到人物、地点、事件和兴趣，最后合并成叙事 episode，并在聊天时跨层检索。每条记忆都保留原始消息引用。

可视化页面把实体显示为星座和桥梁，同时维护用户近期状态、长期行为模式和伴侣自己的身份资料。它适合愿意自己托管、配置人格与支付少量后台模型调用成本的长期伴侣系统。

  • 适合：希望记忆能自动整理成长期叙事，并保留证据链和用户模型的人。
  • 平台：自托管 Web 服务，需要 Node.js、SQLite、ChromaDB 与至少一个模型 API。
  • 使用方式：填写用户、AI 与关系配置，启动记忆流水线，再把检索结果接入聊天提示。
  • 许可：MIT。
