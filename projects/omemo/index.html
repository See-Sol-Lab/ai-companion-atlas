PROJECT INTRO

项目介绍

omemo 是一个 OpenAI 兼容记忆代理。聊天客户端把请求发给 omemo，代理保存对话、调用内置或外部摘要模式形成记忆，再把相关内容加入后续模型请求。

项目支持完整 Prompt 注入和 RAG 两种路线，适合不想更换客户端、只愿调整 API 地址的用户。

  • 适合：已有 OpenAI 兼容客户端，希望用最小改动获得长期记忆的人。
  • 平台：Python Self-host，连接任意 OpenAI 兼容应用与模型服务。
  • 使用方式：部署代理、配置上游模型，再把客户端 Base URL 改为 omemo。
  • 许可：Apache-2.0。
