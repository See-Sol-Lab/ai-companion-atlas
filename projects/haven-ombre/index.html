PROJECT INTRO

项目介绍

Haven-Ombre 是一套以 Markdown 记忆桶为长期真源、同时提供 MCP 与聊天 Gateway 的个人连续性系统。它把原始对话、长期记忆、短期状态和画像拆成不同层，并用保守召回、日期检索与关系图控制何时引用。

项目还增加跨窗口 handoff、自我入口、照顾备忘、Darkroom、Dream、自动写入门卫与 OpenAI/Anthropic 兼容 Gateway。它基于 P0luz/Ombre-Brain 二次开发，保留上游记忆桶、情绪坐标、遗忘曲线、向量检索与 Dashboard，并在 README 中完整说明新增范围。

  • 适合：已有长期伴侣资料，希望加强证据溯源、跨窗交接与画像分层的人。
  • 平台：自托管 Python 服务，支持 MCP 与 OpenAI/Anthropic 兼容聊天客户端。
  • 使用方式：部署 Brain；需要自动注入时再同时部署 Gateway，并配置独立的记忆与状态目录。
  • 许可：MIT；属于 Ombre-Brain 的独立扩展分支。
