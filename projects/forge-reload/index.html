PROJECT INTRO

项目介绍

Forge Reload 从本地 JSONL 中截取近期事件，重建 parent UUID 链，生成可 resume 的新 session，并可注入 AI 撰写的交接包。

它直接操作非公开会话格式，使用前必须备份；Claude Code 格式更新后也可能失效。

  • 适合：需要把长 Claude Code 会话迁移到新 session 的高级用户。
  • 平台：Claude Code 本地会话文件。
  • 使用方式：先完整备份，再按 README 生成并验证新 session。
  • 许可：MIT，非官方工具。
