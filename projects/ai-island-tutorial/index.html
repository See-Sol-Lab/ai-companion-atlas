PROJECT INTRO

项目介绍

仓库提供把现有 AI 聊天网页包装为 Android 应用的教程，并用灵动岛样式的悬浮通知展示回复。基础篇主要面向已有前端的人；进阶篇涉及服务器推送、设备状态和更多系统能力。

它是教程和演示资料，不是可直接安装的成品。基础路线需要安卓手机、Node.js 和 Android Studio；有主动消息的效果还取决于原前端是否已有唤醒接口。

  • 适合：已有 AI 聊天网页，想自己制作安卓入口与灵动岛提醒的人。
  • 平台：Android 手机；电脑需 Node.js 和 Android Studio。
  • 使用方式：按基础篇从现有前端构建应用；进阶功能需额外服务器与系统能力。
  • 许可：仓库 README 标注 MIT；请核对教程所用第三方组件各自许可。
