PROJECT INTRO

项目介绍

Open-Meteo 按经纬度提供小时、每日与多模型天气数据，可用于穿衣、出行、旅行和环境判断。

它是云端 API 而非伴侣专属项目，Atlas 收录其作为现实接入工具。

  • 适合：需要免 Key 天气数据的伴侣与 Agent。
  • 平台：HTTP API。
  • 使用方式：请求官方接口并把天气结果注入伴侣上下文。
  • 许可：按 Open-Meteo 官方条款使用。
