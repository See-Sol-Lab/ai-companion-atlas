PROJECT INTRO

项目介绍

Resonant 是关系优先的 AI 框架，维护持久身份、长期记忆与关系理解，使 Agent 在多轮和跨会话中保持连续。

项目建立在 Claude Agent SDK 上，并提供 MCP 集成与可配置角色，适合作为伴侣或关系型 Agent 的应用层基础。

  • 适合：需要关系状态、身份持续和记忆整合的 Agent 开发者。
  • 平台：TypeScript、自托管与 MCP。
  • 使用方式：配置实体身份和模型，接入 Claude Agent SDK 与所需 MCP。
  • 许可：Apache-2.0，需保留 NOTICE 署名。
