PROJECT INTRO

项目介绍

Shinsekai 面向 Galgame、乙女和剧情向 RPG，使用大模型驱动角色对白，并让立绘与情绪变化同步。它可配置 TTS、ASR、视觉、记忆、工具和插件，聊天窗口保持舞台式呈现。

项目支持本地设置和源码构建，提供 Windows 与 macOS 安装路径。它属于源码可见项目，允许查看和本地自用，但未经书面许可不得再分发、发布安装包或商业使用。

  • 适合：想制作或体验 AI 驱动视觉小说与角色剧情的人。
  • 平台：Windows 与 macOS 桌面环境。
  • 使用方式：按 README 安装桌面端，在 Settings 中配置模型与可选扩展。
  • 许可：源码可见；仅允许查看、本地构建自用和公开 fork 讨论，禁止未经授权再分发与商用。
