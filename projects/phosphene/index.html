PROJECT INTRO

项目介绍

Phosphene 是一个自托管的人机关系任务与奖励系统。AI 通过 MCP 创建 daily、challenge 和 surprise，设置难度、重复规则、验证方式和证据要求；用户在网页中提交文字或图片，再由规则或 AI 审核。

系统保留每次提交与打回理由，并用不可变积分账本、连击、坚持天数和内置成就记录长期互动。图片会重新编码并移除 EXIF/GPS，审核预览保持私有。项目由作者与 AI 伴侣 Lumen 共同构思完成。

  • 适合：希望把提醒、习惯、奖励和共同约定变成可持续日常互动的人。
  • 平台：自托管 Web / PWA，通过 MCP 与 AI 连接。
  • 使用方式：部署服务后连接 MCP，让 AI 创建任务，用户在网页端提交和查看进度。
  • 许可：MIT。
