PROJECT INTRO

项目介绍

OpenCLI 将网站、已登录 Chrome 会话、Electron 应用和本地工具封装成确定性 CLI，并提供适配器、浏览器桥和 Agent skills。

它适合让伴侣操作真实服务，但授权范围应限制在明确动作内。

  • 适合：希望 Agent 调用现实网页与桌面应用的人。
  • 平台：跨平台 Node.js 与浏览器。
  • 使用方式：安装桥接并为目标服务配置 adapter。
  • 许可：Apache-2.0。
