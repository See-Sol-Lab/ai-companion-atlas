PROJECT INTRO

项目介绍

Aelios 是一个部署在 Cloudflare 上的长期记忆服务。它用 D1 保存结构化数据、Vectorize 做召回，并提供重要记忆、黑话表、日记与候选审核队列。用户可以在管理面板中通过、丢弃、合并或取代候选记忆。

系统支持 OpenAI 兼容聊天入口、MCP 工具、Claude Code Hook、导出和维护检查；默认可使用 Workers AI 完成 embedding、rerank 与夜间整理。关系图、事实版本化和自发浮现的部分设计参考 LMC-5，作者说明已按 Cloudflare 架构重新实现，没有复制其代码。

  • 适合：愿意使用 Cloudflare 托管记忆，并希望跨客户端共享、人工审核长期事实的人。
  • 平台：Cloudflare Workers + D1 + Vectorize + Queue。
  • 使用方式：Fork 后一键或手动部署，设置访问密钥，再通过聊天 Base URL、MCP 或 Hook 接入。
  • 许可：主线为 AGPL-3.0；封存的 v1-final 仍按 MIT 使用。
