把外部事件和预约事项交给 Agent 的注意力调度层。

Wake Bridge 管理何时值得让 Agent 重新获得注意力，保存投递与回执证据。它本身不运行 Agent；能否唤醒具体会话取决于宿主适配器。

PROJECT INTRO

项目介绍

Wake Bridge 是面向 Agent 宿主的注意力调度核心。外部来源登记事件，Agent 设置个人策略和未来预约，系统再经过静默时段、在线状态等条件，将结构化唤醒信息交给已经登记的宿主适配器。

当前为预览版，支持单 Agent 本地部署，提供可选的 Claude CLI 在线会话适配器；其他宿主需自行实现并验证适配。它不提供聊天前端、记忆系统或任意桌面客户端的自动唤醒。

  • 适合：正在搭建 Agent 宿主、希望管理外部事件与未来注意力的人。
  • 平台：当前预览版支持 macOS arm64/x64 和带 systemd user service 的 Linux x64；需 Node.js 20+ 与 SQLite CLI。
  • 使用方式：安装 wake-bridge 预览版，并为目标会话配置或实现宿主适配器。
  • 许可：Apache-2.0；当前为预览版。
