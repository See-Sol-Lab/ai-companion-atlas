PROJECT INTRO

项目介绍

弯弯机是一套可直接在浏览器运行的静态 AI 伴侣应用。用户可配置角色与模型 API，把网站部署到 Netlify，也能直接下载文件后使用。

聊天、角色、设置与 API 配置主要保存在当前浏览器的本地存储中；项目支持数据导出导入和 PWA 安装，更换设备、域名或浏览器前需要先备份。

  • 适合：希望用静态网页快速部署私人 AI 伴侣入口的用户。
  • 平台：现代手机与电脑浏览器，可安装为 PWA。
  • 使用方式：Fork 后连接 Netlify 自动部署，或下载完整文件夹手动上传。
  • 许可：README 未声明软件许可；使用、修改与二次发布前需向作者确认授权边界。
