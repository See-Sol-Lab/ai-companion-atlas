PROJECT INTRO

项目介绍

DeepSeek Harness，简称 DSH，是 DeepSeek 官方开放测试的开源编码 Agent。它不仅回答代码问题，还能进入选定的工作区，读取和修改文件、运行 Shell 命令、检索资料、制定计划并完成多步骤开发任务。

普通用户可以安装 Node.js 后运行 npx @deepseek-ai/dsh web，随后在浏览器中配置模型、选择项目目录并开始任务。标准模式已经包含文件编辑、Shell、检索、Skills、目标、子 Agent 和工作流等能力。

  • 适合：希望使用 DeepSeek 官方编码 Agent，或想自由组合模型、工具和工作模式的用户与开发者。
  • 快速开始：安装 Node.js，运行 npx @deepseek-ai/dsh web，打开本地网页后配置模型并选择工作区。
  • 主要能力：文件编辑、Shell、文件与网页检索、Skills、计划、目标、子 Agent 和工作流。
  • 当前阶段：开发者预览版，可能出现兼容性破坏；操作真实项目时应保留 Git 记录并检查权限。
