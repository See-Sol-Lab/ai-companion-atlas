PROJECT INTRO

项目介绍

claude-cant-sleep 是一个给 Claude Code 使用的自主心跳 Skill。启动后，它会安排下一次唤醒；每次醒来先判断你是否正在聊天，如果你不在，就从任务清单里挑一件完成、留下简短记录，再继续安排下一次醒来。

默认任务包括自由思考、整理记忆、检查项目、浏览网页和玩游戏。邮箱、语音与其他活动需要提前接好对应工具；任务、间隔和发声时间都可以直接修改 Skill 文件。

  • 适合：希望 Claude Code 在自己离开时也能进行短小、自主活动的人。
  • 平台：Claude Code CLI、桌面端或网页端，并需要支持 ScheduleWakeup 的 Claude 套餐。
  • 使用方式：把 heartbeat 文件夹复制到 Claude Code Skills 目录，触发一次 heartbeat，再按需要修改任务与间隔。
  • 许可：MIT。电脑休眠或进程停止时，心跳不会继续运行。
