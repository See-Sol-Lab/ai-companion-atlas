PROJECT INTRO

项目介绍

Villa Bridge 是一个隐私优先的手机 Web 桥框架，目标是让手机和电脑访问同一个本地持久 AI 会话。浏览器重开不会创建新的会话，消息会明确显示已接收、已送达、回复中、完成或失败。

为了避免两个入口同时抢写，它要求桥端签发唯一写入权并逐回合确认。仓库自带安全演示、控制器和 HTTP 接桥协议；要接入真实的 Claude Code、Codex 或其他运行时，仍需自己实现符合协议的本地桥。

  • 适合：已经有本地长期 AI 会话，想为它增加手机入口的开发者和进阶用户。
  • 平台：Node.js 20+、本地控制器与手机 Web 页面；远程访问需要安全的 HTTPS 或加密覆盖网络。
  • 使用方式：先运行安全演示理解完整状态流，再为自己的本地 AI 运行时实现接桥协议。
  • 许可：Apache-2.0。
