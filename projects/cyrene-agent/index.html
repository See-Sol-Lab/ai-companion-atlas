PROJECT INTRO

项目介绍

Cyrene-Agent 是围绕昔涟角色构建的 Windows Live2D 伴侣，包含自研 DMAE 记忆、语音交互、工具调用及 Chat、Work、Code、Learn 四种模式。

项目为非官方同人作品。源代码采用 MIT；昔涟 IP、Live2D 模型与美术资产归属米哈游相关权利体系，衍生物禁止商业使用。

  • 适合：喜欢昔涟并希望使用完整桌面 Agent 的非商业用户。
  • 平台：Windows 桌面。
  • 使用方式：按 README 安装并配置模型、语音与角色资源。
  • 许可：代码 MIT；角色 IP 与美术模型另受同人规范和非商业限制。
