Ocean

COMPANION PWA · @FISHWITHOCTOPUS

把聊天、项目、共读和长期连续性放进同一个自托管空间。

Ocean 是一个 provider-neutral 的自托管伴侣空间。它把移动端 PWA 与服务端 Gateway 连接起来，让不同房间、项目、书籍和模型共享稳定的会话边界，同时保留使用量、通知和数据所有权。

PROJECT INTRO

项目介绍

Ocean 提供可安装的移动端 PWA 和自托管 Gateway，支持流式聊天、附件、按场景隔离的会话、项目工作区、共读、多模型会议、通知、音乐与自由时间安排。Session Forge 可以轮换物理会话，同时保留摘要和近期原文，让长对话不必永远挤在同一窗口。

模型密钥和私有连接器保存在服务端环境，浏览器只接收公开清单和标准化响应。长期记忆是可选的外接服务；项目 README 明确说明其 Memory 3.0 参考实现由 Ombre-Brain 衍生，并未嵌入 Ocean 主仓库。

  • 适合：希望自己托管伴侣入口，并把聊天、项目、阅读与通知放在同一空间的人。
  • 平台：现代浏览器与可安装 PWA；需要 Node.js 20+ 和 HTTPS 部署环境。
  • 使用方式：配置至少一家模型提供方，启动 Gateway 与前端；房间和外接服务可按需保留。
  • 许可：PolyForm Noncommercial 1.0.0，允许非商业使用、研究、修改与分发。
