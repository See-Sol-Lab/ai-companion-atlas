PROJECT INTRO

项目介绍

GPT-SoVITS 支持以短参考音频进行零样本 TTS，也能用约一分钟数据微调以提升音色相似度，并覆盖中文、粤语、英语、日语、韩语等跨语言合成。

项目提供数据切分、ASR 标注、训练、推理 WebUI 和 API，可在 Windows、Linux、macOS 或 Docker 中运行。

  • 适合：希望为自托管伴侣制作专属合成声线的人。
  • 平台：Windows、Linux、macOS 与 Docker；GPU 体验更好。
  • 使用方式：准备有权使用的参考音频，经切分标注后直接推理或微调模型。
  • 许可：MIT；声音素材和训练数据仍需拥有合法授权。
