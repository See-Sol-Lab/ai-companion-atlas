PROJECT INTRO

项目介绍

Codex 是 OpenAI 官方编码 Agent。用户选择一个项目或文件夹并描述目标后，它可以阅读代码、查找问题、编辑文件、运行命令和测试，再汇报完成了什么以及怎样验证。

普通用户可以从官方 Codex 页面了解并下载桌面产品；开发者也可以在终端使用 Codex CLI，或在 VS Code、Cursor、Windsurf、Xcode 与 JetBrains 等编辑器中使用相应集成。较长的任务还可以交给云端环境并行完成。

  • 适合：希望 AI 直接理解真实项目、修改文件、运行工具并交付可检查结果的人。
  • 使用入口：桌面应用、Codex CLI、IDE 扩展与 Codex 云端。
  • 使用方式：前往 OpenAI 官方 Codex 页面，选择合适的入口，下载安装或登录后打开项目并描述任务。
  • 权限边界：Codex 只在用户授予的文件、命令、网络和应用权限内工作；执行过程与改动可由用户审查。
