PROJECT INTRO

项目介绍

Ghost Vessel 是本地 Agent 的视频头像前端。它支持细粒度表情片段、随赞美或责备变化并缓慢回归的心境、眨眼和休息待机、语音输入输出，以及从真实 Agent 动态读取的斜杠命令菜单。

运行时只播放预渲染 MP4，因此无需实时 GPU 推理。仓库附带可直接使用的 2D 起始角色和制作工具链，用户也可以把任意 2D、3D 或抽象形象制成自己的表情包；另售的真人风格预设不包含在开源仓库中。

  • 适合：已有本地 Agent，希望增加常驻桌面身体、语音和关系情绪表现的人。
  • 平台：以 Windows 为主，可用浏览器播放器或 Tauri 桌面壳。
  • 使用方式：选择或制作头像预设，运行桥接与播放器，再连接 Hermes、OpenClaw 或自定义 Agent。
  • 许可：仓库引擎、工具、文档和起始角色均为 MIT；外部预设按各自许可。
