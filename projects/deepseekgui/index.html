PROJECT INTRO

项目介绍

DeepSeekGUI 是 See-Sol-Lab 制作的 Windows Agent 工作台。它把 DeepSeek Harness、Node.js 和 pnpm 一起装进桌面应用，不需要先研究命令行；连接模型、选择工作文件夹后就能开始使用。

Agent 可以查看与修改代码和文件、运行工具、读取图片、使用真实浏览器，也能管理 Harness Profile 和兼容插件。工作过程、权限请求和最终改动都会留在界面里，方便用户随时检查。

  • 适合：想在 Windows 上直接使用 DeepSeek Agent 编程、处理文件或完成工作任务的人。
  • 使用方式：下载安装包，打开设置连接 DeepSeek 模型，再选择一个工作文件夹开始会话。
  • 当前版本：V1 支持 Windows 10/11 x64；安装包尚未代码签名，运行前应按发布页说明核对 SHA-256。
  • 项目关系：这是基于 DeepSeek Harness 的非官方社区产品，与 DeepSeek 无隶属或背书关系。
