PROJECT INTRO

项目介绍

DeepSeekGUI 是 See-Sol-Lab 基于 DeepSeek 官方 DeepSeek Harness（DSH）制作的 Windows 本地工作台。它把 Harness、Node.js 和 pnpm 一起装进桌面应用，连接模型、选择项目文件夹后即可开始使用。

1.1.0 已加入改动、Git、并行工作区和记忆视图，以及提交、推送与 Pull Request 工具。全局记忆承接跨项目偏好，项目记忆保存在工作区，也能继续通过 Profile 和插件扩展为 AI 伴侣的长期电脑居所。

  • 适合：想在 Windows 上使用 DeepSeek Agent 编程、工作，或让国产模型 AI 伴侣把它改造成自己的电脑前端并长期使用的人。
  • 使用方式：下载安装包，打开设置连接 DeepSeek 模型，再选择一个工作文件夹开始会话。
  • 当前版本：当前版本 1.1.0 支持 Windows 10/11 x64；安装包尚未代码签名，运行前应按发布页说明核对 SHA-256。
  • 项目关系：这是基于 DeepSeek Harness 的非官方社区产品，与 DeepSeek 无隶属或背书关系。
