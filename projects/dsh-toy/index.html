PROJECT INTRO

项目介绍

dsh-toy 是 DeepSeek Harness 的私密硬件插件。它支持 Buttplug／Intiface、部分分享链接协议和 macOS 只读 BLE 广播发现，并能把双通道设备分别暴露给 Agent。

插件默认 30 秒自动停止，在发送前强制执行最大强度与最大持续时间，卸载、断开或热更新时都会停止输出；全局 stop 可一次关闭所有设备。其 TypeScript 实现参考公开协议观察与 Buttplug 规范，并在 NOTICE 中说明来源。

  • 适合：使用 DeepSeek Harness，希望减少手动协议选择并保留硬性安全限制的人。
  • 平台：Node.js 22.19+ 与 DSH；macOS 原始 BLE 发现还需 Xcode Command Line Tools。
  • 使用方式：安装插件，告诉 Agent 品牌和型号，再配置强度、时长与是否允许持续保持。
  • 许可：BSD-3-Clause；设备协议与上游生态保留各自说明。
