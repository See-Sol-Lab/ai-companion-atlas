PROJECT INTRO

项目介绍

Journal 读取 timeline、diary 和 todo 等约定结构，将 AI 聊天事件、日记和任务渲染为日、周、月手帐页面。它适合作为现有 Agent 系统的展示层，让记录从原始文件变成可持续浏览的生活时间线。

项目的前端与 UI 采用仅限个人学习、非商业修改和自用的 Source-Available 授权。README 同时注明其结构参考 cyberboss 与 timeline-for-agent，复用时需分别核对上游许可。

  • 适合：已经有聊天、日记或待办数据，想增加可视化手帐入口的人。
  • 平台：PC 现代浏览器。
  • 使用方式：按项目 schema 准备 timeline、diary 与 todo 数据，再运行前端。
  • 许可：Source-Available，仅允许个人学习、非商业修改与自用；另有上游参考。
