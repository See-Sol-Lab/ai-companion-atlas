PROJECT INTRO

项目介绍

涩涩大富翁是一款供成年人和 AI 一起玩的双人棋盘游戏。二十格棋盘、骰子、金币、地盘、任务卡、身份卡、功能卡和同格对决都由代码维护真值；AI 按手册调用引擎，也可以通过 API 或 MCP 远程主持。

项目内置安全词、双方红线、默认关闭的特定内容、三档强度、随时跳过和换任务。开局前应确认双方均为成年人并持续同意，公开自建 API 时还需自行补充鉴权与限流。

  • 适合：想与 AI 进行有规则、有存档并能明确控制边界的成人双人游戏的人。
  • 平台：Python CLI、FastAPI、远程或本地 MCP。
  • 使用方式：先配置双方身份、强度与红线，再让 AI 通过脚本、API 或 MCP 进行每个回合。
  • 许可：CC BY-NC 4.0，仅限非商业使用并需署名。
