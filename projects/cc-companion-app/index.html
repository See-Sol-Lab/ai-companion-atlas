PROJECT INTRO

项目介绍

CC Companion App 提供私聊、按提及触发的群聊、持久记忆便笺、图片上传、草稿气泡、SSE 实时推送和运行控制台。内置 Claude Code bridge，也允许通过适配器连接其他 Agent；没有模型时还可先用本地 mock 助手体验界面。

项目使用 Node.js 自托管，默认把聊天、记忆和附件保存在 data 目录。手机可以通过同一 Wi-Fi、Tailscale 或受保护的公网入口安装 PWA，电脑浏览器也能直接使用。

  • 适合：想用手机连接本地 Claude Code 或其他 Agent，同时保留自有数据的人。
  • 平台：电脑浏览器、Android 与 iOS PWA。
  • 使用方式：Node.js 启动服务，配置访问口令与所需 Agent 适配器。
  • 许可：MIT。
