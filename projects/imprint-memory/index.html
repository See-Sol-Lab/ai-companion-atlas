PROJECT INTRO

项目介绍

imprint-memory 是一个本地优先的持久对话记忆系统。它通过 Claude Code Hook、claude.ai 扩展和 Telegram 适配器捕获每轮对话，再用 FTS5 与语义向量进行混合检索。

项目提供 stdio／HTTP MCP、消息总线和任务队列，可作为 Claude Imprint 等上层伴侣系统的独立记忆核心。

  • 适合：同时使用 Claude Code、网页和 Telegram，希望统一保存与召回对话的人。
  • 平台：Python Self-host，支持 stdio 与 HTTP MCP。
  • 使用方式：部署记忆服务，再按入口安装 Hook、浏览器扩展或 Telegram 适配器。
  • 许可：仓库源码公开，具体复用与分发以项目声明为准。
