PROJECT INTRO

项目介绍

Coread 是一个让人和 AI 并肩读书的自托管网页。它支持 EPUB 导入、章节识别、统一坐标分页、划线、评论与回复、阅读进度、目录、离线缓存，以及带批注导出。

AI 通过 stdio、SSE 或 Streamable HTTP MCP 读取书页、添加评论和更新进度。用户的新批注还可以通过 tmux 注入或 webhook 主动推给 AI，让对方不必等到下一次翻书才看见。

  • 适合：想和 AI 一起读小说、非虚构或资料，并长期保留双方批注的人。
  • 平台：自托管 Web；需要 Node.js 和 SQLite。
  • 使用方式：导入 EPUB，在浏览器阅读，再将配套 MCP 服务接入 AI 客户端。
  • 许可：MIT。
