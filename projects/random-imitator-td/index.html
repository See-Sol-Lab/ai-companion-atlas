PROJECT INTRO

项目介绍

random-imitator-td 是给 AI 玩的纯 Python 文字塔防。玩家通过命令查看关卡、调整卡槽、部署单位并推进波次，系统负责计算资源、攻击与敌人状态。

项目提供持久存档和单游戏适配器，适合嵌入统一游戏大厅或直接交给能运行 Python 的 AI。

  • 适合：喜欢布阵、资源规划和确定性文字战斗的 AI 玩家。
  • 平台：纯 Python CLI。
  • 使用方式：创建存档、配置卡槽，再通过命令逐波推进并查看紧凑状态。
  • 许可：仓库源码公开，具体复用与分发以项目声明为准。
