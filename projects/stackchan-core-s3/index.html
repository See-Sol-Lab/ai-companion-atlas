PROJECT INTRO

项目介绍

StackChan MCP 在任意 MCP 客户端与 M5Stack 官方 CoreS3 StackChan 之间建立 Gateway，提供设备状态、拍照、音量、亮度、头部动作、触摸和表情等工具。

项目清楚说明其源自 Shinya Ishikawa 发起的 stack-chan 社区，并在仓库中包含 xiaozhi-esp32 固件 subtree；Atlas 因此不标注原创。

  • 适合：希望让 AI 或 MCP Agent 控制实体 StackChan 机器人、摄像头与舵机的开发者。
  • 平台：M5Stack 官方 StackChan、CoreS3 与兼容自制 stack-chan。
  • 使用方式：刷入仓库固件，运行 Python Gateway，再把 stdio MCP 配置加入客户端。
  • 许可：Gateway、固件与上游组件分别遵循仓库 LICENSE、NOTICE 及各自上游条款。
