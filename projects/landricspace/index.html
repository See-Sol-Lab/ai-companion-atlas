PROJECT INTRO

项目介绍

LandricSpace 围绕“与小 AI 的家”组织功能，包含单聊与多角色房间、关系状态、纪念日、共同旅行规划、音乐、相册和生活记录。前端可在浏览器运行，也能构建 Android APK 与 iOS App。

项目由 Expo 客户端与 Node.js 服务端组成，聊天和生活数据保存在自托管后端。README 对多人联机的描述与当前实现仍有差距，现阶段更适合按单人自用的伴侣空间理解；项目禁止未经授权的商业使用。

  • 适合：想把伴侣关系做成多房间、多生活模块空间的人。
  • 平台：Web、Android 与 iOS。
  • 使用方式：先部署 Node.js 服务端，再启动 Web 或构建 Expo 原生客户端。
  • 许可：源码公开，README 明确禁止未经授权的商业使用。
