PROJECT INTRO

项目介绍

Memex 在 iOS 与 Android 上捕捉文字、照片、语音和文件，由多 Agent 整理为时间线卡片、P.A.R.A 知识库、日程与跨记录洞察。

用户可创建角色，让其评论新记录、进行 1v1 聊天并保留长期记忆；数据存于本地 SQLite 与文件系统，也能完整导出 Markdown。自定义 Skill 可执行 JavaScript，应只安装可信内容。

  • 适合：希望把生活记录、个人知识与 AI 角色陪伴放进手机的人。
  • 平台：iOS 与 Android。
  • 使用方式：安装应用，自备模型或 Ollama，并按需导入角色卡。
  • 许可：GPL-3.0。
