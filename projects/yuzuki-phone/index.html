PROJECT INTRO

项目介绍

柚月小手机为 SillyTavern 提供微信式聊天、朋友圈、微博热搜和视频通话等模块，并实现手势返回、视图栈和剧情时间引擎。图片保存到酒馆服务器本地，避免大型 Base64 数据拖累存档。

它同时支持剧情注入模式和独立 API 模式：前者把手机动态带回酒馆主线，后者让手机内对话不污染主聊天记录。项目保留全部权利，明确禁止商业化和未经授权的二改发布。

  • 适合：使用 SillyTavern，并想给角色增加拟真手机社交生活的人。
  • 平台：SillyTavern 与 PC 浏览器。
  • 使用方式：按 README 把前端文件接入自己的 SillyTavern 环境。
  • 许可：源码公开、保留全部权利；禁止商业化与未经授权的二改发布。
