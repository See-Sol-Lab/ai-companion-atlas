PROJECT INTRO

项目介绍

whisper.cpp 是 OpenAI Whisper 的高性能 C/C++ 推理实现，支持量化、VAD、CPU 与多种 GPU 后端，并提供 C API 和丰富示例。

它覆盖 Windows、macOS、Linux、iOS、Android、树莓派、Docker 与 WebAssembly，适合在本地伴侣、机器人和手机应用中部署离线听觉。

  • 适合：希望在资源有限设备上部署本地语音识别的人。
  • 平台：桌面、移动端、树莓派、容器和浏览器。
  • 使用方式：编译运行时并下载兼容 Whisper 模型，可按硬件选择量化与加速后端。
  • 许可：MIT。
