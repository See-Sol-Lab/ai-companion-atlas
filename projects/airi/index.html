PROJECT INTRO

项目介绍

AIRI 提供浏览器 Stage、桌面 Tamagotchi 和移动 Pocket 等前端形态，支持 VRM 与 Live2D 模型、眨眼和注视动画、实时语音输入输出、多家 LLM 与 TTS Provider，以及浏览器端数据库和本地推理实验。

项目还能连接 Discord、Telegram、Minecraft 与 Factorio，并持续扩展桌面感知和游戏能力。它是一个大型、活跃的跨平台工程，适合希望搭建视觉化数字伴侣或 AI VTuber 的使用者。

  • 适合：希望拥有可见身体、实时语音和游戏能力的视觉伴侣用户与开发者。
  • 平台：现代浏览器、PWA、Windows、macOS，以及开发中的移动 Pocket。
  • 使用方式：可直接体验 Web 版，或安装桌面版本并配置模型、语音与角色资源。
  • 许可：MIT。
