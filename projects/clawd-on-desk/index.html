PROJECT INTRO

项目介绍

clawd-on-desk 是像素桌宠，可连接 Claude Code、Codex、Cursor、Copilot CLI、Gemini CLI 等编码 Agent，并对思考、打字、报错、等待权限和完成做出视觉反应。

它属于 Agent 状态工具，不是纯伴侣前端；不同 Agent 的权限仍在各自正式界面中处理。

  • 适合：同时运行多个编码 Agent，希望用桌面状态替代频繁切窗的人。
  • 平台：Windows、macOS 与 Linux。
  • 使用方式：安装桌面应用并按说明接入对应 Agent hooks。
  • 许可：源码公开；具体条款见项目仓库。
