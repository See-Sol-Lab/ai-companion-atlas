PROJECT INTRO

项目介绍

Gove 提供基于 GPT-SoVITS 的多语言男声音色模型，可用于中文、英文和日文文本转语音。仓库包含模型说明和使用示例。

它需要现成 GPT-SoVITS 环境，不单独承担训练或推理框架。仓库当前未给出清晰许可证，使用和再分发权重前需向项目页面确认。

  • 适合：已经部署 GPT-SoVITS，并需要现成多语言男声音色的人。
  • 平台：GPT-SoVITS 推理环境。
  • 使用方式：下载模型权重并按 README 放入 GPT-SoVITS 后进行推理。
  • 许可：模型权重公开；仓库当前未声明清晰许可证。
