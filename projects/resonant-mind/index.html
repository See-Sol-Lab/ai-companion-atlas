PROJECT INTRO

项目介绍

Resonant Mind 部署在 Cloudflare Workers，提供 28 个 MCP 工具，覆盖语义记忆、情绪处理、身份连续和潜意识 daemon。

它是认知后端而非聊天前端，适合与 Resonant 或其他 Agent 组合。许可允许个人、教育和非商业使用，商业使用需另行授权。

  • 适合：希望在 Cloudflare 上部署持久认知后端的个人与研究者。
  • 平台：Cloudflare Workers 与 MCP。
  • 使用方式：部署 Worker 与存储绑定，再向 Agent 注册 MCP。
  • 许可：Codependent AI Source-Available License；非商业。
