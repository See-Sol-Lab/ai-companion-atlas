PROJECT INTRO

项目介绍

cove-book-forge-mcp 读取 EPUB 与 PDF，把内容整理为人类可维护的 Obsidian 笔记，并生成伴侣专属 Agent Skill。

它强调本地优先和双向沉淀，让书籍从一次对话材料变成长期知识。

  • 适合：希望共读结果同时进入人类笔记和 AI 技能的人。
  • 平台：跨平台 Python 与 MCP。
  • 使用方式：导入书籍，配置 Obsidian 目录和 Agent Skill 输出。
  • 许可：MIT。
