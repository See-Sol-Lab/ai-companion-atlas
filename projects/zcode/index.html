PROJECT INTRO

项目介绍

ZCode 是智谱推出的官方氛围编程桌面工具。用户可以打开现有项目，也可以从一个空目录开始，直接用自然语言描述想制作的网站、应用、游戏或功能。

它会让 AI Agent 阅读项目、拆分步骤、修改文件、运行命令并验证结果。复杂任务可以通过 Goal 持续推进，也能由多个 Agent 分工协作，而不必把所有操作都挤在一次对话里。

  • 适合：想用自然语言制作网站、应用和自动化工具，或希望 AI 参与现有项目开发的人。
  • 使用方式：从 ZCode 官方页面下载安装，登录后打开工作区并描述希望完成的目标。
  • 主要能力：长程 Goal、多 Agent 协作、文件与命令操作、进度验证及远程任务唤起。
  • 费用：模型额度与套餐可能调整，以 GLM Coding Plan 官方页面的当前说明为准。
