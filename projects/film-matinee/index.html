PROJECT INTRO

项目介绍

film-matinee 提取电影画面与字幕，生成视觉 sheet、sidecar 和线性 MCP chunk，并允许人和 AI 在同一时间线上留下批注。

它面向已有 Agent 的共看流程，不包含模型与完整聊天前端；仓库当前未声明明确许可证。

  • 适合：希望与 AI 共同看片并讨论具体镜头的人。
  • 平台：Python 自托管与 MCP。
  • 使用方式：处理本地影片并把生成材料接入 Agent。
  • 许可：源码公开；仓库当前未声明明确许可证。
