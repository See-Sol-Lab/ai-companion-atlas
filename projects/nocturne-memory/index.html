PROJECT INTRO

项目介绍

Nocturne Memory 是一个给 AI Agent 使用的长期记忆服务器。记忆不再只属于某个聊天窗口或某个平台，而是单独保存在自己的 MCP 服务里。Claude Code、Codex、Gemini CLI、Cursor 等支持 MCP 的客户端，都可以接到同一份长期状态。

记忆会按层级整理，启动时可以先读取身份、关系和重要背景。AI 新增、修改或删除记忆后，网页端会显示前后差异，再由使用者决定接受或回滚；不同 AI 人格也可以分开保存，避免彼此串记忆。

  • 适合：已经在多个窗口、客户端或模型之间切换，希望长期身份与共同历史不跟着平台一起丢掉的人。
  • 跨模型：不同模型可以读取同一份长期记忆，但底模本身不同，所以人格表现仍可能有差异。
  • 安全网：修改会留下前后状态，Dashboard 可以查看 diff，再接受或回滚；多个人格可用 namespace 隔离。
  • 部署：支持 SQLite 或 PostgreSQL，本机可直接运行，也可以自托管到服务器；网络开放时支持 Bearer Token 保护。
