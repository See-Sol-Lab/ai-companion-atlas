PROJECT INTRO

项目介绍

Operit AI 是一个面向 Android 的开源 Agent 平台。它支持多家云模型、自定义端点、MNN 与 llama.cpp 本地模型，并能在授权后操作文件、网页、应用界面、相机和系统工具。

应用内包含 Ubuntu 24.04 用户空间、代码编辑与预览、SSH、SFTP、Git 和多种项目模板，同时提供多个记忆空间、混合检索、角色卡、多角色对话、工作流、MCP、Skill 与 ToolPkg 扩展。

  • 适合：想让 Android 设备成为 AI 伴侣与 Agent 的完整工作台，而不满足于纯聊天的人。
  • 平台：Android；跨平台后续版本 Operit 2 为独立项目。
  • 使用方式：安装应用、配置云端或本地模型，再按实际任务逐项授权设备与工具能力。
  • 许可：LGPL-3.0。
