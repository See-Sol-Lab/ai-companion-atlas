PROJECT INTRO

项目介绍

WakeTrace 把运行时、调度器、REST API、MCP 和网页界面放在同一套服务里。伴侣可以由时间或经允许的生活事件醒来，调用工具、完成小作品，并以静默、私下留痕或消息三种结果结束。

它区分完整经历和供下一次读取的简短事实痕迹。聊天与独处的双向承接需客户端或宿主接入；2.0 轻量版不会自动同步每轮聊天。Docker 部署需自行配置模型 API 与鉴权令牌。

  • 适合：希望 AI 伴侣在两次聊天之间拥有有边界的自主活动，并保留可承接经历的人。
  • 平台：Docker Compose 单容器，或 Python 3.11+ 自行部署；需要模型服务。
  • 使用方式：克隆仓库，配置模型密钥及管理、网页和 MCP 令牌，再启动服务；聊天接入需额外配置。
  • 许可：PolyForm Noncommercial 1.0.0；商业使用需另获授权。
