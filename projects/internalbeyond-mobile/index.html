PROJECT INTRO

项目介绍

InternalBeyond Mobile 提供多模型聊天、长期情感记忆、AI 社交圈、日历、博客、书信、共听与共享文件工作区，并允许每位 AI 拥有独立关系设定和 Auto Memory 档案。

项目以单文件 HTML 离线运行，可安装为 PWA；所有数据保存在本地浏览器，并能通过 JSON 备份与桌面版 InternalBeyond 相互迁移。

  • 适合：希望在手机上拥有完整私人伴侣空间，并与桌面版共享关系数据的用户。
  • 平台：现代手机浏览器与 PWA；单文件也可在电脑浏览器运行。
  • 使用方式：下载后直接打开 index.html，或部署到 HTTPS 静态托管并安装到主屏。
