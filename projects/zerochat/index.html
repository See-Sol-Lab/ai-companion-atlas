PROJECT INTRO

项目介绍

ZeroChat 是一款 Flutter Android 应用，提供微信式消息列表、多角色对话、AI 朋友圈、主动消息和定时任务。用户可以在应用内设置模型接口、角色信息与后端地址。

项目配套 Python 服务端，可运行在本地电脑或服务器；手机通过局域网或内网穿透连接。当前需要使用者自行准备 OpenAI 兼容模型 API。

  • 适合：希望伴侣像手机联系人一样聊天、发动态并主动出现的人。
  • 平台：Android；后端可运行于 Windows、Linux 或服务器。
  • 使用方式：启动配套后端，安装 Flutter 客户端并填写模型与后端地址。
  • 许可：MIT。
