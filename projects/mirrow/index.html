PROJECT INTRO

项目介绍

MIRROW 是一套给 AI 伴侣开发者使用的 Python 零件包。它不能单独启动成聊天软件，而是要接进一个已经存在的 FastAPI、asyncio 或其他伴侣程序。

当前公开模块可以读取电脑空闲状态、手机或其他可选数据，判断人类是否忙碌；也可以让 AI 在无人交谈时整理想法，选择合适的主动联系时机，并把模型的意图转换成真正的工具调用。

  • 适合：已经有自己的 AI 伴侣程序，想继续增加环境感知、主动联系和工具行动能力的开发者。
  • 公开内容：环境感知、漫想与主动推送、工具调度、上下文组装以及记忆接口示例。
  • 未公开内容：完整聊天产品、前端、群聊、语音和原系统的完整记忆库。
  • 前置条件：需要一个现有 Python 宿主程序，并自行提供模型调用、消息推送和可选记忆检索接口。
