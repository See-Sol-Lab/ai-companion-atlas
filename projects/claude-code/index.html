PROJECT INTRO

项目介绍

Claude Code 是 Anthropic 官方终端 Agent，可理解代码库、编辑文件、运行命令、处理 Git 工作流，并通过 MCP、hooks、skills 和 Channels 扩展。

它本身是通用开发工具，但已成为许多本地伴侣系统的运行宿主。使用与许可受 Anthropic 官方条款约束。

  • 适合：需要强本地工具能力、终端会话和扩展生态的 Agent 用户。
  • 平台：Windows、macOS 与 Linux。
  • 使用方式：按官方方式安装并登录，再配置项目、MCP 与权限。
  • 许可：Anthropic 官方工具，按仓库 LICENSE 与服务条款使用。
