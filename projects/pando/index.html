Pando

CLAUDE CODE MOBILE GATEWAY · @ELOISE-ASPEN

从手机进入自己电脑里的 Claude Code，会话、工具和数据都留在本机。

Pando 是一层很薄的 FastAPI 桥：它驱动本机已经登录的 Claude Code CLI，把输出实时送到手机 PWA。项目不保存 API Key，聊天历史在自己的 SQLite 中，记忆则通过可替换的外部接口接入。

PROJECT INTRO

项目介绍

Pando 把本地 Claude Code CLI 包装成可从手机访问的自托管 PWA。它可以流式显示思考、正文与工具调用，上传图片或 PDF，并把写文件、运行命令等权限请求传到手机，让用户决定允许或拒绝。

项目本身不实现长期记忆，而是提供四端点 MemoryProvider 契约，任何记忆服务都能替换接入。它默认不带应用层身份验证，因此应放在 Tailscale 等可信私网或带访问策略的隧道后面。

  • 适合：希望在手机上继续使用自己电脑中的 Claude Code，并掌控数据与权限的人。
  • 平台：运行 Claude Code 的 Windows、macOS 或 Linux 电脑，加任意手机浏览器。
  • 使用方式：安装 Python 包、指定工作目录，启动 Pando 后通过可信私网访问 PWA。
  • 许可：代码 MIT；界面与字体、图标的第三方来源在 NOTICE 中单独说明。
