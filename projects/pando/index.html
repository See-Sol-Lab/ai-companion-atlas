PROJECT INTRO

项目介绍

Pando 给电脑上的 Claude Code 配了一个手机遥控网页。电脑保持开机并运行 Pando 后，你可以离开桌前，用手机继续发送消息、查看回复和工作进度，也可以上传图片或 PDF。

当 Claude Code 想修改文件或运行命令时，Pando 可以把确认请求送到手机，由你选择允许或拒绝。它不提供新的 AI，也不会把 Claude Code 装进手机；真正工作的始终是自己的电脑。

  • 适合：希望离开电脑桌后，仍能用手机继续指挥 Claude Code 工作的人。
  • 需要：一台已经安装并登录 Claude Code 的 Windows、macOS 或 Linux 电脑，以及一部手机。
  • 能做：手机聊天、查看工作过程、上传图片或 PDF，并确认是否允许改文件或运行命令。
  • 安全边界：Pando 自身没有登录验证，只能放在可信私人网络中使用，不能直接暴露到公网。
