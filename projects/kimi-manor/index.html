PROJECT INTRO

项目介绍

Kimi Manor 提供 atelier、alcove、cabinet 和 ops 四个空间，并把 xterm.js 真终端嵌入画框。使用者可以把启动命令替换成 Claude Code、Codex、Gemini、Aider 等任意 CLI Agent。

可选 bridge 能把 Agent 状态显示为气泡，让多个 Agent 同席并接入语音。项目提供浏览器 PWA 与 Electron 桌面方式，默认使用占位数据且可离线运行。

  • 适合：长期使用 CLI Agent，又希望增加桌面空间感和可见状态的人。
  • 平台：PC 浏览器 PWA 与 Electron 桌面端。
  • 使用方式：启动本地服务或 Electron，并把终端命令指向自己的 Agent CLI。
  • 许可：MIT。
