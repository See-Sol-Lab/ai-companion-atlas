PROJECT INTRO

项目介绍

cyberboss 将 Claude Code 或 Codex 接入微信，并提供时间、行踪、自主唤醒、自动日记和 MCP 工具调用。

它同时属于主动陪伴和现实接入，本批按更大的陪伴类统一收录。

  • 适合：希望本地 Agent 通过微信长期参与现实生活的人。
  • 平台：Claude Code、Codex 与微信桥。
  • 使用方式：部署本地 Bridge 并按 README 配置通道与工具。
  • 许可：AGPL-3.0。
