PROJECT INTRO

项目介绍

Veglia 的 Android 应用通过可见的前台无障碍服务记录近期应用活动，并在 AI 明确请求时截取当前屏幕。自托管 Python 服务只保留最近少量截图，再通过用户配置的 Hook 把图片送进 AI 会话。

它与同作者的 ghost-bf 不是同一实现：ghost-bf 是 MacroDroid、定时唤醒和通知教程；Veglia 提供原生活动感知、截图与召回应用代码，但不包含完整主动唤醒闭环。

  • 适合：双方明确同意，并希望让伴侣按需理解 Android 手机活动或当前屏幕的人。
  • 使用方式：Android 11+；自行构建和安装 APK，部署 Python 服务与 HTTPS，再接入 AI 侧 CLI 和通知 Hook。
  • 隐私边界：所有接口使用共享密钥；默认只保留最近 5 张截图，手机显示前台通知，查看和召回可以分别关闭。
