PROJECT INTRO

项目介绍

Duix Mobile 提供 iOS 与 Android 的实时互动数字人方案，支持本地 / 私有部署和低延迟语音头像交互。

项目可扩展到平板、车载、VR、IoT 与大屏，主要提供数字人身体与交互前端，不包含独立长期人格和记忆。

  • 适合：需要移动端端侧数字人和实时语音头像的开发者。
  • 平台：Android、iOS 与边缘设备。
  • 使用方式：按各平台 Demo 集成模型、语音与数字人资源。
  • 许可：源码公开；具体使用与部署边界见项目 LICENSE。
