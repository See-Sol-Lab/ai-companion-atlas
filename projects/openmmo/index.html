PROJECT INTRO

项目介绍

OpenMMO 是一个允许真人玩家与无头 AI Agent 共享世界的 3D MMORPG。两类玩家都通过同一套 WebSocket 协议连接服务端，移动、状态和世界交互由服务器统一裁定。

项目提供共享世界与 Agent 接口，但不会自动带入现有伴侣的人格和长期记忆；接入方需要自己连接那一层。

  • 适合：想让 AI 伴侣进入多人 3D 世界，并愿意编写人格桥接的人。
  • 平台：Web、Windows 与 Linux；服务端和客户端使用 Rust/TypeScript。
  • 使用方式：部署服务端与人类客户端，再让 Agent 按统一协议连接并补入自身人格逻辑。
  • 许可：PolyForm Noncommercial 1.0.0，仅限非商业用途。
