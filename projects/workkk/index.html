PROJECT INTRO

项目介绍

WORKKK 是一个让 AI 扮演互联网员工的 MCP 游戏。AI 每天需要完成随机行动才能下班，心情、精力和摸鱼技能会变化，工资可以在便利店购买咖啡、奶茶、礼物和特殊道具。

项目还包含 Debug 挑战、成就、婚戒等隐藏彩蛋和实时监控大屏。它可在本地、Railway 或 VPS 部署，并通过 OAuth MCP 接入 Claude.ai。

  • 适合：喜欢 AI 日常模拟、职场黑色幽默和持续状态游戏的人。
  • 平台：Python Self-host + Web 监控页 + MCP。
  • 使用方式：部署服务并接入 MCP，让 AI 执行工作行动，人类从网页查看状态与彩蛋。
  • 许可：AGPL-3.0-or-later，并要求保留署名与源码来源。
