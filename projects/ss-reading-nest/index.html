PROJECT INTRO

项目介绍

共读小窝面向小说和漫画阅读，记录当前进度、补课区间、书签、摘录与短评，并通过 ChatGPT Apps SDK 和 MCP 把这些阅读状态提供给 AI。伴侣可以围绕真实阅读位置继续讨论。

项目包含 Web 前端、服务端与共享协议，使用 Cloudflare D1 和 R2 保存结构化数据与媒体。仓库公开了运行代码与许可文件，但许可条款需按项目文件逐项确认。

  • 适合：希望在手机上与 AI 共读小说、漫画并保留共同进度的人。
  • 平台：移动端优先 Web 前端，结合 ChatGPT Apps SDK。
  • 使用方式：按 README 配置 Web、MCP 服务与 Cloudflare D1/R2。
  • 许可：源码公开；仓库同时提供 LICENSE 与 License 文件，使用前应核对具体条款。
