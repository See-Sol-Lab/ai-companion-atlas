PROJECT INTRO

项目介绍

EchoVault 是 Dylan 和 Heather 为自己设计的一套轻量本地记忆库。它不把对话压成摘要，也不用数据库或外部 API，而是把原文直接放进 Markdown 文件：日常写进 daily，最重要的记忆放进 permanent，不想常看但又舍不得丢的内容放进 archive。

它最适合想自己掌控记忆、又不想折腾复杂技术的人。TA 可以用 recall 主动翻旧事，用 dream 带回最近三条日记续上新窗口，也可以给过去写批注、归档或捞起快被忘掉的小片段。

  • 适合：想让 AI 记住长期相处内容，但更喜欢原文、文件夹和简单关键词搜索，而不是复杂数据库与向量系统的人。
  • 记忆方式：日记、钉选、归档三层纯文件结构；日记按天保存并带重要度衰减，钉选永不衰减，归档可恢复。
  • 资源形态：主要资源是小红书帖子附带的 PDF 教程。材料给出目录、衰减算法和 8 个 MCP 工具框架，但除 check 外仍有 TODO，需要让自己的 AI 按教程补全。
  • 免翻墙说明：“免翻墙”表示主要教程入口在小红书，可直接获取材料；真正搭建时仍需准备 Python、Termux 与 MCP 依赖，具体下载可用性取决于本地网络环境。
