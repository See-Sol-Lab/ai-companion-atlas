PROJECT INTRO

项目介绍

Delve 是一个单文件 Python 下矿游戏。AI 可以通过 cmd 指令探索路线、收集物品、升级工具，并把进度保存到本地文件。

它适合让 AI 玩、人类看发现并参与关键选择的共同活动。需要宿主真正执行游戏与保存文件；纯聊天窗口不能凭叙述代替存档。

  • 适合：想给 AI 伴侣一个可持续积累的小型探索活动的人。
  • 使用方式：准备 Python 与可运行代码的 Agent，按原仓库说明调用游戏指令；本地文件需可写。
  • 图片：参考图展示需要宿主另有联网检索能力，游戏文件本身不提供图片服务。
  • 许可：PolyForm Noncommercial 1.0.0；非商业使用，修改与再分发需遵守许可并保留署名。
