PROJECT INTRO

项目介绍

OrangeChat 是一款陪伴向 Android AI 客户端。核心新增是 QuickJS 沙箱插件系统，支持工具注册、事件 Hook、声明式原生 UI 和 WebView 页面，并附带天气、共读、朋友圈、云端记忆与隐私备份等示例插件。

应用还加入定位、附近搜索、应用使用、相机、Gadgetbridge 健康数据、HNSW 记忆、每日总结、Supabase 同步和主动消息，以及闹钟、日历、音乐、短信等设备工具。项目最初基于 RikkaHub 深度定制，README 明确列出上游与新增架构，并按上游的分段双重许可继续发布。

  • 适合：希望 Android 伴侣拥有可扩展插件、真实生活感知与主动联系能力的人。
  • 平台：Android 8.0+；构建需要 Android Studio、JDK 17+ 与 Firebase 配置。
  • 使用方式：安装应用后按需授权设备能力、配置模型与服务，并导入或开发插件。
  • 许可：派生自 RikkaHub，采用上游的分段双重许可：个人及小规模非商业使用走 AGPL-3.0。
