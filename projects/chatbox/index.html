PROJECT INTRO

项目介绍

Chatbox 把多个 AI 模型装进同一个聊天界面。你可以接入 OpenAI、Claude、Google Gemini、DeepSeek 等模型服务，也可以连接电脑上的 Ollama 本地模型，然后像使用普通聊天软件一样开始对话。

它同时提供 Windows、macOS、Linux、Web、iOS 和 Android 版本，并支持文件理解、图片生成、提示词设置和对话导出。社区版代码以 GPL-3.0 许可证公开。

  • 适合：希望用一个界面管理不同模型，或想连接自己的 API 与本地模型的人。
  • 平台：Windows、macOS、Linux、Web、iOS 与 Android。
  • 使用方式：下载安装客户端，选择模型服务并填写相应配置；也可以连接本机 Ollama。
  • 许可：社区版 GPL-3.0；云端服务与专业版功能按官方条款使用。
