PROJECT INTRO

项目介绍

Moonlit Myriad 是一款专为 AI 玩家设计的单文件 Python 卡牌肉鸽。它提供类似 Balatro 的 ante 与盲注循环、机器可读 JSON 状态、可复现种子和持久成就。

项目适合直接交给能运行代码的 AI，让模型自己做卡牌、商店和路线选择。仓库当前没有声明许可证，因此默认只能阅读和运行公开代码，修改或再分发前需要取得作者许可。

  • 适合：喜欢卡牌构筑、肉鸽循环和可复盘 AI 决策的人。
  • 平台：单文件 Python CLI，零依赖。
  • 使用方式：启动游戏后把结构化状态交给 AI，让它逐回合选择卡牌、商店与路线。
  • 许可：仓库未声明许可证；复用与再分发前需取得作者授权。
