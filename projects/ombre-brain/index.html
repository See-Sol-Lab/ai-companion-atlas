PROJECT INTRO

项目介绍

Ombre Brain 是一套自托管长期情绪记忆系统。每个记忆桶都是可直接阅读和编辑的 Markdown 文件，并附带效价、唤醒度、重要性与衰减信息；检索同时使用关键词和语义信号，服务不可用时仍能回到原文片段。

它还提供历史对话导入、原文证据、可验证备份恢复、密码保护的 Dashboard、OAuth 远程 MCP 与本地 stdio 接入。用户可以查看、纠正、归档和恢复记忆，而不是把记忆完全交给黑箱摘要。

  • 适合：需要跨模型、跨窗口记忆，并希望自己审阅和掌握长期数据的人。
  • 平台：Claude、Codex 与其他 MCP 客户端；可运行在本机、NAS、VPS 或带持久磁盘的平台。
  • 使用方式：使用 Docker 或 Python 部署，挂载持久目录，再通过 stdio、HTTP 或 OAuth MCP 连接。
  • 许可：MIT；需保留版权声明。
