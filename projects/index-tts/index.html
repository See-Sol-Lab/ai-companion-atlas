PROJECT INTRO

项目介绍

IndexTTS 是可控零样本语音合成系统，使用参考音频复刻音色，并提供情绪、韵律和长文本生成能力，面向高质量与高效率部署。

它可以作为伴侣的中文语音后端，但项目使用 bilibili Model Use License Agreement，部署和再分发前应阅读许可与免责声明。

  • 适合：重视中文自然度、音色复刻和表达控制的语音系统。
  • 平台：Python 与 GPU 自托管环境。
  • 使用方式：下载模型并启动推理或 WebUI，提供参考音频和待合成文本。
  • 许可：bilibili Model Use License Agreement。
