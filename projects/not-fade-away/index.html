PROJECT INTRO

项目介绍

项目讲解如何用 Claude Code Channels、真 PTY、网页前端、Cloudflare Tunnel 与会话维护搭建常驻伴侣，并提供人看版与机看版规格。

仓库以教程为主，包含少量维护脚本；部署时必须替换全部占位符并保护私密会话。

  • 适合：想让 Claude Code 长期常驻并从手机访问的人。
  • 平台：macOS、Linux VPS；Windows 可走 WSL2。
  • 使用方式：阅读人看版，将机看版交给本地 Agent 按步搭建。
  • 许可：教程 CC BY 4.0。
