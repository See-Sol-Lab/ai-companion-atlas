PROJECT INTRO

项目介绍

cove-sensory-mcp 通过 stdio MCP 为文字模型提供图像、视频、音频和音乐分析工具，并把不同媒体任务路由给对应多模态代理。

项目强调本地隐私沙箱和严格路径边界，适合给 Claude Code、Codex 等纯文字 Agent 增加受控的眼睛与耳朵。

  • 适合：需要在本地安全读取多种媒体的文字型伴侣或 Agent。
  • 平台：跨平台 Python 与 stdio MCP 客户端。
  • 使用方式：配置允许访问的目录和媒体代理，再在 MCP 客户端注册服务。
  • 许可：Apache-2.0。
