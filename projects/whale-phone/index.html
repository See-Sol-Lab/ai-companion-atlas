PROJECT INTRO

项目介绍

玄鲸小手机提供移动端拟真聊天体验，把私聊、群聊、朋友圈、论坛、表情包、角色设定、长期记忆、语音和一起听歌等功能放进统一界面。用户可以自行配置第三方模型 API 或本地模型。

项目以 Web 技术开发，并通过 Capacitor 打包为 Android 原生应用；聊天、角色和大部分配置保存在本地。它不提供模型、托管后端或生成内容服务。

  • 适合：喜欢拟真手机界面，希望集中承载角色扮演与陪伴日常的人。
  • 平台：Android，Web 技术配合 Capacitor 打包。
  • 使用方式：安装或自行构建应用，再配置自己的模型 API、语音和角色数据。
  • 许可：AGPL-3.0。
