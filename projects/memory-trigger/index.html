PROJECT INTRO

项目介绍

Memory Trigger 为任意 AI Agent 提供本地长期记忆，区分用户明确表达与 AI 推测，用核心记忆、置信度、否认降权、到期机制和遗忘曲线维持可信记录。

它还能按情绪与场景主动召回旧事，跟踪带期限的承诺，并通过 MCP 暴露记忆工具与使用指引；纯 Python 文件模式也可独立运行。

  • 适合：希望为 AI 伴侣或 Agent 增加可信长期记忆、主动回忆与承诺闭环的用户。
  • 平台：Python 3；本地文件、命令行或 MCP 客户端。
  • 使用方式：克隆后运行自检，选择本地模式或配置 MCP Server，并让 Agent 读取记忆使用指引。
  • 许可：核心模板 MIT；可选 mcp-memory-graph 使用 PolyForm Noncommercial，商业使用需另行授权。
