PROJECT INTRO

项目介绍

OpenPersona 定义 Soul、Body、Faculty、Skill 四层人格架构，用于创建、组合和编排 AI Persona。

框架兼容 OpenClaw、ClawHub 和 skills.sh，适合将人格核心与身体、能力、技能分开管理。

  • 适合：需要结构化人格资产和跨生态编排的开发者。
  • 平台：OpenClaw 与 Agent Skill 生态。
  • 使用方式：按四层架构定义 Persona，并接入兼容运行时。
  • 许可：MIT。
