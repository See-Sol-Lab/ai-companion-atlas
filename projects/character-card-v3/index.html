PROJECT INTRO

项目介绍

Character Card Spec V3 为新一代角色聊天前端定义人格、知识和扩展数据结构，使 AI 身份资料可以被兼容应用保存和交换。

它与 v2 并存，实际导入能力取决于目标前端。

  • 适合：使用 RisuAI 等 v3 生态并关注人格可携带性的用户。
  • 平台：兼容角色卡 v3 的前端。
  • 使用方式：按规范生成 v3 角色卡并在兼容应用间迁移。
  • 许可：开放规范；具体条款见项目仓库。
