PROJECT INTRO

项目介绍

Codex Tandem 0.1.1 是面向 Codex CLI 的双账号切换器。它保留 CODEX_HOME 下的会话、历史、配置与扩展，仅切换账号凭据，再使用正常的会话恢复流程。

项目包含本地权限检查、原子替换和失败恢复机制。凭据仍以本地文件保存，使用者需要保护主机账户与备份；这些机制未经本站运行验证。

  • 需要：Node.js 20+、已安装的 Codex CLI，以及两个本人有权使用的账号。
  • 平台：README 列 Linux/macOS；作者报告 Linux 实测，macOS 尚缺独立验证，不标 Windows 支持。
  • 使用边界：在没有 Codex 任务运行时切换。不是账号共享服务，也不保证未来 CLI 版本或桌面客户端兼容。
  • 许可：MIT；凭据文件不应上传或提交到仓库。
