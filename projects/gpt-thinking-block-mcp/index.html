PROJECT INTRO

项目介绍

GPT Thinking Block MCP 是一个需要自行部署的工具。GPT 在给出最终回答前，可以先生成一张可折叠的工作卡，整理当前问题、可选方向、限制条件和仍不确定的地方。

卡片可以使用偏分析的风格，也可以使用更自然的陪伴式表达。篇幅、提示词、颜色和外观都能修改。它不会读取模型内部隐藏的推理，而是让 GPT 为当前回答另外写一份可以给人看的工作稿。

  • 适合：希望在复杂分析、创作或长期对话中，看见 GPT 回答前如何整理问题的人。
  • 两种风格：可以选择偏分析的工作稿，或者更自然的陪伴式表达。
  • 可以调整：支持不同篇幅、卡片配色、文字风格和折叠效果。
  • 使用提醒：需要自行部署并连接 ChatGPT 或 Codex；卡片里不要填写密码、密钥或其他秘密。
