PROJECT INTRO

项目介绍

WebCall 是一套可自部署的 AI 实时语音通话网页。你在浏览器里说话，系统把声音转成文字交给模型，再把回答合成为语音播放出来。

它支持自定义角色、多种 OpenAI 兼容模型、MiniMax 语音和多种语音识别方案。首次启动可用网页向导完成配置，并带有基础的账号、用量与管理功能。

  • 适合：想给 AI 伴侣增加一个网页电话入口，并自行决定角色、模型和声音的人。
  • 平台：Python Flask 与 Web 前端，可部署到 Hugging Face Spaces 或 Docker。
  • 使用方式：部署服务，按照网页向导配置模型、语音识别和语音合成服务，再通过浏览器通话。
  • 许可：AGPL-3.0。
