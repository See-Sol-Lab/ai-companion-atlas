PROJECT INTRO

项目介绍

RikkaHub 是一款原生 Android LLM 客户端，支持 OpenAI、Anthropic、Gemini 及兼容接口，提供图片、文档、多模态输入、Web 访问、搜索、消息分支、角色卡导入和类似 ChatGPT 的记忆功能。

它还内置基于 PRoot 的 Linux Agent 工作区，并支持 MCP 和自定义 Agent。用户可以为不同模型设置接口、请求头和参数，在手机上构建从普通聊天到工具执行的多种使用方式。

  • 适合：想在 Android 上统一管理多家模型、角色、MCP 与本地工作区的人。
  • 平台：Android；部分能力可通过内置 Web 访问延伸到其他设备。
  • 使用方式：安装官方版本，在应用内添加自己的模型供应商、角色卡和工具。
  • 许可：AGPL-3.0。
