PROJECT INTRO

项目介绍

OmniRouter 是一个安装在自己电脑上的模型中转站。你可以在它的网页后台添加 OpenAI、OpenRouter、DeepSeek 和其他兼容服务，并统一保存不同的模型地址与 API Key。

设置完成后，伴侣前端只需要填写 OmniRouter 提供的一个固定 API 地址。每次聊天请求先到这里，再由它按模型分组、任务类型、顺序、随机或权重选择真正负责回答的模型。

  • 适合：同时使用多个模型服务，不想在每个伴侣前端里反复配置和手动换线路的人。
  • 使用方式：添加 Provider、API Key、模型和分组，再把仪表盘显示的统一 API 地址填入伴侣前端。
  • 自动选择：可以按问题类型选择模型组，也支持顺序、随机和权重轮换。
  • 安全提醒：API Key 当前以明文保存在本地 SQLite 数据库中；不要分享数据库，也不要把服务直接暴露到公网。
