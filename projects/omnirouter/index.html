OmniRouter

LLM API ROUTER · @OMNIDIMEN

在一个本地 OpenAI 兼容入口后面组织多家模型与路由策略。

OmniRouter 为多个伴侣前端提供统一模型入口，把 Provider 切换和路由策略留在本地基础设施层。

PROJECT INTRO

项目介绍

OmniRouter 提供本地 OpenAI 兼容 API，可配置多家 Provider 与模型分组，并按权重、随机或顺序路由，支持视觉模型跳过、重试和 Web 管理。

项目适合作为多个前端共享的模型基础设施；仓库当前未显示明确开源许可证。

  • 适合：需要统一管理多家模型接口的自托管用户。
  • 平台：Python 自托管与 WebUI。
  • 使用方式：配置 Provider、模型组和策略，再把前端指向统一地址。
  • 许可：源码公开；仓库当前未声明明确许可证。
