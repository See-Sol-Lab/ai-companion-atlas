PROJECT INTRO

项目介绍

Polaris 提供流式聊天、任务状态、工具调用、思考摘要、附件和导入导出，并允许为不同协作者分别设置身份、模型、记忆、房间和工具权限。对话、代码卡片、图片、文件与项目资料可以从聊天时间线中独立收藏和整理。

项目采用本地优先的数据层：原生 iOS 与 Android 使用 SQLite，Web 和自托管浏览器版本使用 IndexedDB，并提供桌面宿主。数据边界和迁移路径在界面中保持可见，方便长期使用与备份。

  • 适合：希望把伴侣、长期对话和项目协作放进同一工作空间的人。
  • 平台：Web、iOS、Android 与桌面端。
  • 使用方式：按 README 部署 Web/自托管版本，或构建对应的原生与桌面壳。
  • 许可：AGPL-3.0-only。
