PROJECT INTRO

项目介绍

AstrBot 提供完整 WebUI 与 Web ChatUI，可管理模型、Persona、知识库、MCP、Skills、上下文压缩、沙箱和插件，并接入 QQ、Telegram、企业微信、飞书、钉钉、Slack 等平台。

项目支持桌面 App、Launcher、Docker 与服务器部署，生态包含千余插件。

  • 适合：希望用 PC 前端管理多通道伴侣或 Agent 的用户。
  • 平台：PC 桌面、自托管 Web 与多种 IM。
  • 使用方式：安装桌面版或部署服务，在 WebUI 中配置模型与通道。
  • 许可：AGPL-3.0。
