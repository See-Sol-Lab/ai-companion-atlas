PROJECT INTRO

项目介绍

ChatGPT-Exporter 用于批量导出 ChatGPT 对话，覆盖个人与团队空间，并输出 JSON 或 Markdown。

项目适合阶段性备份与迁移；仓库当前未显示明确开源许可证。

  • 适合：拥有大量 ChatGPT 会话并需要整体备份的人。
  • 平台：浏览器与本地导出环境。
  • 使用方式：按 README 配置后选择空间与输出格式。
  • 许可：源码公开；仓库当前未声明明确许可证。
