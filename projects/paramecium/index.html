PROJECT INTRO

项目介绍

Paramecium 是一套强调原文真源的网关记忆架构。它保存完整聊天记录，用向量和其他索引寻找相关位置，但召回时返回原始文本，不用模型摘要替换曾经发生过的对话。

这种路线适合在意证据、措辞和关系细节的长期伴侣系统，也便于用户回看记忆究竟来自哪里。

  • 适合：不愿让摘要取代原话，希望记忆可追溯到逐字记录的人。
  • 平台：自托管 JavaScript 网关。
  • 使用方式：将模型请求经过网关，保存原始对话并让索引只承担定位职责。
  • 许可：仓库源码公开，具体复用与分发以项目声明为准。
