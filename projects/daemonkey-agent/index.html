PROJECT INTRO

项目介绍

守护猴是一套安装在自己电脑上的完整 AI 伴侣软件。启动后，它会打开一个本地网页聊天界面；第一次见面时，你可以给伴侣起名字，告诉 TA 怎么称呼你、你在做什么，以及希望 TA 提供怎样的陪伴或帮助。

后续对话、人物画像、共同记忆和新增能力都会保存在本地数据目录。即使关闭网页、重新启动电脑或更换背后的模型，守护猴仍会加载原来的身份与记忆。

  • 适合：希望在自己的电脑上长期运行一个有网页界面、有关系记忆、还能使用工具的 AI 伴侣的人。
  • 前置条件：需要 Python 3.10+ 和一个可用的模型 API Key。
  • 使用方式：启动本地服务，在浏览器页面配置模型并完成第一次相遇，之后直接在网页里聊天和使用能力。
  • 数据：对话、画像、记忆与用户扩展保存在本地；调用外部模型时，相关对话内容仍会发送给所选模型服务商。
