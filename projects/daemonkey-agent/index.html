PROJECT INTRO

项目介绍

Daemonkey 是运行在本地电脑上的伴侣 daemon，提供长期记忆、成长、自加技能、自我修复和微信通道。

项目带核心指纹、Manifest 与回滚工具，用于保护更新和恢复；任何网络部署修改版都必须继续公开源码。

  • 适合：希望使用长期常驻、自扩展和可恢复本地搭档的人。
  • 平台：Windows、macOS 与本地自托管。
  • 使用方式：安装守护进程，配置模型、通道与技能权限。
  • 许可：AGPL-3.0。
