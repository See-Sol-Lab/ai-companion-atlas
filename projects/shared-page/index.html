PROJECT INTRO

项目介绍

shared-page 提供手帐风日历、三种笔迹、可互相点赞的便签、照片拼贴和桌面小组件。服务端还能把整页渲染为 PNG，并通过 MCP 让 AI 读取和写入同一份日历。

项目包含 iOS 客户端与自托管服务端，当前仓库历史较短，但核心代码、文档和许可已经公开。

  • 适合：希望与 AI 共用日历、便签和照片手帐的人。
  • 平台：iOS 客户端与自托管服务。
  • 使用方式：部署服务端，构建 iOS 客户端，并按需连接 MCP 与推送。
  • 许可：MIT。
