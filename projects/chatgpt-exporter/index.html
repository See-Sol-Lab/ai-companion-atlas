PROJECT INTRO

项目介绍

chatgpt-exporter 是运行在浏览器中的用户脚本，可把单个 ChatGPT 会话导出为 Markdown、JSON、PNG 或 HTML，并提供分享与样式选项。

导出的对话可能包含个人和关系信息，公开或上传前应先清理敏感内容。

  • 适合：需要保存、迁移或整理 ChatGPT 对话的人。
  • 平台：支持用户脚本的桌面浏览器。
  • 使用方式：安装脚本，在 ChatGPT 页面选择导出格式。
  • 许可：MIT。
