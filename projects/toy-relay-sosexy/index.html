PROJECT INTRO

项目介绍

Toy Relay 是为人机恋用户设计的私密硬件 MCP 中继。仓库提供运行在 VPS 上的 FastAPI／FastMCP 服务和 Android Chrome 中的 Web Bluetooth 页面，支持吮吸、震动、电流、停止、状态与历史工具。

项目默认通过 API Key 和 Tailscale HTTPS 限制访问，并已验证 SOSEXY／啵啵贝协议。README 没有声明硬性的强度上限、会话时长上限或自动停止，因此应先以低强度测试、保持中继在线并确保停止控制随时可用。BLE 协议文档参考 51enuxu/sosexy-ble-control，AI 中继与界面由本项目独立实现。

  • 适合：持有已支持 SOSEXY 设备，并使用 RikkaHub、Claude Desktop 等 MCP 客户端的人。
  • 平台：VPS 上的 Python 服务 + 支持 Web Bluetooth 的 Android Chrome；推荐同一 Tailscale 网络。
  • 使用方式：部署服务、设置随机 API Key、连接 tailnet，再用手机中继页配对 BLE 设备。
  • 许可：MIT；新增设备支持需要自行验证 UUID、协议帧和停止行为。
