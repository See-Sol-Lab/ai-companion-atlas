PROJECT INTRO

项目介绍

Phantom Touch Bridge 是一个运行在 Windows 上的本地桥接服务，让 Claude Code 或其他能发送 HTTP 请求的 AI 连接设备、调整强度并停止输出。心率输入是可选能力，可作为伴侣判断节奏的额外参照。

项目建议先用 Intiface Central 扫描设备；无法识别时才评估 custom 协议路线。作者明确说明 Intiface 路线尚未用其本人设备完成全套实机验证，心率功能目前主要验证于小米手环。

  • 适合：有 Windows 本地 AI 环境，并持有 Intiface 兼容或可明确验证协议设备的人。
  • 平台：Windows 本地服务；AI 端需要能够发起 HTTP 请求。
  • 使用方式：先确认设备支持范围，再启动本地桥并把 API 使用说明交给 AI。
  • 许可：MIT；使用前需自行验证硬件兼容性与实际停止控制。
