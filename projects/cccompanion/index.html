CcCompanion 由 SwiftUI iOS App 和电脑端推送服务组成，让 iPhone 通过局域网或私有组网连接自己的 Claude Code 会话。

PROJECT INTRO

项目介绍

CcCompanion 的 iOS 客户端提供聊天、终端、斜杠命令、语音输入、搜索收藏、多 Agent 工作群和微信风格主题。它连接电脑端 tmux 中的 Claude Code session，并通过 Apple Push 把回复送回手机。

电脑端服务可运行在 macOS、Windows WSL2、Linux 或 VPS，手机通过 LAN、Tailscale 或 ZeroTier 直连。项目与 Anthropic 无隶属关系，所有消息均由使用者自己的设备处理。

  • 适合：希望在 iPhone 上继续本地 Claude Code 长会话的人。
  • 平台：iOS 客户端；配套 macOS、WSL2、Linux 或 VPS 服务。
  • 使用方式：部署电脑端服务，通过私有网络连接 iOS App 与本地会话。
  • 许可：MIT，非官方 Claude Code 客户端。
