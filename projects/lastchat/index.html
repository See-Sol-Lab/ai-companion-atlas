PROJECT INTRO

项目介绍

LastChat 是一款功能丰富的 Android AI 客户端。它支持多供应商与自定义接口、图片视频音频输入、RAG 长期记忆、Web 搜索、MCP、图像生成、TTS，以及无限角色的创建、标签、导入和导出。

应用提供 PRoot Linux 工作区中的 Python 环境和 QuickJS JavaScript 引擎，聊天与向量记忆保存在本机，并可通过 WebDAV 备份。项目是 RikkaHub 的独立命名 fork，README 明确署名上游，并说明其重做 UI 与新增功能。

  • 适合：需要 Android 多模型客户端，同时重视本地记忆、角色管理和脚本执行的人。
  • 平台：Android。
  • 使用方式：安装后配置模型供应商，按需建立角色、启用记忆、搜索、MCP 与本地工作区。
  • 许可：AGPL-3.0；图像裁剪组件另有上游来源说明。
