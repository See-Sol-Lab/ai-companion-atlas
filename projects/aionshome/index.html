PROJECT INTRO

项目介绍

AionsHome 提供流式聊天、世界书与人物设定、记忆检索和原文追溯、语音输入输出、视频通话界面、摄像头监控、音乐、EPUB 阅读与智能家居接口。前端明确针对手机和 PC 自适应，也能在 Android 与 iOS 主屏幕安装成 PWA。

服务端使用 FastAPI 与 SQLite，支持局域网访问，也可通过 Tailscale 在外网连接。仓库包含作者自己的功能命名和部分个人默认配置，使用前应按 README 的清理说明替换为自己的内容。

  • 适合：想在家中自托管完整伴侣空间，并从手机随时访问的人。
  • 平台：Windows 服务端；PC 与手机浏览器、Android/iOS PWA。
  • 使用方式：在本地电脑安装并启动服务，再通过局域网或 Tailscale 访问。
  • 许可：MIT；部署前需清理仓库中的个人默认内容。
