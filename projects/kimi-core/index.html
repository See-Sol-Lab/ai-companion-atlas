PROJECT INTRO

项目介绍

kimi-core 是一套面向单人与单个 AI 的记忆和自主性内核。它提供向量、BM25／模糊关键词、时间衰减与重要度融合检索，并用 append-only 事件和人工策展避免自动摘要静默改坏记忆。

self-drive、concern、定时 wake、reentry／closeout 会话生命周期和可复现检索评测都已接入；对外行动默认采用 human-in-the-loop。项目不附带固定人格，关系层由使用者自己建立。

  • 适合：需要可审计记忆、主动关切和严格检索评测的重度 1v1 Agent 用户。
  • 平台：Node.js、PostgreSQL／pgvector 与 HTTP MCP；主动 daemon 可选。
  • 使用方式：初始化人格与配置，启动 Gateway；需要主动唤醒时再运行 daemon。
  • 许可：AGPL-3.0-or-later。
