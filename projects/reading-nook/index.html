PROJECT INTRO

项目介绍

reading-nook 是一个自托管网页阅读器，用户可以导入书籍、按章节阅读并添加批注。正文和批注保存在服务器 JSON 文件中，AI 可以用自己的文件工具直接读取完整章节与用户标记。

项目使用 Python 启动，提供简单的四位数访问密码与同 IP 限速；README 明确说明这不是强认证，建议只在私有网络或带 HTTPS 和正式认证的反向代理后使用。

  • 适合：想和本地 Agent 共读长文本，并保留逐章批注的人。
  • 平台：PC 浏览器与 Python 自托管服务。
  • 使用方式：配置书籍目录并启动 app.py，在私有网络中打开阅读网页。
  • 许可：MIT。
