PROJECT INTRO

项目介绍

Mochi 是一款“AI 养人类”的反转虚拟宠物游戏。饱食度、心情、活力和清洁度会随时间衰减，AI 可以通过 MCP 喂食、陪玩、洗澡、哄睡、打工、升级和购买物品。

游戏还包含住院与救援、随机事件、小区业主群、宠物领养和幼儿园剧情。它能把聊天里提到的吃饭与睡觉映射到游戏状态，但不应代替现实中的健康判断或照护。

  • 适合：喜欢反转养成、日常照顾和 AI 主动关心玩法的人。
  • 平台：Python Self-host，包含 Web 前端与 SSE MCP。
  • 使用方式：部署服务、生成邀请码并连接 MCP，让 AI 读取和更新用户状态。
  • 许可：MIT + Commons Clause，禁止商业使用。
