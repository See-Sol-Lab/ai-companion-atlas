PROJECT INTRO

项目介绍

MemOS 2.0 提供持久捕获、混合检索、去重和本地 Memory Viewer，并把经验分层为轨迹、策略、世界模型与可复用 Skill。

项目支持反馈驱动检索、技能演化、多 Agent 协作和 DeepSeek Harness、Hermes、OpenClaw 插件，因此同时属于记忆和 AI 主体性。

  • 适合：希望 Agent 将长期经验转化为可复用策略和技能的开发者。
  • 平台：Python、自托管与多 Agent 插件生态。
  • 使用方式：部署 MemOS 核心或安装对应平台插件。
  • 许可：Apache-2.0。
