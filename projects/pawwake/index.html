PROJECT INTRO

项目介绍

Pawwake（原 AI Memory Gateway）是一个 OpenAI 兼容转发网关。它提供碎片、事件、核心三层记忆，支持自动提取、AI 整理、手动合并、撤回来源和关键词＋向量混合搜索。

项目还管理跨平台对话线、历史记录、Token 统计和 A/B 分区缓存，并把程序 API 与 Dashboard 登录分开鉴权。客户端只需改 API 地址即可接入。

  • 适合：使用 Kelivo、ChatBox、NextChat 等客户端，想同时获得记忆与缓存优化的人。
  • 平台：Python Self-host + PostgreSQL；兼容任意 OpenAI 格式客户端与模型。
  • 使用方式：先部署纯转发网关，再按需接数据库、记忆、向量搜索与分区缓存。
  • 许可：AGPL-3.0。
