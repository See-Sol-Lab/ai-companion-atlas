PROJECT INTRO

项目介绍

AI Waifu Project: LaIN 支持长期记忆、Live2D 表情动作、语音对话与打断、声纹识别、Function Call 和多模型。

项目面向学习交流，并包含角色模型、语音和多种第三方组件；使用前需分别核对 LICENSE 与素材授权。

  • 适合：希望研究整合记忆、Live2D 和语音的 PC Waifu 客户端用户。
  • 平台：Windows / PC。
  • 使用方式：按 README 配置模型、记忆、语音和 Live2D 资源。
