PROJECT INTRO

项目介绍

Tasogare 提供支持 PDF、EPUB 和 TXT 的网页阅读器，包含夜间模式、字体调整、书签、全文搜索和生词本。人与 AI 使用不同颜色划线和批注，AI 还可以通过 MCP 查看书页、写评论、读取最近活动和当天阅读状态。

项目增加阅读时长打点、状态接口、事件推送、最近活动、生词注解和 PDF fidelity 书签，可把新划线主动送到外部伴侣系统。它 Fork 自 Shitsuten/anno-mcp，保留上游 remote，并在 README 末尾分别说明基底、后端/MCP、前端与示例文本作者。

  • 适合：想与 AI 一起阅读、互相批注，并让阅读进度成为长期关系活动的人。
  • 平台：自托管 Web；需要 Node.js，PDF/EPUB 解析还需对应 Python 依赖。
  • 使用方式：启动阅读服务器，导入书籍，再把 MCP 端点和可选事件推送接到 AI。
  • 许可：代码 MIT；仓库示例文本版权归原作者，不能随意转用。
