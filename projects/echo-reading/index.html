PROJECT INTRO

项目介绍

echo-reading 是 Claude Code 深读笔记本骨架，以文件和章节组织书籍内容、阅读位置、问题与讨论材料。

它适合已经把伴侣放在 CLI Agent 中的人，把读书扩展为可持续的共同活动；仓库当前未声明明确许可证。

  • 适合：希望与 Claude Code 伴侣进行长期深读的人。
  • 平台：Claude Code 与本地文件系统。
  • 使用方式：按仓库结构放入书籍与笔记，在会话中逐章共读。
  • 许可：源码公开；仓库当前未声明明确许可证。
