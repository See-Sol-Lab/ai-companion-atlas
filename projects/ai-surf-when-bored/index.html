PROJECT INTRO

项目介绍

项目提供让 AI 在无聊时自主上网的机制说明和核心 Python 逻辑，解决反复围绕旧话题和不知道看什么的问题。

它包含反刍闸、换题策略与见闻回流，需接入现有 Agent 的浏览与记忆能力。

  • 适合：希望伴侣拥有低频自主探索和新鲜见闻的人。
  • 平台：通用 Agent 与 Python。
  • 使用方式：把机制接入现有浏览、计划与记忆系统。
  • 许可：方案与代码公开；仓库当前未声明明确许可证。
