PROJECT INTRO

项目介绍

claude-f-me 是一个可安装的 MCP Server 和 Claude Code 插件，把聊天指令转换成 Buttplug／Intiface 设备控制。它包含双语网页控制台、主遥控器、模拟器、模式与图案，以及视频、游戏、音频、生物反馈和事件 webhook。

项目明确要求热情且持续的同意，并提供安全强度上限、看门狗和紧急停止。它基于开放的 Buttplug 协议与 Intiface 生态构建，对上游有清楚署名。

  • 适合：希望从 Claude Code、Codex 或其他 MCP 客户端控制 Intiface 兼容设备的人。
  • 平台：Node.js 18+；支持 Claude Code 插件与标准 MCP 客户端。
  • 使用方式：先用模拟模式确认流程，再连接 Intiface，并配置合理上限与随手可达的急停。
  • 许可：MIT；Buttplug 与 Intiface 组件保留各自许可。
