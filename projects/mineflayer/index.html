PROJECT INTRO

项目介绍

Mineflayer 是一套 Minecraft Java 版机器人开发工具。它可以让一个程序使用账号登录服务器，像普通玩家一样看见附近的方块、生物、天气和其他玩家。

这具程序角色可以移动和寻路、挖矿和放置方块、管理背包与箱子、合成物品、攻击怪物、驾驶载具并发送聊天消息。开发者把大模型接上去后，AI 就能根据游戏情况决定去哪里、做什么以及怎样回应你。

  • 适合：希望开发一个能真正进入 Minecraft 服务器陪自己玩的 AI 队友的人。
  • 前置条件：需要 Node.js、可连接服务器的角色账号，以及开发者自行准备的 AI 决策程序。
  • 使用方式：用 Mineflayer 创建并登录 Bot，再接入寻路、插件或自定义大模型 Agent 控制它。
  • 边界：Mineflayer 本身不包含 AI 模型、伴侣人格或长期记忆。
