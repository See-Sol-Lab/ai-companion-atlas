PROJECT INTRO

项目介绍

Mineflayer 是成熟的 Minecraft Bot 高层 API，支持多个游戏版本，提供实体与方块感知、物理移动、攻击、载具、背包、合成、挖掘、建造、使用物品和聊天。

它本身不包含伴侣人格或 LLM 循环，但已有 MCP、寻路、网页视图、状态机等插件，是让 AI 进入 Minecraft 的常用底层载体。

  • 适合：想把自己的 AI 伴侣接入 Minecraft，并自行设计决策循环的人。
  • 平台：Node.js 18+，连接 Minecraft Java 版服务器。
  • 使用方式：创建 Bot、连接服务器，再组合 pathfinder、MCP 或自定义 LLM Agent。
  • 许可：MIT。
