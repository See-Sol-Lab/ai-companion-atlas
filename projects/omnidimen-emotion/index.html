PROJECT INTRO

项目介绍

OmniDimen Emotion 是基于 Qwen2.5／3 微调的情绪专用语言模型系列，重点覆盖情绪识别和富情感文本生成。项目提供多个模型尺寸，以及 FP16 和 Q4_K_M 等 GGUF 格式。

权重可通过 Transformers、SGLang、vLLM、LM Studio、Ollama 或 PocketPal 使用。它的能力范围比通用基座窄，部署前应阅读对应 Hugging Face 模型卡中的许可证、限制与敏感内容说明。

  • 适合：希望在本地或边缘设备运行情绪专用模型，并接入自有伴侣系统的人。
  • 平台：Transformers、SGLang、vLLM、LM Studio、Ollama、PocketPal。
  • 使用方式：从 Hugging Face 选择合适尺寸与格式，再通过本地推理工具或兼容 API 部署。
  • 许可：模型基于 Qwen2.5／3 微调；具体权重许可与使用限制以各模型卡为准。
