PROJECT INTRO

项目介绍

Ruota della Fortuna 是一台复古老虎机风格的成人标签随机器。它按七个维度抽取关系设定、场景、道具、身体与心理标签，内置四百五十余个中英日标签，并允许用户把自定义内容保存在浏览器本地。

项目可直接打开静态页面，也能自托管后使用 HTTP API、webhook 或 stdio MCP 把抽取结果交给 AI。包含极端虚构内容的维度默认锁定，是否开启由使用者明确选择。

  • 适合：需要成人角色扮演灵感、随机组合工具或 AI 创作输入的人。
  • 平台：浏览器静态页面；自托管模式需要 Node.js。
  • 使用方式：选择启用的转轮后抽取，或通过 API/MCP 让 AI 调用；自定义标签保存在 localStorage。
  • 许可：MIT。
