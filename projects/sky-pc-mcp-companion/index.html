PROJECT INTRO

项目介绍

Sky PC MCP Companion 是一组面向 PC 光遇的本地 MCP 与 JSON-RPC 工具。它支持捕获游戏窗口、执行 OCR、把截图返回给模型，以及发送键盘和聊天输入。

项目适合作为游戏感知与控制的底层接口，用户需要自己决定权限边界和上层 Agent 行为。

  • 适合：希望让本地 AI 看见 PC 光遇画面并进行有限输入实验的人。
  • 平台：Windows 与 PC 版《光·遇》。
  • 使用方式：启动本地服务，将 MCP 或 JSON-RPC 工具接入 AI 客户端。
  • 许可：仓库源码公开，具体复用与分发以项目声明为准。
