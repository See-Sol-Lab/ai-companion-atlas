PROJECT INTRO

项目介绍

whale-listen 将常见音频文件分析为机器可读 JSON，包含音符音高、开始时间、时值、力度、密度图、音高曲线、和弦与静默结构。

伴侣可以用这些数据讨论旋律变化、节奏密度和段落结构，或把一起听过的音乐转成可保存、可比较的共同材料。

  • 适合：希望 AI 理解纯音乐、旋律和节奏结构的共听场景。
  • 平台：Python CLI，支持常见桌面系统。
  • 使用方式：输入 MP3、WAV 或 FLAC，生成结构化 JSON 交给模型读取。
  • 许可：MIT。
