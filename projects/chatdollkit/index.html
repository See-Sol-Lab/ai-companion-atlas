PROJECT INTRO

项目介绍

ChatdollKit 是 Unity 虚拟角色 SDK，支持 ChatGPT、Claude、Gemini 等模型及 Function Calling、多模态、STT、TTS、唤醒词和语音打断。

它能自主控制 3D 模型的口型、表情和动作，并运行在桌面、iOS、Android、VR、AR 与 WebGL。

  • 适合：希望把 3D / VRM 角色做成语音 Agent 的 Unity 开发者。
  • 平台：Unity 支持的桌面、移动端、VR、AR 与 WebGL。
  • 使用方式：把 SDK 导入 Unity 项目，再配置模型、语音和角色动画。
  • 许可：Apache-2.0。
