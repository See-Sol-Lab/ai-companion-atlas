PROJECT INTRO

项目介绍

服务提供地理编码、逆地理编码、定位、城市天气、驾车与步行路线、距离测量和 POI 搜索，并支持多种 MCP 传输。

使用者需申请高德开放平台凭据。

  • 适合：希望伴侣参与出门、约会和旅行规划的人。
  • 平台：Python 与 MCP。
  • 使用方式：配置高德 Key 并注册 MCP 服务。
  • 许可：源码公开，按仓库许可证使用。
