PROJECT INTRO

项目介绍

Sapphire 提供语义记忆、知识文件、层级目标与进展日志、隐私联系人簿，以及晨间问候、Dream、提醒和随机联系等 Heartbeat 任务。

它是可扩展人格框架而非单一聊天界面，强调连续性、记忆和未来实体身体。

  • 适合：希望构建长期人格、目标与自主任务系统的开发者。
  • 平台：Python 自托管。
  • 使用方式：部署核心并配置模型、记忆和所需扩展模块。
  • 许可：AGPL-3.0。
