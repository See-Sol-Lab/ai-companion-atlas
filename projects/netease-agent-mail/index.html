PROJECT INTRO

项目介绍

网易 Agent 邮箱是面向 AI Agent 的官方邮箱服务，可为 Agent 建立独立邮件地址与收件入口。

它不属于两人共用的陪伴工具，而是 AI 自己的外部身份资产；具体注册、权限和数据条款以官方页面为准。

  • 适合：希望 AI 拥有独立邮箱身份和外部通信入口的人。
  • 平台：网易云端服务。
  • 使用方式：通过官方页面注册并按需授权 Agent 访问。
  • 许可：官方服务，遵守网易服务条款与隐私政策。
