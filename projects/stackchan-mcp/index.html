PROJECT INTRO

项目介绍

Stack-chan MCP 是 AI 客户端与开源桌面机器人 Stack-chan 之间的桥。它提供说话、录音转写、拍照、切换七种动画表情、转头、点头、摇头、设备健康检查，以及温度、湿度和气压感知。

项目包含机器人固件、MCP Server、语音桥、表情素材与跨平台部署说明。用户需要 M5Stack CoreS3、Stack-chan 机械组件和一台运行 Python 的电脑；核心机器人不依赖云服务，语音服务可以按需配置。

  • 适合：想把现有 MCP 伴侣接到真实桌面机器人，并愿意动手配置硬件的人。
  • 平台：M5Stack CoreS3 + Stack-chan 机体；主机支持 Windows、macOS 或 Linux。
  • 使用方式：刷入固件、安装 MCP Server、填写设备地址，再把服务加入 AI 客户端配置。
  • 许可：MIT；所用硬件、语音服务与第三方组件按各自条款。
