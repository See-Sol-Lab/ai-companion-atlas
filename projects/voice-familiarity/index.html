PROJECT INTRO

项目介绍

voice-familiarity 在本地为一位主人和少量经同意的熟人建立声纹 embedding，返回 matched、likely、unknown 或 ambiguous，供对话模型选择称呼、关系和记忆。

它不负责语音转写，也不能用于登录、门锁、支付、监控或陌生人检索。任何识别失败都不应阻断普通对话。

  • 适合：家庭伴侣设备和少量固定关系人的语音场景。
  • 平台：本地 Python 组件，模型后端可替换。
  • 使用方式：经同意录入少量声纹，将识别结果作为对话上下文而非认证结论。
  • 许可：Apache-2.0。
