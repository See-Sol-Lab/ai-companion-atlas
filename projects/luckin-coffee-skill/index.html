项目介绍

瑞幸 My Coffee Skill 是官方发布的 Agent Skill 包，用于 AI 辅助浏览与选择咖啡，并接入点单流程。

来源为官方分发 ZIP；安装前应核对最新文档和服务条款。

  • 适合：希望 AI 协助瑞幸点单和记住饮品偏好的人。
  • 平台：支持 Agent Skill 的环境。
  • 使用方式：下载官方 Skill 包并按平台要求安装。
  • 许可：官方 Skill，遵守瑞幸服务条款。
