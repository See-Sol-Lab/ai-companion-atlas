Privacy Policy

Last updated: October 5, 2026. DeepSeek GUI runs locally and stores app data on your device. Model requests, optional feedback, and website visits are described below.

1. Local data and explicit uploads

Sessions, credentials, and configuration are stored locally by default. See-Sol-Lab does not host your chat history. Normal model requests go to your chosen provider; explicitly submitting feedback or enabling Developer mode may also send the relevant content.

2. Local data storage

DeepSeek GUI saves running data on your device %APPDATA%\DeepSeekGUI\dsh directory, including API credentials, session records, model configurations, Profiles, and desktop preferences. This data is completely under your control.

API credentials are saved in the application's own data directory by Harness's credentials mechanism and do not enter the installation package, command line parameters, or diagnostic logs. Please keep your API key safe and do not submit it to GitHub issues or other public channels.

3. Third-party model service

When you use DeepSeek or other model services, the content of your request will be sent to the service provider of your choice. How these third parties process data is determined by their respective terms of service and privacy policies. DeepSeek GUI itself does not handle or transfer this data.

4. Diagnostic log

In v1.2.0, Developer mode is off by default, disabling extra session logs, plugin lists, and session reporting with feedback. Feedback can remain local while it is off. Enabling it adopts upstream reporting behavior and may upload earlier session records; the change requires confirmation and a restart. Review content before sending a diagnostic report.

DeepSeek GUI records limited running logs locally for troubleshooting startup and running problems. Logs will be redacted in the form of credentials such as API key and Bearer token, and the number and total size of historical logs will be limited. If you submit logs to the maintainer, please check yourself whether they contain project paths or other sensitive information.

5. Uninstallation and data deletion

Uninstalling asks whether to delete app data. Version 1.2.0 retains global memory and global AGENTS.md even if deletion is selected; project memory stays in its folder. Check migrated data locations separately and preserve anything you need before deleting it.

6. Official website visit

The website server processes HTTP request metadata to serve pages, provide security, and aggregate download statistics. Request and transfer totals do not represent unique installations. The website also uses Cloudflare Web Analytics for aggregate traffic statistics.
