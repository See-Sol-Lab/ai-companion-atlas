FIRST RUN

If you encounter a blue pop-up window, continue the installation in two steps.

After double-clicking the installation package, Windows will pop up "Your computer has been protected". This pop-up window only displays the "Don't Run" button by default. You need to click "More Information" first before the Run button will appear.

  1. The first step

    Click in the lower left corner More information. This is an inconspicuous text link and can easily be ignored.

  2. The second step

    After the pop-up window is expanded, more still needs to run button, click it to start the installation.

This prompt comes from Windows' default blocking of unsigned applications. The SHA256 checksum of the installation package is published in GitHub Release page, you can check it before installing. Code signing will be added in subsequent versions.
