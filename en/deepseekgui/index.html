FROM INSTALL TO WORK

Install, select a folder, and start.

Harness originally had to install Node.js, run the command line, and open localhost in the browser. DeepSeek GUI packages all of these - after installation, it is a desktop application that can be opened directly.

01 · INSTALL

Sign in right after installing

Installs for the current user with normal permissions. On first launch, sign in with a DeepSeek account or enter an API key, then pick a folder and start.

02 · WORKBENCH

Project status is next to

View file changes, branches, commits, worktrees, and project memories directly next to the session without repeatedly switching back to the command line for confirmation.

03 · LOCAL DATA

Collaboration experience remains local

Credentials, settings, sessions, and global memory exist in the application data directory; when managed data needs to be moved, it can be copied, verified, and switched.

HARNESS-FIRST

v1.1.2 catches up with official Harness 0.1.7.

The workbench still extends the official Harness client, and sessions, tools, and permissions follow upstream. On top of that it adds account sign-in, engineering memory, a skill library, and a set of safety protections.

Account sign-in and usage

Sign in with a DeepSeek account and start working, no API key needed. Settings shows your balance, top-up, and spending, requests, and token usage for today, 7 days, and 30 days.

SIGN IN · BALANCE · USAGE
Engineering memory and skill library

Project facts and preferences are kept as versioned memories you can view, correct, forget, and undo. Skills are imported from a folder or ZIP and enabled per project.

MEMORY · SKILLS · PROJECTS
Protected locations and verified updates

Anything that touches system files, installed programs, or the app's own code goes through a red approval. Updates are checked against SHA-256 after download and install only after you confirm.

PROTECT · VERIFY · UPDATE
