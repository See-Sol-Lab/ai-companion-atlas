PROJECT INTRO

Project introduction

dsh-toy is a private hardware plug-in for DeepSeek Harness. It supports Buttplug/Intiface, partial sharing link protocol and macOS read-only BLE broadcast discovery, and can expose dual-channel devices to Agent respectively.

The plug-in automatically stops in 30 seconds by default, and enforces maximum intensity and maximum duration before sending. It will stop output when uninstalling, disconnecting, or hot updating; global stop can shut down all devices at once. Its TypeScript implementation refers to the Public Protocol Observation and Buttplug specifications, and the source is stated in NOTICE.

  • Suitable for:Use DeepSeek Harness for those who wish to reduce manual protocol selection and preserve hard security constraints.
  • Platform:Node.js 22.19+ with DSH; macOS raw BLE discovery also requires Xcode Command Line Tools.
  • Usage:Install the plug-in, tell the Agent the brand and model, and then configure the intensity, duration and whether to allow continuous maintenance.
  • License:BSD-3-Clause; device protocol and upstream ecological reservations are explained separately.
