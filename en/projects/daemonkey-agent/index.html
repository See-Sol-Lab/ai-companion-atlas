PROJECT INTRO

Project introduction

Guardian Monkey is a complete set of AI companion software installed on your computer. After startup, it will open a local web chat interface; when you meet for the first time, you can give your partner a name, tell him or her what to call you, what you are doing, and what kind of companionship or help you want him or her to provide.

Subsequent conversations, character portraits, shared memories, and new abilities will be saved in the local data directory. Even if you close the web page, restart your computer, or change the model behind it, the guardian monkey will still load the original identity and memory.

  • Suitable for:People who want to run an AI companion with a web interface, relational memory, and tools on their computer for a long time.
  • Preconditions:Requires Python 3.10+ and a valid model API Key.
  • Usage:Start the local service, configure the model on the browser page and complete the first encounter, and then chat and use capabilities directly on the web page.
  • Data:Dialogues, portraits, memories and user extensions are saved locally; when calling an external model, the relevant dialogue content will still be sent to the selected model service provider.
