PROJECT INTRO

Project introduction

The local connector uses a pinned Tarot Ritual engine for questions, spreads, card draws, and readings. After the user accepts an invitation and uses the original interface, the agent can retrieve revealed cards and the original summary in a later turn. Automatic continuation requires host integration and is not guaranteed across clients.

Requires Node.js 24.5+, npm, Git, a WebGL2 desktop browser, and an agent with command and browser access on the same computer. AI readings require your own model service; card draws work without one. This listing is based on public documentation, not a hands-on installation test.

  • Suitable for:People who want to draw cards, discuss them, and reflect with an existing AI companion.
  • Platform:Windows 10/11 x64, macOS Intel / Apple Silicon, and Linux x64; requires a local host.
  • Usage:Run the bundled installer from source and integrate with your host. AI readings require separate model configuration and may incur charges.
  • License:The connector uses ISC; the Tarot Ritual engine and third-party assets retain their respective licenses.
