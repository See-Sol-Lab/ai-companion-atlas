PROJECT INTRO

Project introduction

Aelios is a long-term memory service deployed on Cloudflare. It uses D1 to save structured data, Vectorize for recall, and provides important memories, slang lists, diaries, and candidate review queues. Users can pass, discard, merge or replace candidate memories in the admin panel.

The system supports OpenAI compatible chat portal, MCP tools, Claude Code Hook, export and maintenance checks; by default, Workers AI can be used to complete embedding, reranking and nightly sorting. The design of the relationship diagram, fact versioning and spontaneous emergence part refers to LMC-5. The author states that it has been re-implemented according to the Cloudflare architecture without duplicating its code.

  • Suitable for:People who are willing to use Cloudflare's hosted memory and want to share, manually review, long-term facts across clients.
  • Platform:Cloudflare Workers + D1 + Vectorize + Queue。
  • Usage:Fork and then deploy with one click or manually, set the access key, and then access through chat Base URL, MCP or Hook.
  • License:The mainline is AGPL-3.0; the archived v1-final is still used under MIT.
