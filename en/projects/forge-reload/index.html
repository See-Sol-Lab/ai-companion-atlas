PROJECT INTRO

Project introduction

Forge Reload intercepts recent events from local JSONL, rebuilds the parent UUID chain, generates a new session that can be resumed, and can inject AI-written handover packages.

It directly operates the non-public session format and must be backed up before use; the Claude Code format may also become invalid after being updated.

  • Suitable for:Advanced users who need to migrate long Claude Code sessions to new sessions.
  • Platform:Claude Code local session file.
  • Usage:Make a full backup first, then press README to generate and verify a new session.
  • License:MIT, unofficial tool.
