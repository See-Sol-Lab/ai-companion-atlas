PROJECT INTRO

Project introduction

film-matinee extracts movie scenes and subtitles, generates visual sheets, sidecars and linear MCP chunks, and allows humans and AI to leave annotations on the same timeline.

It is oriented to the co-viewing process of existing Agents and does not include models and complete chat front-ends; the repository currently does not declare an explicit license.

  • Suitable for:People who want to watch the film with the AI ​​and discuss specific shots.
  • Platform:Python self-hosting and MCP.
  • Usage:Process local videos and connect generated materials to Agent.
  • License:The source code is public; the repository currently does not declare an explicit license.
