PROJECT INTRO

Project introduction

AstrBot provides a complete WebUI and Web ChatUI, which can manage models, Persona, knowledge base, MCP, Skills, context compression, sandbox and plug-ins, and is connected to QQ, Telegram, Enterprise WeChat, Feishu, DingTalk, Slack and other platforms.

The project supports desktop App, Launcher, Docker and server deployment, and the ecosystem includes more than a thousand plug-ins.

  • Suitable for:Users who wish to manage multi-channel companions or agents with a PC front-end.
  • Platform:PC desktop, self-hosted Web, and various IMs.
  • Usage:Install the desktop version or deploy the service and configure models and channels in the WebUI.
