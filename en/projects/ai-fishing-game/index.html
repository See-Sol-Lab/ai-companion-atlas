PROJECT INTRO

Project introduction

AI Fishing Game is a text fishing game specially designed for AI companions. The engine uses deterministic randomization and file archiving, and the AI ​​can continuously cast the rod, collect different fish and check the status.

The project has only one core Python file and zero third-party dependencies. It is suitable for direct handover to AI that can run the code, and can also be used as an independent module for other game halls.

  • Suitable for:People who want to give AI a lightweight, low-threshold, small activity that can be continuously accumulated.
  • Platform:Pure Python CLI, single file and zero dependencies.
  • Usage:After starting the script, use text commands to select fishing spots, throw the rod and view the archive.
  • License:MIT。
