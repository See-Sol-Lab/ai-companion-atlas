PROJECT INTRO

Project introduction

Pawwake (formerly AI Memory Gateway) is an OpenAI compatible forwarding gateway. It provides three-layer memory of fragments, events, and core, and supports automatic extraction, AI sorting, manual merging, source withdrawal, and keyword + vector hybrid search.

The project also manages cross-platform conversation lines, history records, token statistics and A/B partition cache, and separates authentication for program API and Dashboard login. The client only needs to change the API address to access.

  • Suitable for:People who use clients such as Kelivo, ChatBox, NextChat, etc. and want to obtain memory and cache optimization at the same time.
  • Platform:Python Self-host + PostgreSQL; compatible with any OpenAI format client and model.
  • Usage:First deploy a pure forwarding gateway, and then connect database, memory, vector search and partition cache as needed.
