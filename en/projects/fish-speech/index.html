PROJECT INTRO

Project introduction

Fish Speech is a multi-language generative TTS system that supports reference timbre cloning, long text speech generation, self-hosted inference and training, and provides command line, service interface and WebUI.

It is suitable for partner's voice reply, reading and voice message output; the code and model weights are currently subject to the Fish Audio Research License.

  • Suitable for:Speech projects that value naturalness and multilingual capabilities, and can self-host GPU inference.
  • Platform:Python with GPU self-hosted environment.
  • Usage:Download the model, start the inference service or WebUI, and then call it from the companion front end.
  • License:Fish Audio Research License, please check research and distribution boundaries before use.
