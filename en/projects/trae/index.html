PROJECT INTRO

Project introduction

Trae is an AI programming software launched by ByteDance. During normal development, it can complete code, answer project questions, find bugs and modify files; when you want to start from scratch, you can also directly describe websites, applications or functions in natural language.

In modes such as SOLO or Builder, AI splits tasks according to goals, generates projects, runs commands, and displays web page effects. Users still need to check the generated code and final results before deciding whether to adopt it.

  • Suitable for:People who want AI to assist in daily programming, or who want to use natural language to create websites, applications, and office tools.
  • Usage:Download the client from the domestic official website, open an existing project or create a new workspace and directly describe the task.
  • Main abilities:Code completion, project Q&A, troubleshooting, automatic task execution, project generation and web page preview.
  • Fees:Available models, free quotas and packages may be adjusted, subject to the current instructions on Trae’s official website.
