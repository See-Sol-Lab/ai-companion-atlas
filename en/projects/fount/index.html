PROJECT INTRO

Project introduction

fount is not a single AI character, nor a model service, but a studio used to create and run AI characters. After connecting to the model API, you can create or import a character, and then configure the personality, worldview, behavioral logic, and available tools.

The completed character can stay in the fount to chat, and can also be connected to mobile phones, browsers, Telegram, Discord, IDEs and terminals. Cross-platform is just a different entrance for characters; what this project really solves is how to deeply customize and use your own AI characters for a long time.

  • Suitable for:People who are willing to spend time deeply customizing their characters and hope that their personality will not just stay in a prompt word.
  • Usage:Install fount, connect to the model API, then create or import the character and configure the required parts.
  • Usage threshold:It has many functions and requires certain learning and coding foundation; people who just want to chat immediately will find it complicated.
  • License:The source code is open to the public; see the project LICENSE for specific license terms.
