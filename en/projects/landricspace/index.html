PROJECT INTRO

Project introduction

LandricSpace organizes functions around "a home with a small AI", including single chat and multi-role rooms, relationship status, anniversaries, joint travel planning, music, photo albums and life records. The front end can run in the browser and can also build Android APKs and iOS Apps.

The project consists of the Expo client and the Node.js server. Chat and life data are saved in the self-hosted backend. There is still a gap between the description of multiplayer online in the README and the current implementation. At this stage, it is more suitable to be understood as a companion space for single-person use; the project prohibits unauthorized commercial use.

  • Suitable for:People who want to make their partnership into a multi-room, multi-living module space.
  • Platform:Web, Android and iOS.
  • Usage:Deploy the Node.js server first, then start the Web or build the Expo native client.
  • License:The source code is open to the public, and the README explicitly prohibits unauthorized commercial use.
