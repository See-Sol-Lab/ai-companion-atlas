PROJECT INTRO

Project introduction

LingChat supports independent archiving and permanent memory, self-developed emotion recognition, dynamic facial expressions, character clothing and touch interaction, VITS voice, multi-character scripts and bonding systems, and has built-in Pomodoro, schedule and to-do.

Desk pet mode can observe desktop work, games or idle status, and actively initiate conversations accordingly. The project provides a Windows installation package and also opens the Tauri front-end source code.

  • Suitable for:Windows users who prefer the company of Galgame performances, table pets, and highly visual characters.
  • Platform:Windows 10 64-bit and above.
  • Usage:Download the program from Releases and configure your own model API after first launch.
