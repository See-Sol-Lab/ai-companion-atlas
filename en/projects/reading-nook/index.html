PROJECT INTRO

Project introduction

reading-nook is a self-hosted web reader that allows users to import books, read by chapters, and add annotations. The text and annotations are saved in the server JSON file, and AI can directly read the complete chapters and user tags using its own file tools.

The project is started using Python, providing a simple four-digit access password and speed limit for the same IP; the README clearly states that this is not a strong authentication, and it is recommended to only be used in a private network or behind a reverse proxy with HTTPS and formal authentication.

  • Suitable for:People who want to read long texts with the local Agent and retain chapter-by-chapter annotations.
  • Platform:PC browser and Python self-hosted service.
  • Usage:Configure the book directory and start app.py to open the reading web page in the private network.
  • License:MIT。
