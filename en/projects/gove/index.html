PROJECT INTRO

Project introduction

Gove provides a multilingual male voice model based on GPT-SoVITS, which can be used for Chinese, English and Japanese text-to-speech. The repository contains model descriptions and usage examples.

It requires an off-the-shelf GPT-SoVITS environment and does not undertake separate training or inference frameworks. The repository currently does not give a clear license, and you need to confirm with the project page before using and redistributing the weights.

  • Suitable for:have deployed GPT-SoVITS and are in need of ready-made multilingual male voices.
  • Platform:GPT-SoVITS inference environment.
  • Usage:Download the model weights and put them into GPT-SoVITS according to README for inference.
  • License:Model weights are public; the repository currently does not declare a clear license.
