PROJECT INTRO

Project introduction

Claude Code is Anthropic's official terminal Agent, which can understand code libraries, edit files, run commands, handle Git workflows, and is extended by MCP, hooks, skills, and Channels.

It is a general-purpose development tool in its own right, but has become the running host for many local companion systems. Use and license are governed by Anthropic Official Terms.

  • Suitable for:Agent users who require strong local tool capabilities, terminal sessions, and extended ecosystem.
  • Platform:Windows, macOS, and Linux.
  • Usage:Install and log in according to the official method, and then configure the project, MCP and permissions.
  • License:Anthropic official tool, used according to the repository LICENSE and terms of service.
