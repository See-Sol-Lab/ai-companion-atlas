PROJECT INTRO

Project introduction

Gongdu Xiaowo is geared towards reading novels and comics. It records the current progress, remedial class intervals, bookmarks, excerpts and short comments, and provides these reading statuses to AI through ChatGPT Apps SDK and MCP. Partners can continue the discussion around the true reading position.

The project includes web front-end, server and sharing protocols, using Cloudflare D1 and R2 to save structured data and media. The repository exposes the running code and license files, but the license terms need to be confirmed one by one according to the project files.

  • Suitable for:People who want to read novels and comics with AI on their mobile phones and keep the common progress.
  • Platform:Mobile-first web front-end, combined with the ChatGPT Apps SDK.
  • Usage:Follow the README to configure web, MCP services with Cloudflare D1/R2.
  • License:The source code is open to the public; the repository also provides LICENSE and License files, and you should check the specific terms before use.
