PROJECT INTRO

Project introduction

Yorishiro is a visual terminal front-end made specifically for macOS. It will automatically launch Claude Code or Codex that you have installed and logged in, and put the real terminal and a VRM role into the same window. There is no need to submit an API Key to Yorishiro.

You still let the Agent read files, write code, and run commands as usual. The character will observe the terminal status: change its gaze when thinking, change its expression when reporting an error, light up when your approval is needed, and react when the work is completed.

  • Suitable for:Using Claude Code or Codex on Mac, I hope to see an AI character with expressions and actions while working.
  • Preconditions:Claude Code or Codex needs to be installed and logged into the computer first.
  • Usage:Install Yorishiro, select the Agent to start, and you can use the terminal and VRM roles in the same window.
  • Memory:You can save a diary by Persona and accumulate important experiences into memories.md; this is an additional feature.
