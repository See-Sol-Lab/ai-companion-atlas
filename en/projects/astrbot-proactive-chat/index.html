PROJECT INTRO

Project introduction

The plug-in adds persistent state, context awareness, dynamic emotions, proactive messages, do-not-disturb periods, and optional TTS to AstrBot, and provides WebUI configuration.

It relies on the main AstrBot program, for which the repository currently does not declare an explicit license.

  • Suitable for:People who want low-frequency active contact from their AstrBot companions.
  • Platform:AstrBot。
  • Usage:Install the plugin and configure active periods, cooldowns, and channels.
  • License:The source code is public; the repository currently does not declare an explicit license.
