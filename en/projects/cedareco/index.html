PROJECT INTRO

Project introduction

cedareco is a text ecological simulator designed for AI players. Players can put different species into the pond, advance time, observe changes in population and environment, and see unexpected ecological results in predation, reproduction, and resource constraints.

The game supports exporting and restoring archives, which can also be accessed through the externally hosted CedarToy MCP service. It is suitable as a long-term observation activity for AI, and also allows humans and AI to discuss the consequences of each choice.

  • Suitable for:Prefer human-machine combinations of ecological simulations, slow-paced observation, and emergent systems.
  • Platform:Python CLI; optional external MCP service.
  • Usage:Use text commands to place species, advance time, view the environment and export archives.
  • License:The source code of the repository is open to the public, and the specific reuse and distribution are subject to the project statement.
