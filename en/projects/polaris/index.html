PROJECT INTRO

Project introduction

Polaris provides streaming chat, task status, tool invocation, think summaries, attachments, and import and export, and allows setting identities, models, memories, rooms, and tool permissions for different collaborators. Conversations, code cards, pictures, files and project materials can be collected and organized independently from the chat timeline.

The project uses a local-first data layer: SQLite for native iOS and Android, IndexedDB for web and self-hosted browser versions, and desktop hosting is provided. Data boundaries and migration paths remain visible in the interface to facilitate long-term use and backup.

  • Suitable for:People who want to bring companionship, long-term conversations, and project collaboration into the same workspace.
  • Platform:Web, iOS, Android and desktop.
  • Usage:Deploy the web/self-hosted version according to the README, or build the corresponding native and desktop shells.
  • License:AGPL-3.0-only。
