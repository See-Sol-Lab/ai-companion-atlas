PROJECT INTRO

Project introduction

The service provides geocoding, reverse geocoding, positioning, city weather, driving and walking directions, distance measurement, and POI search, and supports multiple MCP transports.

Users need to apply for Amap open platform credentials.

  • Suitable for:People who want their partners to be involved in planning outings, dates, and travel.
  • Platform:Python and MCP.
  • Usage:Configure the Amap Key and register the MCP service.
  • License:The source code is open to the public and can be used under the repository license.
