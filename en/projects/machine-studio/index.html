PROJECT INTRO

Project introduction

The machine's independent studio is a technical memory library for AI. The author originally put emotional, daily and technical content in OmbreBrain, but later found that technical information would frequently expire, so he separated them separately and saved progress, conclusions and pitfalls by project.

It provides tools for saving, searching, updating, project timeline, and true deletion through MCP, as well as a web workbench. SQLite and keyword search are used by default; local vector search can be added if needed.

  • Suitable for:People who already have a long-term AI companion or Agent and want to manage working technical memory and emotional relationship memory separately.
  • Relationship with Ombre Brain:The project is an independent technical sub-library designed for Ombre Brain, but it is not its built-in plug-in and can also be deployed separately.
  • Network security:The service listens to 0.0.0.0 by default; Bearer Token should be set when using the public network. The web page also supports login sessions and basic security restrictions.
