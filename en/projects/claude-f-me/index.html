PROJECT INTRO

Project introduction

claude-f-me is an installable MCP Server and Claude Code plug-in that converts chat commands into Buttplug/Intiface device control. It includes a bilingual web console, master remote, emulator, modes and graphics, as well as video, gaming, audio, biofeedback and event webhooks.

The project explicitly requires enthusiastic and ongoing consent and provides for safety intensity caps, watchdogs, and emergency stops. It is built based on the open Buttplug protocol and Intiface ecosystem, with clear signature to the upstream.

  • Suitable for:Persons wishing to control Intiface-compatible devices from Claude Code, Codex, or other MCP clients.
  • Platform:Node.js 18+; supports Claude Code plug-in and standard MCP client.
  • Usage:First use the simulation mode to confirm the process, then connect the Intiface, and configure a reasonable upper limit and an easily accessible emergency stop.
  • License:MIT; Buttplug and Intiface components retain their respective licenses.
