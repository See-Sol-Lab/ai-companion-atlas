PROJECT INTRO

Project introduction

ZCode is the official atmosphere programming desktop tool launched by Zhipu. Users can open an existing project or start from an empty directory and directly describe the website, application, game or function they want to create in natural language.

It will have an AI agent read the project, split it into steps, modify files, run commands and verify the results. Complex tasks can be continuously advanced through Goal, and multiple Agents can divide and collaborate without having to squeeze all operations into one conversation.

  • Suitable for:People who want to use natural language to make websites, applications and automation tools, or who want AI to participate in the development of existing projects.
  • Usage:Download and install from the ZCode official page. After logging in, open the workspace and describe the goals you want to accomplish.
  • Main abilities:Long-range Goal, multi-Agent collaboration, file and command operations, progress verification and remote task arousal.
  • Fees:The model quota and package may be adjusted, please refer to the current instructions on the official GLM Coding Plan page.
