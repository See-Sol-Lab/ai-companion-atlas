PROJECT INTRO

Project introduction

Tidal Echo is a set of private 1:1 chat channels: the mobile PWA is responsible for sending and receiving, the FastAPI relay is responsible for logging, SSE and push, and the desktop channel sends messages to Claude Code; it can also be replaced by any OpenAI compatible model loop. The core text, pictures, voice, calls, poke and lock screen push are all connected to the real backend.

It is extracted and completely redacted from the author's own AI companion system, with names, keys, domain names, and paths all parameterized. The project is for single users, does not establish an account system, and does not rely on third-party hosting.

  • Suitable for:Anyone who already has local AI or Claude Code and wants to establish a long-term private channel from their mobile phone.
  • Platform:Mobile PWA, Windows/macOS/Linux desktop and a server supporting HTTPS.
  • Usage:Deploy relay, PWA and desktop channels in sequence, and let the three ends use the same random key.
