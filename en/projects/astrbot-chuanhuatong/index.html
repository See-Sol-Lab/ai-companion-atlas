PROJECT INTRO

Project introduction

The painting tube reads the emotion tags in the AstrBot reply, switches the corresponding character portrait, and renders the multi-layered text, pictures, background and frosted glass components into a Galgame style chat box picture.

The project provides drag-and-drop WebUI editing layout and custom templates, which is suitable for AI in group chats or private chats to obtain a stable visual image and emotional difference.

  • Suitable for:Using AstrBot, I hope to reply to users with character drawings and emotional performances.
  • Platform:AstrBot plug-in and WebUI.
  • Usage:Install the plug-in, prepare the character sketch and configure the layout and emotion labels in the WebUI.
