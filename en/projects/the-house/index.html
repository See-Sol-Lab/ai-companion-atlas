PROJECT INTRO

Project introduction

the-house supports Claude and any OpenAI compatible interface. It can create multiple independent session windows, set role prompt words, adjust request parameters, send pictures and connect to MCP services. History, settings, and memories are saved in the native browser.

The project does not require a server, it can be run by double-clicking HTML, and can also be deployed to a static site. The repository currently does not state an explicit open source license, so making the source code available does not equate to a license to modify and redistribute it.

  • Suitable for:People who want a standalone PC chat front-end with minimal deployment steps.
  • Platform:Modern browser for PC.
  • Usage:Open a single HTML and fill in the model API and optional MCP address in the settings.
  • License:The source code is public; the repository currently does not declare an explicit license.
