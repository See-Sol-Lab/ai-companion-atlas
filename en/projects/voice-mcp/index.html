PROJECT INTRO

Project introduction

voice-mcp provides speak(text) MCP tools to switch between DashScope Qwen-TTS VC and ElevenLabs, and playback the results through the MCP Apps inline player and real-time visualization panel.

This repository is an MIT fork of garan0613/voice-mcp, retaining the original behavior and adding Provider switching, ElevenLabs and visualization functions, so it is not marked as original.

  • Suitable for:People who hope that MCP Agents such as Claude and Codex will actively call exclusive sounds.
  • Platform:Cloudflare Workers and clients supporting MCP Apps.
  • Usage:Deploy the Worker, configure the Voice Provider, and then register the service with the MCP client.
  • License:MIT; based on garan0613/voice-mcp.
