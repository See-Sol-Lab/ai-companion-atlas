PROJECT INTRO

Project introduction

LumiMuse allows you to create characters and set personalities, backgrounds, opening lines, sample dialogues and raw image tags to extract long-term memories about users, relationships and shared experiences in chats. It also provides real-time injection, native graphs, and data import and export.

The project can be run locally with Node.js and also supports Docker Compose; data is saved in SQLite and local files for easy backup and migration.

  • Suitable for:People who want a good-looking, quiet, long-term self-hosted character to accompany their web page.
  • Platform:Modern PC browsers and self-hosted servers.
  • Usage:Run locally or deploy with Docker, configure the model and graph service after entering for the first time.
  • License:MIT。
