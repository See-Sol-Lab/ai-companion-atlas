PROJECT INTRO

Project introduction

Mochi is a reverse virtual pet game in which "AI raises humans". Satiety, mood, vitality and cleanliness will decay over time. AI can feed, play with, bathe, coax to sleep, work, upgrade and purchase items through MCP.

The game also includes hospitalization and rescue, random events, community owner groups, pet adoption, and kindergarten plots. It can map eating and sleeping mentioned in chat to game status, but it should not replace real-life health judgment or care.

  • Suitable for:People who like reverse development, daily care and AI active care gameplay.
  • Platform:Python Self-host, including web front-end and SSE MCP.
  • Usage:Deploy the service, generate the invitation code and connect to the MCP to let AI read and update user status.
