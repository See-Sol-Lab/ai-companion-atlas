PROJECT INTRO

Project introduction

Pando equipped Claude Code on the computer with a mobile remote control web page. With your computer still on and running Pando, you can step away from your desk and use your phone to continue sending messages, checking replies and work progress, or uploading images or PDFs.

When Claude Code wants to modify a file or run a command, Pando can send a confirmation request to your phone, and you can choose to allow or deny it. It doesn’t offer new AI or put Claude Code on your phone; it’s always your computer that does the real work.

  • Suitable for:People who hope to continue to use their mobile phones to direct Claude Code's work after leaving the computer desk.
  • requires:A Windows, macOS, or Linux computer with Claude Code installed and logged in, and a mobile phone.
  • can do:Chat on your mobile phone, view work processes, upload images or PDFs, and confirm whether you are allowed to change files or run commands.
  • Security boundary:Pando itself has no login verification and can only be used in trusted private networks and cannot be directly exposed to the public network.
