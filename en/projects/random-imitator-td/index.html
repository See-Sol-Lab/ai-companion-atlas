PROJECT INTRO

Project introduction

random-imitator-td is a pure Python text tower defense for AI to play. Players view levels, adjust card slots, deploy units and advance waves through commands. The system is responsible for calculating resources, attacks and enemy status.

The project provides persistent archives and single-game adapters, suitable for embedding in unified game lobbies or directly handing over to AI that can run Python.

  • Suitable for:AI players who enjoy formations, resource planning, and deterministic text combat.
  • Platform:Pure Python CLI.
  • Usage:Create an archive, configure the card slot, then advance wave by wave through commands and view the compact status.
  • License:The source code of the repository is open to the public, and the specific reuse and distribution are subject to the project statement.
