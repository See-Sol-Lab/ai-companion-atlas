PROJECT INTRO

Project introduction

StackChan MCP establishes a Gateway between any MCP client and M5Stack's official CoreS3 StackChan, providing tools such as device status, photography, volume, brightness, head movement, touch, and expressions.

The project clearly states that it originates from the stack-chan community initiated by Shinya Ishikawa, and contains the xiaozhi-esp32 firmware subtree in the repository; Atlas therefore does not mark it as original.

  • Suitable for:Developers who want to let AI or MCP Agent control physical StackChan robots, cameras and servos.
  • Platform:M5Stack official StackChan, CoreS3 and compatible homemade stack-chan.
  • Usage:Flash the repository firmware, run Python Gateway, and add the stdio MCP configuration to the client.
  • License:Gateway, firmware and upstream components comply with the repository LICENSE, NOTICE and respective upstream terms respectively.
