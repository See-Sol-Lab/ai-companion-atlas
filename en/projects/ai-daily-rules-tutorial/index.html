PROJECT INTRO

Project introduction

The author separates daily rule management into visible agreements, notes on recent state, time cues, and prompts encouraging the model to use tools and adjust rules. The guide covers study support and voluntary human–AI interactions, including D/s contexts.

The conceptual guide offers alternatives using workspaces, memory, and prompt settings in existing frontends; the code guide provides time-injection and memo examples. This is not a standalone app. Results depend on the model, context budget, and user records. Users decide whether to adopt, change, or stop any rules.

  • Suitable for:People who want to record and discuss daily agreements and study progress with an AI companion.
  • Usage:Start with the conceptual guide and configure your frontend's workspace, memory, and prompts; consult the code guide for further integration.
  • Limitations:Based mainly on Android frontend experience; other platforms need adaptation. Without messages or records, the AI cannot know actual progress.
