PROJECT INTRO

Project introduction

Luckin My Coffee Skill is an officially released Agent Skill package, used for AI-assisted browsing and coffee selection, and access to the ordering process.

The source is the official distribution ZIP; the latest documentation and terms of service should be checked before installation.

  • Suitable for:People who want AI to assist Luckin in ordering and remembering drink preferences.
  • Platform:An environment that supports Agent Skills.
  • Usage:Download the official Skill package and install it according to the platform requirements.
