PROJECT INTRO

Project introduction

chatgpt-exporter is a userscript that runs in the browser and can export a single ChatGPT session to Markdown, JSON, PNG, or HTML, with sharing and styling options.

Exported conversations may contain personal and relationship information, and sensitive content should be sanitized before being made public or uploaded.

  • Suitable for:People who need to save, migrate, or organize ChatGPT conversations.
  • Platform:Desktop browser that supports user scripts.
  • Usage:Install the script and select the export format on the ChatGPT page.
  • License:MIT。
