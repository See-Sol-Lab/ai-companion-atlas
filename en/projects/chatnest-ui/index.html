PROJECT INTRO

Project introduction

"Heji's Another Home" is a mobile-first AI companion chat interface, especially suitable for use on the iPhone. It puts chat, search, long-term memory, clock, diary and calendar in the same place, making daily use more like a complete app.

The repository comes with demo content, and you can start the experience without connecting to the backend. For formal chat, users need to deploy and connect the model backend by themselves. Chat records can also be cached locally so that you can continue to view them when you open them again.

  • Suitable for:People who want to make long-term chats with your AI companion a permanent application on the iPhone home screen.
  • can do:Chat, search history, organize long-term memory, view diary calendar and time.
  • Usage:You can use the demo data to experience it first; for formal use, you need to connect your own chat and model backend.
  • Project source:Based on deep modifications of ChatNest, using the upstream non-commercial license.
