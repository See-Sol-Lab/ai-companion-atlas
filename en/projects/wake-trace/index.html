PROJECT INTRO

Project introduction

WakeTrace combines a runtime, scheduler, REST API, MCP, and web interface in one service. A companion can wake from time or permitted life events, use tools, create small works, then end silently, leave a private trace, or send a message.

It separates full experiences from short factual traces for future wakes. Two-way continuity with chat requires client or host integration; version 2.0 does not sync every chat turn automatically. Docker deployment requires your own model API and authentication tokens.

  • Suitable for:People who want bounded autonomous activity for an AI companion between chats, with selected experiences carried forward.
  • Platform:Single-container Docker Compose or a self-managed Python 3.11+ deployment; requires a model service.
  • Usage:Clone the repository, configure a model key and separate admin, web, and MCP tokens, then start the service. Chat integration requires further setup.
