PROJECT INTRO

Project introduction

co-reading-kit splits EPUB, TXT and Markdown into searchable fragments, allows AI to read by chapters or keywords through MCP, and writes reading notes and progress files.

It is suitable as a co-reading organ for existing partners and does not come with a chat front end; the repository currently does not declare an explicit license.

  • Suitable for:People who want to read books with local Agents for a long time.
  • Platform:Node.js and MCP clients.
  • Usage:Import books and register the MCP service in Agent.
  • License:The source code is public; the repository currently does not declare an explicit license.
