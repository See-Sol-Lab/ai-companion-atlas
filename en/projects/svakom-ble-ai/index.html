PROJECT INTRO

Project introduction

SVAKOM BLE AI is a complete tutorial for reversing the Bluetooth protocol from scratch and building an AI control system. It records the services and features, command frames, continuous sending mechanism and actual measurement methods of SL278H, and provides two BLE relays, Android Chrome Web Bluetooth and cross-platform Python.

The project also describes Railway relays, hidden control instructions, and Claude.ai MCP access. When using, you must avoid the firmware OTA write channel, protect remote secrets, and verify with low-intensity and short-term commands first. The current repository does not declare an open source license, so making the source code public does not equate to authorization to modify or redistribute it.

  • Suitable for:Anyone who owns a SVAKOM SL278H or is willing to verify the protocol of a similar BLE device themselves.
  • Platform:Android Chrome Web Bluetooth, or Windows/macOS/Linux Python relay; available with Railway and MCP.
  • Usage:First use nRF Connect and a test script to confirm the channel and command, and then select a mobile phone or computer to relay to access the AI.
  • License:The repository does not declare a license; by default it can only be read and verified based on public information, and the author's permission is required before reuse.
