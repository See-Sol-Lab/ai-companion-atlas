PROJECT INTRO

Project introduction

Echo Mistik is a publicly simplified version of the private Mistik architecture, maintaining long-term companionship with local memories, tools, persistent state, shared values, and reflective Dream notes.

The project runs locally as a Python Web App, providing a cyberpunk interface. The license is separate from the commercial license and Atlas is labeled as non-commercial.

  • Suitable for:People who want a lightweight, native, reflective web companion.
  • Platform:Windows, macOS, Linux and native browsers.
  • Usage:Start the Python Web App and configure the model Key and Persona.
  • License:Non-commercial use; commercial authorization must be obtained separately according to project documents.
