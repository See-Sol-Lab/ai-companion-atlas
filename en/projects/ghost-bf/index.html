PROJECT INTRO

Project introduction

ghost-bf explains how to use MacroDroid to detect phone activity, call AI, and return messages via system notifications.

The solution does not require programming, but relies on users to configure automation and model entry; when native activity awareness, on-demand screenshots and recall applications are required, Veglia by the same author can be selected.

  • Suitable for:People who want to use zero-code methods to increase active companionship on their mobile phones.
  • Platform:Android and MacroDroid.
  • Usage:Follow the tutorial to establish the detection, request and push process.
