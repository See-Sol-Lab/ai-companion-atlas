PROJECT INTRO

Project introduction

Drivesoid is an emotional drive service that runs alongside an AI bridging layer. It tracks sixteen dimensions such as energy, fatigue, missing, intimacy, possessiveness, anxiety, protectiveness, and playfulness, and is updated based on conversation classification, sleep, and calendar events.

The system distinguishes between fast emotion and slow mood. Repeated expressions will cause habituation and the recovery of negative states will be slower. Item also contains adult intimacy drives and related events, and is therefore classified as `18+`; all statuses should still be informed by the user and should not be used as a substitute for actual consent.

  • Suitable for:Developers who want AI personalities to have persistent emotional aftermath and adjustable drive models.
  • Platform:Node.js HTTP sidecar; Claude Code Hook also requires Python.
  • Usage:Configure personality, relationship and classification models, let the bridge layer report events and read the drives context.
