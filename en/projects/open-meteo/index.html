PROJECT INTRO

Project introduction

Open-Meteo provides hourly, daily and multi-model weather data by latitude and longitude, which can be used for dressing, travel, travel and environmental judgment.

It is a cloud API rather than a companion exclusive project, and Atlas includes it as a reality access tool.

  • Suitable for:Companion and Agent that require Key-free weather data.
  • Platform:HTTP API。
  • Usage:Request the official interface and inject the weather results into the companion context.
  • License:Used in accordance with Open-Meteo official terms.
