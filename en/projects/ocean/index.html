PROJECT INTRO

Project introduction

Ocean is a set of AI companion web applications that can be deployed by yourself. After the deployment is completed and the model service is connected, it can be opened from a browser or installed as a PWA on a mobile phone or computer.

It manages different uses separately: daily chats are placed in ordinary conversations, long-term work is placed in the project space, books and excerpts are placed in the shared reading space, and multiple models can be organized to participate in the same discussion. Each scene retains its own dialogue and material, without them all being lumped together.

  • Suitable for:People who want to manage their own data and use the same companion app to handle daily chats, projects, shared readings, and meetings.
  • Preconditions:Requires Node.js 20+, at least one model server, and HTTPS configured in a production environment.
  • Usage:Deploy the web frontend with Ocean Gateway, fill in the model service configuration, and use it from a browser or installed PWA.
  • Optional features:Features such as long-term memory, co-reading MCP, music, notifications, and games may require additional services or separate configuration.
