PROJECT INTRO

Project introduction

Destiny Card Array is a static browser card drawing game that combines time and space coordinates, motifs, identities and variables to create time travel or story settings.

Users can customize deck content locally for use in creating prompts, role-playing, or co-writing with AI; the repository does not currently declare an explicit license.

  • Suitable for:People who like to draw cards to create stories and create world settings with AI.
  • Platform:Modern browsers.
  • Usage:Open the static page to extract directly, or edit the local card pool.
  • License:The source code is public; the repository currently does not declare an explicit license.
