PROJECT INTRO

Project introduction

Youyue mobile phone provides SillyTavern with WeChat-style chat, friend circle, Weibo hot search and video call modules, and implements gesture return, view stack and plot time engine. Images are saved locally on the tavern server to avoid large Base64 data from dragging down the archive.

It supports both plot injection mode and independent API mode: the former brings mobile phone dynamics back to the main line of the tavern, and the latter allows conversations on the phone to not pollute the main chat history. The project reserves all rights and expressly prohibits commercialization and unauthorized secondary release.

  • Suitable for:People who use SillyTavern and want to add a realistic mobile social life to their characters.
  • Platform:SillyTavern and PC Browser.
