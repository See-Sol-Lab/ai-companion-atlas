PROJECT INTRO

Project introduction

OpenCLI lets AI use Chrome that is already logged in on your computer. You only need to describe the task in natural language, and AI can open the web page, find the content, click the button, fill in the input box, and bring back the processing results.

For commonly used websites, OpenCLI has prepared ready-made functions, such as searching Xiaohongshu, viewing popular content on Bilibili, reading Zhihu questions or checking website notifications. When encountering a website that does not have ready-made functions, it can also temporarily operate the browser like a human.

  • Suitable for:People who want AI to help with repetitive tasks such as searching for information, checking notifications, filling out forms, and organizing web pages.
  • How to use:Install OpenCLI, Chrome extension and corresponding Agent Skill, and then directly tell the AI the task.
  • Already supported:Websites such as Xiaohongshu, Bilibili, Zhihu, Twitter, and Reddit can also temporarily operate ordinary web pages.
  • Security boundary:AI will use the account you are currently logged in; high-risk operations such as posting, messaging, following, and deletion must be confirmed by humans.
