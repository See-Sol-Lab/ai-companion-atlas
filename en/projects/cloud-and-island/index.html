CLOUD-AND-ISLAND · @COCORAINA

PROJECT INTRO

Project introduction

The Cloud and Island tutorial covers persistent memory, diary, handover letter, Telegram channel, active messages, free time, health data and optional Mini App.

The repository mainly provides building documents and configuration methods, not a complete program that can be used out of the box.

  • Suitable for:Someone who wishes to build Claude's long-term home with his own hands.
  • Platform:VPS, Claude and Telegram.
  • Usage:Follow the step-by-step tutorial to configure servers, memories, and channels.
  • License:The scheme is public; the repository does not currently declare an explicit license.
