PROJECT INTRO

Project introduction

The project explains how to use Claude Code Channels, real PTY, web front-end, Cloudflare Tunnel and session maintenance to build a permanent companion, and provides human-viewing and machine-viewing version specifications.

The repository is tutorial-oriented and contains a small number of maintenance scripts; all placeholders must be replaced and private sessions must be protected when deployed.

  • Suitable for:People who want to make Claude Code permanent and accessible from their mobile phone.
  • Platform:macOS, Linux VPS; Windows can run WSL2.
  • Usage:Read the human version and hand over the machine version to the local Agent to build it step by step.
  • License:Tutorial CC BY 4.0.
