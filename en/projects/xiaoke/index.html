PROJECT INTRO

Project introduction

xiaoke is a conversation relay tool that needs to be deployed by itself, placed between the chat interface and the AI ​​model. Conversations successfully completed by it are saved locally in order. Multiple windows or front ends can share this recent conversation by connecting to the same xiaoke.

When opening a new window, xiaoke will first check what content is already in the window, and then fill in the missing recent conversations. It will not modify personality settings, nor will it automatically import old chats from other apps.

  • Suitable for:People who use multiple chat windows or front ends at the same time and hope to continue chatting after switching.
  • How it works:Saves the conversations completed through it, and fills in the latest records when the new window lacks the previous text. What
  • is not responsible for:does not manage personality, system prompt words and long-term memory, nor will it automatically read the history of other apps.
  • Privacy reminder:The saved timeline contains the chat text, which needs to be protected as private data and cannot be directly disclosed.
