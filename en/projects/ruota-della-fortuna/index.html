PROJECT INTRO

Project introduction

The Ruota della Fortuna is a retro slot machine style tag randomizer for adults. It extracts relationship settings, scenes, props, physical and psychological tags according to seven dimensions, has more than 450 built-in Chinese, English and Japanese tags, and allows users to save customized content locally in the browser.

The project can directly open the static page, or it can be self-hosted and use HTTP API, webhook or stdio MCP to hand over the extraction results to AI. Dimensions containing extreme fictional content are locked by default, and the user explicitly chooses whether to enable them or not.

  • Suitable for:Anyone in need of adult role-playing inspiration, random combination tools, or AI creation input.
  • Platform:Browser static page; self-hosted mode requires Node.js.
  • Usage:Extract after selecting an enabled wheel, or let the AI ​​call it through API/MCP; custom tags are saved in localStorage.
  • License:MIT。
