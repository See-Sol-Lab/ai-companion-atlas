PROJECT INTRO

Project introduction

MIRA maintains continuity as a permanent conversation: old passages are collapsed into first-person memories with absolute time, discrete memories decay by access, linkage and temporal relevance, and are automatically retrieved before responding.

The system also includes metacognitive observations, evolvable user behavior models, auto-discoverable tools, stable encrypted documents, and native Web Chat. The installation relies on PostgreSQL, Valkey and Vault, and the overall deployment threshold is higher than that of ordinary memory plug-ins.

  • Suitable for:Users who wish to self-host complete continuous digital entities rather than just connecting to a memory API.
  • Platform:macOS, Linux, Docker and the local web.
  • Usage:Run the deployment script or Docker to configure the model, database, and credential services.
