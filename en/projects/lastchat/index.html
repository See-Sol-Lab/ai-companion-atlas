PROJECT INTRO

Project introduction

LastChat is a feature-rich Android AI client. It supports multi-vendor and custom interfaces, picture video audio input, RAG long-term memory, web search, MCP, image generation, TTS, and unlimited character creation, tagging, import, and export.

The application provides a Python environment and QuickJS JavaScript engine in the PRoot Linux workspace. Chat and vector memories are saved locally and can be backed up via WebDAV. The project is an independently named fork of RikkaHub. The README clearly names the upstream and explains its reworked UI and new features.

  • Suitable for:Those who need an Android multi-model client that simultaneously values ​​local memory, role management, and script execution.
  • Platform:Android。
  • Usage:Configure the model provider after installation, create roles as needed, enable memory, search, MCP and local workspace.
  • License:AGPL-3.0; the image cropping component is also described in the upstream source.
