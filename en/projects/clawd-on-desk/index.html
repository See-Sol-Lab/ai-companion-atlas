PROJECT INTRO

Project introduction

clawd-on-desk is a pixel desk pet that can connect to coding agents such as Claude Code, Codex, Cursor, Copilot CLI, Gemini CLI, etc., and provide visual responses to thinking, typing, reporting errors, waiting for permissions, and completion.

It belongs to the Agent status tool, not a pure companion front end; the permissions of different Agents are still handled in their respective formal interfaces.

  • Suitable for:Run multiple coding agents at the same time, hoping to use desktop status to replace people who frequently cut windows.
  • Platform:Windows, macOS, and Linux.
  • Usage:Install the desktop application and follow the instructions to access the corresponding Agent hooks.
  • License:The source code is open to the public; see the project repository for specific terms.
