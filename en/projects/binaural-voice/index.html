PROJECT INTRO

Project introduction

The tool converts existing mono speech to binaural WAV using near-field HRIR data for direction and distance. Tags target either ear, behind or in front of the head, or changes in distance. Motion occurs mainly during speech and pauses hold position.

Basic processing needs Python, NumPy, and SciPy; FFmpeg can convert input formats. Existing audio works without ElevenLabs, while the optional synthesis script requires your own credentials. The author recommends non-real-time clips, and headphone results vary by listener.

  • Suitable for:People adding close-up, surrounding, or distance effects to companion voice clips and recordings.
  • Usage:Prepare mono speech, render it with position tags and timestamps, and listen on headphones.
  • Limitations:Headphones and horizontal rendering only, with a nearest distance of about 25 cm; not recommended for live calls.
