AI VIRTUAL PHONE · @XIAOLONGBAO0709

Put chat, friend circles, plots and joint activities into a virtual phone that you can build yourself.

AI Virtual Phone uses Next.js to simulate a complete mobile phone, allowing users to create characters, chat privately, group chats, view Moments, write diaries, run storylines, play games and install custom applications. All model services are configured by users themselves.

PROJECT INTRO

Project introduction

AI Virtual Phone is a self-hosted browser virtual phone. It supports private chats, group chats, friend circles, voice messages, transfer cards, character schedules and long-term relationships. It also provides world books, presets, story modes, visual novels, map adventures, diaries and note walls.

The project also includes the application market SDK, game lobby, pictures, voice, music, 3D world and theme beautification. Users prepare their own API Key for LLM and optional multimedia services; after turning on the self-hosting mode, they can be used locally without an account and activation code.

  • Suitable for:People who want to use virtual mobile phones to carry multi-character relationships, social dynamics, plots and joint games.
  • Platform:Modern browsers and PWAs; local or Netlify/Vercel deployment.
  • Usage:Start the project, turn on self-hosted mode, add the model in settings and create or import character cards.
