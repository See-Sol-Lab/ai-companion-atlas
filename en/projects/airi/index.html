PROJECT INTRO

Project introduction

AIRI provides front-end forms such as browser Stage, desktop Tamagotchi and mobile Pocket, and supports VRM and Live2D models, blink and gaze animations, real-time voice input and output, multiple LLM and TTS Providers, as well as browser-side databases and local inference experiments.

The project also connects Discord, Telegram, Minecraft and Factorio, and continues to expand desktop perception and gaming capabilities. It is a large-scale, active cross-platform project, suitable for users who want to build a visual digital companion or AI VTuber.

  • Suitable for:Visual companion users and developers who want visible bodies, real-time voice and gaming capabilities.
  • Platform:Modern browsers, PWAs, Windows, macOS, and mobile Pocket in development.
  • Usage:You can experience the web version directly, or install the desktop version and configure model, voice and character resources.
  • License:MIT。
