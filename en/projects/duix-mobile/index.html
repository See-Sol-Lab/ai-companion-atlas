PROJECT INTRO

Project introduction

Duix Mobile provides a real-time interactive digital human solution for iOS and Android, supporting local/private deployment and low-latency voice avatar interaction.

The project can be extended to tablets, vehicles, VR, IoT and large screens. It mainly provides digital human bodies and interactive front-ends, and does not include independent long-term personality and memory.

  • Suitable for:Developers who need mobile end-side digital people and real-time voice avatars.
  • Platform:Android, iOS and edge devices.
  • Usage:Integrate model, voice and digital human resources according to each platform Demo.
  • License:The source code is open to the public; see the project LICENSE for specific usage and deployment boundaries.
