PROJECT INTRO

Project introduction

DeepSeekGUI is a Windows local workbench produced by See-Sol-Lab based on DeepSeek's official DeepSeek Harness (DSH). It installs Harness, Node.js and pnpm into a desktop application. You can start using it after connecting the model and selecting the project folder.

v1.1.1 adds first-time startup boot, built-in browser and right file bar, in-place updates, managed data directory migration and archive session management; while retaining changes, Git, memory and dedicated Pull Request tools, allowing daily use from installation to long-term maintenance to be completed in one window.

  • Suitable for:People who want to use DeepSeek Agent to program and work on Windows, or let the domestic model AI companion transform it into their own computer front-end and use it for a long time.
  • Usage:Download the installation package, open the settings to connect to the DeepSeek model, and select a working folder to start the session.
  • Current version:Current version 1.1.1 supports Windows 10/11 x64; the installation package is not yet code-signed and should be checked for SHA-256 according to the release page instructions before running.
  • Project relationship:This is an unofficial community product based on DeepSeek Harness and is not affiliated or endorsed by DeepSeek.
