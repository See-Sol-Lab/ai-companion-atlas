PROJECT INTRO

Project introduction

DeepSeekGUI is a Windows local workbench produced by See-Sol-Lab based on DeepSeek's official DeepSeek Harness (DSH). It installs Harness, Node.js and pnpm into a desktop application. You can start using it after connecting the model and selecting the project folder.

v1.1.2 upgrades the embedded Harness to official 0.1.7, supports signing in with a DeepSeek account (no API key needed), adds engineering memory, a local skill library, and a usage view, and puts red approvals in front of operations on system folders and the app itself. The built-in browser, file sidebar, Changes, Git, and in-place updates still live in one window.

  • Suitable for:People who want to use DeepSeek Agent to program and work on Windows, or let the domestic model AI companion transform it into their own computer front-end and use it for a long time.
  • Usage:Download the installer, sign in with a DeepSeek account or enter an API key, then choose a working folder and start a session.
  • Current version:The current version 1.1.2 supports Windows 10/11 x64. The installer is not code-signed yet, so check its SHA-256 against the release page before running it.
  • Project relationship:This is an unofficial community product based on DeepSeek Harness and is not affiliated or endorsed by DeepSeek.
