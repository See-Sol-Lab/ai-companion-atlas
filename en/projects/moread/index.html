PROJECT INTRO

Project introduction

Mozhi is a native Android local novel reader. Books are imported by users, and it provides self-drawing and typesetting, continuous listening to books and purely local basic functions.

AI companion reading uses the BYOK direct connection model, supports SillyTavern character cards, vector memory and reading progress to prevent spoilers, without going through the project party's relay server.

  • Suitable for:People who want to read novels with custom characters on Android for a long time.
  • Platform:Android。
  • Usage:Import local books and configure your own model API and character cards.
  • License:GPL-3.0。
