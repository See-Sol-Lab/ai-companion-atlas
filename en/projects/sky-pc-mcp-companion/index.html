PROJECT INTRO

Project introduction

Sky PC MCP Companion is a set of native MCP and JSON-RPC tools for PC light encounters. It supports capturing the game window, performing OCR, returning screenshots to the model, and sending keyboard and chat input.

The project is suitable as the underlying interface for game perception and control. Users need to decide their own permission boundaries and upper-layer Agent behavior.

  • Suitable for:People who want to let the local AI see the PC light encounter screen and conduct limited input experiments.
  • Platform:Windows and PC version of "Light·Encounter".
  • Usage:Start the local service and connect the MCP or JSON-RPC tool to the AI ​​client.
  • License:The source code of the repository is open to the public, and the specific reuse and distribution are subject to the project statement.
