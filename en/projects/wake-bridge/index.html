PROJECT INTRO

Project introduction

Wake Bridge is an attention scheduler for agent hosts. Sources register events, the agent sets policies and future commitments, and the system delivers a structured wake envelope through a registered host adapter after applying quiet hours and presence rules.

This preview supports one agent in a local deployment and includes an optional adapter for an active Claude CLI session. Other hosts must implement and verify an adapter. It is not a chat frontend or memory system and does not wake arbitrary desktop clients.

  • Suitable for:People building an agent host who need to manage outside events and future attention.
  • Platform:The preview supports macOS arm64/x64 and Linux x64 with systemd user services; requires Node.js 20+ and SQLite CLI.
  • Usage:Install the wake-bridge preview and configure or implement a host adapter for the target session.
  • License:Apache-2.0; currently a preview release.
