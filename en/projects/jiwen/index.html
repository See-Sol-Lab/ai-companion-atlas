Jiwen

JIWEN · @CLARASHAFIQ

Make "want to speak first" come from an ongoing state rather than a random dice roll.

Jiwen is a JavaScript state engine of about 500 lines. It does not write replies, store memories, or call models. It only advances the character state based on time and events, and outputs contact, observation, or self-regulation signals when a threshold is reached.

Project address (can be copied to AI):https://github.com/ClaraShafiq/jiwen

PROJECT INTRO

Project introduction

Accumulated temperature describes the status changes of the character when waiting, being responded to, depressed or immersed in activities through five continuous axes of connection, pride, valence, arousal and immersion. Each tick only advances the mathematical state, and returns to contact, observation, or find_activity only after reaching the threshold.

The project provides natural language status description, tone guidance, parameter adjustment simulator, nine-category emotion intonation grid and testing. Developers can connect it to any chat, push or heartbeat system, and then use their own models to generate specific actions and lines.

  • Suitable for:are developing active companions, character state machines, or anyone who needs interpretable trigger logic.
  • Platform:Pure JavaScript, zero external dependencies, and can be connected to any host.
  • Usage:Create a role instance, call tick periodically, and convert the return status into model context or action.
  • License:MIT。
