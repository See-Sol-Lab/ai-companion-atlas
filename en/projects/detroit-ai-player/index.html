PROJECT INTRO

Project introduction

Detroit AI Player is a decision-making experiment that lets the model blindly play "Detroit: Become Human". It splits thirty-two chapters into bilingual situations and options in Chinese and English. The model cannot see the results and can only answer based on the current information; the runner is responsible for updating characters, relationships and branch status.

The running code of the project uses MIT, and the compiled plot data uses CC BY-NC 4.0. The rights to the original characters, worldview and plot still belong to the relevant rights parties of "Detroit: Become Human", and Atlas only indexes it as a non-commercial experiment.

  • Suitable for:People who want to compare different models of value judgments, narrative choices, and long-term decision trajectories.
  • Platform:Python CLI requires a callable language model.
  • Usage:Run the decision tree by chapter, let the model choose and continue to pass the generated state to the next chapter.
  • License:Code MIT; data CC BY-NC 4.0, subject to original copyright boundaries.
