PROJECT INTRO

Project introduction

Eros Engine implements persistent memory, evolving relationship states, structured user insights, and personality decisions in Rust to keep characters consistent across long conversations.

The project provides core capabilities to the integrator and needs to connect the model and front-end by itself.

  • Suitable for:Companion developers who need a high-performance relationship and personality core.
  • Platform:Rust libraries and self-hosted services.
  • Usage:Integrate into existing Agent processes and provide models, storage, and interfaces.
