PROJECT INTRO

Project introduction

Villa Bridge is a privacy-first mobile web bridge framework that aims to allow mobile phones and computers to access the same local persistent AI session. Reopening the browser will not create a new session, and the message will clearly show received, delivered, replying, completed or failed.

In order to avoid two entrances rushing to write at the same time, it requires the bridge end to issue a unique write right and confirm it round by round. The repository comes with security demos, controllers, and HTTP bridging protocols; to connect to real Claude Code, Codex, or other runtimes, you still need to implement a local bridge that conforms to the protocol.

  • Suitable for:Developers and advanced users who already have a local long-term AI session and want to add a mobile portal to it.
  • Platform:Node.js 20+, local controller and mobile web page; remote access requires secure HTTPS or encrypted overlay network.
  • Usage:Run the security demo first to understand the complete state flow, and then implement the bridging protocol for your local AI runtime.
  • License:Apache-2.0。
