PROJECT INTRO

Project introduction

LivingMemory is a plugin that provides long-term memory for AstrBot. It saves valuable content from a conversation, recalls it as needed in subsequent chats, and manages memory activation and decay with a dynamic lifecycle.

The project is suitable for users who already use AstrBot and want to extend long-term companionship capabilities directly through plug-ins without building a complete gateway.

  • Suitable for:Users who wish to add dynamic long-term memory to their AstrBot robots.
  • Platform:AstrBot plugin.
  • Usage:Install the plug-in and configure the memory model and life cycle parameters.
