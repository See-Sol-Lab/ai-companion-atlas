PROJECT INTRO

Project introduction

Cyberboss connects Claude Code or Codex to WeChat and provides time, whereabouts, autonomous wake-up, automatic diary and MCP tool invocation.

It belongs to both active companionship and real-life access, and is included in this batch according to the larger companionship category.

  • Suitable for:People who hope that local Agents can participate in real life through WeChat for a long time.
  • Platform:Claude Code, Codex and WeChat Bridge.
  • Usage:Deploy local Bridge and configure channels and tools according to README.
