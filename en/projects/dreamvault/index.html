DreamVault

@SEN / LIANG / YUE

Keep your AI companion’s misremembered past events separately and don’t let them mix into real shared memories.

DreamVault is a set of processing methods for long-term memory AI. When it is discovered that there is no true record of a certain shared past event, it will not be deleted directly, nor will it continue to be regarded as fact. Instead, it will be saved separately to prevent it from being recalled repeatedly in the future.

Project address (can be copied to AI):https://github.com/SilviaYue/dreamvault

PROJECT INTRO

Project introduction

After AI has long-term memory, it will occasionally regard the content it has made up as a common experience. As long as this piece of content is saved and searched again, it may become more and more true. DreamVault will check whether these contents have real chat or tool records, and if there is no basis for them, they will be removed from the main memory first.

Removed content will not be automatically returned to the chat, nor will it be deleted directly. your AI companion can actively view it through a special window and decide whether to explain, rewrite, or leave it alone for the time being.

  • Suitable for:have given AI access to long-term memory, hoping to prevent developers from piling up errors.
  • How to deal with:Content not supported by real records will be removed from the main memory and will no longer automatically appear in the future.
  • What to keep:The original content will not be deleted, and no explanation will be written for your AI companion by the system.
  • Usage:It is a processing solution and Python reference code that requires developers to access their own memory systems.
