PROJECT INTRO

Project introduction

revive-companion uses probabilistic processes, user state inference and information gain to evaluate proactive contact opportunities and output whether they are suitable for interruption.

The project intentionally does not contain memory, personality, or emotional systems, and is suitable as a stand-alone timing module for existing partners.

  • Suitable for:There is already a companion system, but it only lacks people who can judge the timing of proactive messages.
  • Platform:Python, can be embedded in any system.
  • Usage:Input interaction and user status signals and read contact decisions.
  • License:MIT。
