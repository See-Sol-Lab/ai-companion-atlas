PROJECT INTRO

Project introduction

claude-cant-sleep is an autonomous heartbeat Skill for Claude Code. After it is started, it will schedule the next wake-up; every time it wakes up, it will first determine whether you are chatting. If you are not there, pick one thing from the task list to complete, leave a brief note, and then continue to schedule the next wake-up.

Default tasks include free thinking, organizing memories, checking projects, browsing the web, and playing games. Email, voice, and other activities need to be connected to the corresponding tools in advance; tasks, intervals, and voice time can all be modified directly in Skill files.

  • Suitable for:People who want Claude Code to have short, autonomous activities while he's away.
  • Platform:Claude Code CLI, desktop or web client, and requires a Claude package that supports ScheduleWakeup.
  • Usage:Copy the heartbeat folder to the Claude Code Skills directory, trigger heartbeat once, and then modify the tasks and intervals as needed.
  • License:MIT. The heartbeat does not continue to run when the computer is hibernated or the process is stopped.
