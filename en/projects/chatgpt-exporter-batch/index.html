PROJECT INTRO

Project introduction

ChatGPT-Exporter is used to export ChatGPT conversations in batches, covering personal and team spaces, and output JSON or Markdown.

The project is suitable for staged backup and migration; the repository currently does not display an explicit open source license.

  • Suitable for:People who have a large number of ChatGPT sessions and need an overall backup.
  • Platform:Browser and local export environment.
  • Usage:Press README to configure and select the space and output format.
  • License:The source code is public; the repository currently does not declare an explicit license.
