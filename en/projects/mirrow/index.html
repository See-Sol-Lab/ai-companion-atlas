PROJECT INTRO

Project introduction

MIRROW is a Python component package for AI companion developers. It cannot be launched as a chat software independently, but must be connected to an existing FastAPI, asyncio or other companion program.

The current public module can read computer idle status, mobile phone or other optional data to determine whether humans are busy; it can also allow AI to organize thoughts when no one is talking, choose the appropriate time to actively contact, and convert the model's intention into a real tool call.

  • Suitable for:Developers who already have their own AI companion program and want to continue to add environmental awareness, active contact, and tool action capabilities.
  • Public content:Examples of context awareness, rambling and active pushing, tool scheduling, context assembly, and memory interfaces.
  • Undisclosed content:Complete memory library of complete chat product, front-end, group chat, voice and original system.
  • Preconditions:requires an existing Python host program and provides its own interfaces for model invocation, message push, and optional memory retrieval.
