PROJECT INTRO

Project introduction

woaini integrates Pomodoro, notifications that can still be triggered after locking the screen, offline caching and break chat rooms into a single-page PWA. Users can import character cards and world book information, and use PNG, JPG or WebP as differential expressions to retain their character's appearance during conversation breaks.

Projects can be deployed directly to GitHub Pages, opened in computer browsers, and added to the home screen on iPhone and Android. The README is primarily provided as a deployment guide, and the repository currently does not declare an explicit open source license.

  • Suitable for:People who want to join the company of lightweight AI during study or work breaks.
  • Platform:Modern browser, Android and iOS PWA.
  • Usage:Deploy to GitHub Pages or other static sites, and then add it to the mobile home screen.
  • License:The source code is public; the repository currently does not declare an explicit license.
