Veglia

VEGLIA · @EVELYN & RIVER

With explicit authorization, let the AI view Android activity, request screenshots, and gently call you back.

Veglia consists of Android accessibility services, Python services, and AI-side CLI. The mobile phone always displays foreground notifications, screenshots are saved in its own server and the number is automatically limited, and viewing and recall are authorized separately.

Project address (can be copied to AI):https://github.com/sebastianevan200-stack/veglia

PROJECT INTRO

Project introduction

Veglia's Android app logs recent app activity via visible foreground accessibility services and takes screenshots of the current screen when explicitly requested by the AI. The self-hosted Python service only retains a small number of recent screenshots, and then sends the images to the AI ​​session through user-configured Hooks.

It is not the same implementation as ghost-bf by the same author: ghost-bf is a MacroDroid, scheduled wake-up and notification tutorial; Veglia provides native activity awareness, screenshots and recall application code, but does not include a complete active wake-up closed loop.

  • Suitable for:A person who has express consent and wishes to have their partner understand Android phone activity or current screen on demand.
  • Usage:Android 11+; build and install APK by yourself, deploy Python service and HTTPS, and then connect to AI-side CLI and notification Hook.
  • Privacy boundary:All interfaces use a shared key; by default, only the last 5 screenshots are retained, the phone displays foreground notifications, and viewing and recall can be turned off respectively.
