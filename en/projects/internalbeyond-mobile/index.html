PROJECT INTRO

Project introduction

InternalBeyond Mobile provides multi-model chat, long-term emotional memory, AI social circle, calendar, blog, correspondence, listening and shared file workspace, and allows each AI to have independent relationship settings and Auto Memory files.

The project runs offline as single-file HTML and can be installed as a PWA; all data is saved in the local browser and can be migrated to and from the desktop version of InternalBeyond via JSON backup.

  • Suitable for:Users who want to have a complete private partner space on their mobile phone and share relationship data with the desktop version.
  • Platform:Modern mobile browsers and PWA; single files can also run in computer browsers.
  • Usage:Open index.html directly after downloading, or deploy to HTTPS static hosting and install to the home screen.
