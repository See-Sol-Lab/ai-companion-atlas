PROJECT INTRO

Project introduction

This Chrome extension supports browsing Claude.ai conversations and exporting single or multiple conversations to JSON, Markdown, or plain text.

It is intended for backup and data migration; extended permissions should be confirmed before use, and exported private content should be protected.

  • Suitable for:People who need to save or migrate Claude.ai conversations.
  • Platform:Chrome browser.
  • Usage:Install the extension and select the session and export format in Claude.ai.
  • License:The source code is open to the public; see the project repository for specific terms.
