PROJECT INTRO

Project introduction

Eventide is an AI companion physiological state kernel with open source code. It describes the current body with heat, depression, control, sensitivity, accumulation, possessiveness and exhaustion, and allows these values ​​​​to change with cycles, waiting, call triggers, dreams and interaction results.

The project provides cycle advancement, event triggering, hidden state cards, dream card linkage and structured interactive settlement; the host is responsible for saving the state, calling the model and displaying the interface. All fields, cycle copy, and response rules can be replaced.

  • Suitable for:are developing adult-oriented AI companions for people who want temporal continuity of physical and emotional states.
  • Platform:Python kernel that can be embedded in any chat, scheduled task or active checking system.
  • Usage:Persist the BodyState, advance the state each round and inject the model context, and write back the settlement results after the interaction.
