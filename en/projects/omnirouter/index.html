PROJECT INTRO

Project introduction

OmniRouter is a model relay station that you install on your own computer. You can add OpenAI, OpenRouter, DeepSeek and other compatible services to its web backend, and uniformly save different model addresses and API Keys.

After the setup is complete, the companion front-end only needs to fill in a fixed API address provided by OmniRouter. Each chat request comes here first, and then it selects the model that is actually responsible for answering based on model grouping, task type, order, randomness or weight.

  • Suitable for:People who use multiple model services at the same time and do not want to repeatedly configure and manually change lines in each companion front end.
  • Usage:Add Provider, API Key, model and group, and then fill in the unified API address displayed on the dashboard into the companion front end.
  • Automatic selection:Model groups can be selected by problem type, and sequential, random, and weight rotation are also supported.
  • Safety reminder:The API Key is currently stored in the local SQLite database in clear text; do not share the database or expose the service directly to the public network.
