PROJECT INTRO

Project introduction

netease-music-mcp is based on neteasecli and mpv, providing search, play, pause, song switching, lyrics, playlist and current song context, and comes with a local web player.

It requires the user's own NetEase Cloud music environment and does not provide music content authorization; the repository currently does not declare an explicit license.

  • Suitable for:People who want local Agent to participate in NetEase Cloud listening.
  • Platform:Windows, macOS, and MCP clients.
  • Usage:Install neteasecli and mpv, and then register the MCP service.
  • License:The source code is open to the public; music content and repository license need to be confirmed separately.
