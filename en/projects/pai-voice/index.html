PROJECT INTRO

Project introduction

PaiVoice provides a dependency-free browser calling client, a Python WebSocket real-time core, and a tmux Adapter. It can pass the transcribed words to Claude CLI, Codex CLI, OpenAI-compatible API or other reply end, and then play them through replaceable TTS.

Its positioning is different from Callhome and WebCall: PaiVoice provides a voice base layer that can be embedded in PWA and self-made front ends, and does not include a complete companion product, personality or memory system.

  • Suitable for:Developers who want to add real-time voice calling capabilities to their PWA, terminal Agent or local model.
  • Current status:Already includes a browser client, a runnable real-time service and Claude/Codex tmux access; the repository is still small and does not provide an automated test directory.
  • Usage:Install Python dependencies, configure server-side ASR, TTS and model Adapter, and then connect the Web client to your own front-end.
  • License:AGPL-3.0; When providing modified version services through the network, the source code needs to be provided to the corresponding users.
