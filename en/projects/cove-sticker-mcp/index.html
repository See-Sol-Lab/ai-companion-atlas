PROJECT INTRO

Project introduction

The project provides a local web library and MCP tools for importing images, folders, or ZIP files, deduplicating content, and retrieving images through descriptions and tags. Manual tagging, search, and MCP retrieval work without a vision model. No sticker collection is bundled.

This is a source-installed development version requiring Python 3.11+. When automatic vision tagging is enabled, image previews go to your configured model service; retrieved images and descriptions go to the agent. Smaller previews reduce transfer size but do not guarantee negligible token costs. This listing has not been installation-tested.

  • Suitable for:People who want a custom sticker library for an MCP companion without tying it to one chat platform.
  • Platform:Python 3.11+ and an MCP client supporting stdio or Streamable HTTP.
  • Usage:Install from GitHub source, manage the library in the web interface, and register the server in your MCP client. Automatic vision tagging is optional.
  • License:MIT; imported sticker assets remain subject to their own copyright terms.
