PROJECT INTRO

Project introduction

Bending Machine is a set of static AI companion applications that can be run directly in the browser. Users can configure the role and model API, deploy the website to Netlify, or directly download the file for use.

Chat, roles, settings and API configurations are mainly saved in the local storage of the current browser; the project supports data export and import and PWA installation, and needs to be backed up before changing devices, domain names or browsers.

  • Suitable for:Users who want to quickly deploy a private AI companion portal with a static web page.
  • Platform:Modern mobile and computer browsers can be installed as a PWA.
  • Usage:Fork and then connect to Netlify for automatic deployment, or download the complete folder and upload it manually.
