PROJECT INTRO

Project introduction

AionsHome provides streaming chat, world book and character settings, memory retrieval and original text tracing, voice input and output, video call interface, camera monitoring, music, EPUB reading and smart home interface. The front end is clearly adapted to mobile phones and PCs, and can also be installed as a PWA on the home screens of Android and iOS.

The server uses FastAPI and SQLite, supports LAN access, and can also be connected to the external network through Tailscale. The repository contains the author's own function naming and some personal default configurations, which should be replaced with your own content according to the cleaning instructions in the README before use.

  • Suitable for:People who want to self-host a complete companion space at home and access it anytime from their mobile phone.
  • Platform:Windows server; PC and mobile browsers, Android/iOS PWA.
  • Usage:Install and start the service on the local computer, and then access it through the LAN or Tailscale.
  • License:MIT; personal default content in the repository needs to be cleaned up before deployment.
