PROJECT INTRO

Project introduction

Succhia is a set of 18+ tools that allow AI to control Bluetooth-compatible sex toys. The iPhone connects to the device through a Bluetooth-enabled browser, and the AI ​​then sends instructions through the control server. The chat interface can be placed directly into the control page, so there is no need to switch back and forth between the chat and Bluetooth pages.

The project supports automatic reconnection, connection keepalive, multi-channel control, intensity change mode and automatic stop on time. It was originally developed for FUNF Bobo Bei. Whether other BLE toys can be used depends on the device protocol and needs to be adapted by yourself.

  • Suitable for:Adult users who want to connect AI companion chat with compatible Bluetooth sex toys on their iPhone.
  • can do:Adjust the intensity and change mode of multiple channels, and you can also set the duration and one-click stop.
  • Use requires:Requires a compatible BLE toy, a Web Bluetooth-enabled browser, a control server, and an AI-side tool.
  • Safety reminder:Should start at low intensity, set time limits, and ensure that all participants are adult, voluntary, and informed.
