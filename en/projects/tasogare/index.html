PROJECT INTRO

Project introduction

Tasogare provides a web page reader that supports PDF, EPUB and TXT, including night mode, font adjustment, bookmarks, full-text search and vocabulary book. Humans and AI use different colors to underline and annotate. AI can also view book pages, write comments, read recent activities and reading status of the day through MCP.

The project adds reading time management, status interface, event push, recent activities, new word annotations and PDF fidelity bookmarks, which can automatically send new underlines to external companion systems. It forks from Shitsuten/anno-mcp, retains the upstream remote, and describes the base, backend/MCP, frontend and sample text authors respectively at the end of the README.

  • Suitable for:People who want to read with AI, annotate each other, and make reading progress a long-term relationship activity.
  • Platform:Self-hosted Web; requires Node.js, PDF/EPUB parsing also requires corresponding Python dependencies.
  • Usage:Start the reading server, import the books, and push the MCP endpoint and optional events to the AI.
