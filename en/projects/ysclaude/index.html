PROJECT INTRO

Project introduction

YSClaude supports text chat, voice and video calls, built-in vector and keyword memory, Internet search, photos, music, diary letters, emoticons, shared reading, to-do, accounting and custom workflows that can be triggered in the background. It can also connect to MCP, SSH and session files.

After turning on Shizuku and accessibility permissions, AI can observe the Android screen, execute Shell, click and input, and call phone capabilities such as positioning, contacts, text messages, and calls according to authorization. The project uses PolyForm Noncommercial 1.0.0, and the interface refers to the Claude style, but the main functions are continuously expanded by the project.

  • Suitable for:People who want to use an Android App to take over chat, memory, tools and active workflow.
  • Platform:Android, you need to build the APK yourself or obtain the version through project channels.
  • Usage:Configure OpenAI compatible interfaces and required voice, search, MCP and device permissions.
  • License:PolyForm Noncommercial 1.0.0, for non-commercial use only.
