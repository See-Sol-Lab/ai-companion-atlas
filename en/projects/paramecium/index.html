PROJECT INTRO

Project introduction

Paramecium is a gateway memory architecture that emphasizes the true source of the original text. It saves the complete chat record, uses vectors and other indexes to find relevant locations, but returns the original text when recalling, without replacing the conversation that once took place with a model summary.

This route is suitable for long-term companion systems that care about evidence, wording, and relationship details. It also makes it easier for users to review where the memory came from.

  • Suitable for:Someone who is unwilling to let a summary replace the original words and wants the memory to be traced back to a verbatim record.
  • Platform:Self-hosted JavaScript gateway.
  • Usage:Pass the model request through the gateway, save the original conversation and let the index only take on the positioning responsibility.
  • License:The source code of the repository is open to the public, and the specific reuse and distribution are subject to the project statement.
