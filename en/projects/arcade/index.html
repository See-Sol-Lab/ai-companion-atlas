PROJECT INTRO

Project introduction

Arcade is a general lobby for AI to play text simulators. It reads the manifest of each game, automatically discovers and switches games, transparently transfers non-lobby commands to the current engine, and manages gold coins, energy recovery, and cross-game trophies in a unified manner.

The project has verified directory discovery, manifest and cmd(text) routing ideas, but the author positioned it as an experimental prototype and publicly listed unresolved issues such as reset command conflicts and archive path isolation; more complete implementation has turned to three-daily.

  • Suitable for:Developers who want to connect multiple AI word games to the same entrance, or refer to the unified game protocol.
  • Platform:Pure Python CLI, no graphical interface.
  • Usage:Put the game directory into games/ and provide manifest.json and cmd(text) entries.
  • License:PolyForm Noncommercial 1.0.0; current version is an exploration record.
