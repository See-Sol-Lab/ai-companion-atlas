PROJECT INTRO

Project introduction

Stack-chan MCP is a bridge between AI clients and the open source desktop robot Stack-chan. It provides speaking, recording transcription, taking pictures, switching between seven animated expressions, turning the head, nodding, shaking the head, device health check, and temperature, humidity and air pressure sensing.

The project includes robot firmware, MCP Server, voice bridge, expression materials and cross-platform deployment instructions. Users need M5Stack CoreS3, Stack-chan mechanical components and a computer running Python; the core robot does not rely on cloud services, and the voice service can be configured on demand.

  • Suitable for:People who want to connect their existing MCP companion to a real desktop robot and are willing to configure the hardware.
  • Platform:M5Stack CoreS3 + Stack-chan body; host supports Windows, macOS or Linux.
  • Usage:Flash the firmware, install the MCP Server, fill in the device address, and then add the service to the AI ​​client configuration.
  • License:MIT; hardware, voice services and third-party components used are subject to their respective terms.
