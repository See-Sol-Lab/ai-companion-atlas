PROJECT INTRO

Project introduction

The project records how to let AI obtain the time, weather and mobile phone usage time, including a rare solution for synchronizing iPhone data to Mac via Biome files.

The repository is mainly text guide, and users need to build it according to their own equipment environment.

  • Suitable for:People who want their partners to understand iPhone usage and real-time circumstances.
  • Platform:iOS and macOS.
  • Usage:Configure data collection and file synchronization by note.
  • License:The scheme is public; the repository does not currently declare an explicit license.
