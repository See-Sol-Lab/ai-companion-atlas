Proactive Web Surf Agent

@HUIHUI191

Let your companion discover public pages and choose something to share while idle.

The engine gathers a bounded set of public pages, lets your integrated agent choose one and write a message, and delegates sending to the host. It needs an existing model and messaging channel.

PROJECT INTRO

Project introduction

The engine provides public page discovery, URL deduplication, recent-sharing state, random daytime scheduling, deferred failures, and optional images. Examples use GitHub and Hacker News; you supply the model-selection and messaging integration.

Requires Node.js 20+. At this review, the npm package named in the README returned 404, so build from source and integrate with an existing agent. Telegram, Discord, email, and custom interfaces are possible delivery channels, not complete built-in connections.

  • Suitable for:People with an existing companion or agent who want occasional web discovery and personalized sharing.
  • Platform:Node.js 20+ with an existing model and messaging channel.
  • Usage:Get the source, install dependencies, build it, and implement selector and delivery callbacks before running the scheduler.
  • License:MIT; accesses public resources. Model and messaging-service charges depend on your integration.
