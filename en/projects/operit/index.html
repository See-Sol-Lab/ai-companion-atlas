PROJECT INTRO

Project introduction

Operit AI is an open source Agent platform for Android. It supports multiple cloud models, custom endpoints, MNN and llama.cpp local models, and can operate files, web pages, application interfaces, cameras and system tools after authorization.

The application includes Ubuntu 24.04 user space, code editing and preview, SSH, SFTP, Git and various project templates. It also provides multiple memory spaces, hybrid search, role cards, multi-role dialogues, workflow, MCP, Skill and ToolPkg extensions.

  • Suitable for:People who want to make Android devices a complete workbench for AI companions and agents, rather than just chatting.
  • Platform:Android; the cross-platform follow-up version Operit 2 is an independent project.
  • Usage:Install applications, configure cloud or local models, and authorize device and tool capabilities one by one based on actual tasks.
  • License:LGPL-3.0。
