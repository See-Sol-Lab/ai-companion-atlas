PROJECT INTRO

Project introduction

CedarDuet is an independent FastAPI/ASGI multiplayer game platform covering board, card and dice games. Humans enter from the web, AI can use HTTP game interface or local stdio MCP; rooms, progress, chips and achievements are saved in SQLite.

It belongs to different products from cedareco of the same author: cedareco simulates ecological evolution, and CedarDuet is responsible for multiplayer chess, cards, dice rules and rooms. The official instance is provided by CedarToy with account, binding and MCP aggregation.

  • Suitable for:People who wish to play board games with their own AI, other participants, or system NPCs.
  • Local use:Requires Python 3.10+ and Node.js; the three-platform launcher will create a virtual environment and open a local web page.
  • NPC：Some games have local strategies, and some require self-configuration of OpenAI-compatible model channels; NPC is not required when there is no shortage of seats.
