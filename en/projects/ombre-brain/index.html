PROJECT INTRO

Project introduction

Ombre Brain is a self-hosted long-term emotional memory system. Each memory bucket is a Markdown file that can be read and edited directly, and comes with valence, wake-up, importance and decay information; retrieval uses both keywords and semantic signals to return to the original text fragment when the service is unavailable.

It also provides historical conversation import, original text evidence, verifiable backup and recovery, password-protected Dashboard, OAuth remote MCP and local stdio access. Users can view, correct, archive and restore memories rather than leaving them entirely to black box digests.

  • Suitable for:People who need cross-model and cross-window memory, and want to review and master long-term data by themselves.
  • Platform:Claude, Codex, and other MCP clients; runs locally, on NAS, VPS, or on a platform with persistent disks.
  • Usage:Deploy using Docker or Python, mount the persistent directory, and connect via stdio, HTTP, or OAuth MCP.
