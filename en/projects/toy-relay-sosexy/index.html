PROJECT INTRO

Project introduction

Toy Relay is a private hardware MCP relay designed for users who love computers. The repository provides FastAPI/FastMCP services running on VPS and Web Bluetooth page in Android Chrome, supporting suck, vibration, current, stop, status and history tools.

The project restricts access through API Key and Tailscale HTTPS by default, and has verified the SOSEXY/Bobo protocol. The README does not state hard intensity caps, session length caps, or automatic stopping, so test at low intensity first, keep relays online, and ensure stop controls are readily available. For the BLE protocol document, please refer to 51enuxu/sosexy-ble-control. The AI ​​relay and interface are independently implemented by this project.

  • Suitable for:People who have SOSEXY-enabled devices and use MCP clients such as RikkaHub, Claude Desktop, etc.
  • Platform:Python service on VPS + Android Chrome with Web Bluetooth support; same Tailscale network recommended.
  • Usage:Deploy the service, set a random API Key, connect to tailnet, and then use the mobile phone relay page to pair the BLE device.
  • License:MIT; Added device support requires self-verification of UUID, protocol frames, and stop behavior.
