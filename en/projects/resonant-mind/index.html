PROJECT INTRO

Project introduction

Deployed on Cloudflare Workers, Resonant Mind provides 28 MCP tools covering semantic memory, emotion processing, identity continuity, and subliminal daemons.

It is a cognitive backend rather than a chat frontend, suitable for combination with Resonant or other Agents. License permits personal, educational, and non-commercial use, commercial use requires separate authorization.

  • Suitable for:Individuals and researchers wishing to deploy persistent cognitive backends on Cloudflare.
  • Platform:Cloudflare Workers and MCP.
  • Usage:Deploy the Worker and bind it to the storage, and then register the MCP with the Agent.
