PROJECT INTRO

Project introduction

Shinsekai is geared toward Galgame, Otome, and story-oriented RPGs, using large models to drive character dialogue and synchronizing vertical graphics with emotional changes. It can be configured with TTS, ASR, vision, memory, tools and plugins, and the chat window maintains a stage-like presentation.

The project supports local settings and source code construction, and provides installation paths for Windows and macOS. It is a source code visible project, allowing viewing and local self-use, but it may not be redistributed, released installation packages or commercially used without written permission.

  • Suitable for:People who want to create or experience AI-driven visual novels and character plots.
  • Platform:Windows and macOS desktop environments.
  • Usage:Press README to install the desktop version, and configure the model and optional extensions in Settings.
  • License:The source code is visible; only viewing, local construction for self-use and public fork discussion are allowed. Unauthorized redistribution and commercial use are prohibited.
