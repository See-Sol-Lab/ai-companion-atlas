PROJECT INTRO

Project introduction

Dylan Heartbeat is the resident runtime for the Kelivo AI companion. Gateway retains the client's original personality, world book, and memory, and only injects real time and active behavior context at appropriate locations; the background process wakes up the model according to day, night, and last contact time, and then records push or silence back to the common timeline.

The project supports Bark and ntfy, weather injection, multi-modal transparent transmission, automatic diary, management page, and local or Railway deployment. The timestamp memory database will restore the message time that was trimmed by the client, so that the active event accurately falls in the time gap of the conversation history.

  • Suitable for:Using Kelivo, hope is that AI can proactively contact people, preserving a sense of time and behavioral continuity.
  • Platform:Kelivo client works with Node.js Gateway; can run on local machine, VPS, Railway or Render.
  • Usage:After Fork, fill in the model, push, time zone and wake-up policy configuration, and then run Gateway and wake-up at the same time.
