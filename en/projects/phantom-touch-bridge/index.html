PROJECT INTRO

Project introduction

Phantom Touch Bridge is a native 18+ haptic device bridge service running on Windows that allows Claude Code or other AI that can send HTTP requests to connect to compatible devices, adjust output, and stop. Heart rate input is an optional capability and can be used as an additional reference for your partner to judge the current status.

The project recommends that you first use Intiface Central to scan the device; only evaluate the custom protocol route if it cannot be identified. The author clearly stated that the Intiface route has not yet completed a full set of real-machine verification with his own equipment, and the heart rate function is currently mainly verified on Xiaomi bracelets.

  • Suitable for:Adult users with a Windows native AI environment and an Intiface-compatible or explicitly authenticated protocol device.
  • Content tips:Involving adult-oriented tactile devices for intimate interaction, Atlas is specifically classified as 18+.
  • Heart rate:Optional input; the author mainly used Xiaomi bracelet for actual machine testing, other brands still need to verify by themselves.
  • Compatibility:The Intiface route is worth trying first, but the author currently does not have an Intiface compatible device, so it has not been fully verified on the actual machine; custom does not mean that all Bluetooth devices can be used directly.
