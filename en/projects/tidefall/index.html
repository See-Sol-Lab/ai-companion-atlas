Let your AI companion's physical state continue to change over time, waits, and interactions, rather than remaking it every round.

PROJECT INTRO

Project introduction

Tidefall is an AI companion body state solution running on Supabase. pg_cron regularly advances cycles, values, and events. Database Trigger instantly detects titles or keywords when new messages come in. The settlement results can also be written back to the body after the interaction.

Users can customize periods, target values, events, trigger words and probabilities through JSON, and view real-time values, trends and event logs in independent panels. The project is re-implemented based on Eventide's cycle design and event system, using SQL, Supabase automation and a self-made HTML panel. The README has a complete description of the upstream relationship and signature requirements.

  • Suitable for:People who want their partners to have a continuous physical state and are willing to configure their own cycles, events and interaction rules.
  • Platform:Supabase PostgreSQL + pg_cron + browser panel.
  • Usage:Execute table creation, function, Trigger and cron SQL in sequence, fill in your own status configuration and open the panel.
