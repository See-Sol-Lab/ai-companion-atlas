PROJECT INTRO

Project introduction

The repository teaches you to wrap an existing AI chat page as an Android app and display replies through a Dynamic Island-style floating notice. The basic guide is for people who already have a frontend; the advanced guide discusses server push, device status, and additional system features.

It is a tutorial with demonstration material, not a ready-made installer. The basic route needs an Android phone, Node.js, and Android Studio; proactive messages also depend on whether the original frontend has a wake interface.

  • Suitable for:People with an existing AI chat page who want to build an Android app and floating notifications.
  • Platform:Android phone; a computer with Node.js and Android Studio.
  • Usage:Follow the basic guide to build from an existing frontend; advanced features need additional server and device integration.
  • License:The repository README states MIT; check the licenses of any third-party components used by the guide.
