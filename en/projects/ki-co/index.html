PROJECT INTRO

Project introduction

KI-CO provides multi-model long dialogues, personality cores, memory files, life lines, status cards, diaries, memory seeds, viewing rooms and Time Bridge, and supports web pages, PWAs and Electron desktops.

The project has formed its own cabin brand and complete living space; the old window analysis and continuation module clearly refers to and reuses the relevant ideas of Solasphere. Atlas retains this source statement and does not mark the originality.

  • Suitable for:Users who want to save long-term conversations, hierarchical memories and joint movie watching in the local companion space.
  • Platform:Web, PWA and Windows Electron single file version.
  • Usage:Download the distribution version and use it directly, or deploy the web page yourself and configure the model endpoint and local memory.
