PROJECT INTRO

Project introduction

gaze is a native tool for adding screen awareness to existing AI companions. It can continuously capture a specified window or a controlled foreground window, use a visual model to generate short narrations, use OCR to extract text, and optionally listen to system audio to generate subtitles. Real-time context can be written to simple JSON, JSONL, or any own memory service.

The project adopts a narrow-gate strategy by default: if the target window cannot be found, it will be skipped, and the entire desktop will not be automatically intercepted; windows such as banking, chat, password manager, and email are blacklisted, and at the same time, AI clients and floating windows are independently prevented from being recursively captured. Users can also record completely offline, without sending footage to external services.

  • Suitable for:People who want AI to accompany them to watch videos, read screens, and play games while retaining clear visual boundaries.
  • Platform:Windows 10/11; pure Python, minimal mode without Node or browser automation.
  • Usage:Select Window and Visual Services, and enable OCR, audio subtitles, and memory push as needed.
  • License:MIT。
