PROJECT INTRO

Project introduction

omemo is an OpenAI compatible memory agent. The chat client sends the request to omemo, and the agent saves the conversation, calls the built-in or external summary mode to form a memory, and then adds the relevant content to subsequent model requests.

The project supports two routes: complete prompt injection and RAG, which is suitable for users who do not want to change the client and only want to adjust the API address.

  • Suitable for:There are already OpenAI compatible clients for those who want to gain long-term memory with minimal changes.
  • Platform:Python Self-host, connect to any OpenAI compatible application and model service.
  • Usage:Deploy the agent, configure the upstream model, and change the client Base URL to omemo.
  • License:Apache-2.0。
