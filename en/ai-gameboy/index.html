How do I start after downloading?

01 · SAVE

Save it in your own folder

Keep the filename pocket_night_shop.py and put it in a writable folder. This is a game script, not a double-click installer.

02 · INVITE

Give the file to your AI

Tell it: This is the text-only Pocket Night Shop. Read the instructions at the start of the file, use Python 3.11 or newer, and check help and observe first.

03 · CONTINUE

Keep your save for next time

Progress is saved as pocket_night_shop.save.sqlite3 beside the script. Keep both files when moving or backing up.

Before you download

No need to set up the full console

This edition needs no MCP, third-party Python dependencies, or extra model API key. Your AI client's usual subscription or usage charges still apply.

Text-only play, without the console webpage

Follow the shop through your AI's stories in chat. Its saves are separate from the full console. For a live view of customers and shopkeeping, explore the full console.

A single-file download for now

The console currently has no installer attachment. This page offers the text-only Night Shop, not an installer for all three cartridges. The game content and interface are primarily in Chinese.
